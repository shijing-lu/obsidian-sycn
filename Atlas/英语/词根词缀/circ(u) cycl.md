# **circ(u) cycl = 圆环**

> [!tip] 快速记忆
>  很容易联想到 **circle**（圆）。这类词根都带有“圆、环、循环”的含义。比如 **bicycle** 就是两个(bi)圆环(cycle)组成的自行车；**recycle** 就是再(re)循环(cycle)。

- **circle**: /'sɜ:rk(ə)l/ = circ + le = 圆 + n. ==n.圆==
- **semicircle**: /'semisɜ:rk(ə)l/ = ==n.半圆==
    - 【真题意群】 move in a semicircle 在半圆内移动
- **circular**: /'sɜ:rkjələr/ = ==a.圆形的==
- **circulate**: /'sɜ:rkjəleɪt/ = ==v.流通==
    - 【真题意群】 circulate the coins 使硬币流通
    - **circulation**: /ˌsɜ:rkjə'leɪʃ(ə)n/ = ==n.循环==
- **circus**: /'sɜ:rkəs/ = ==n.马戏团==
- **cyclist**: /'saɪklɪst/ = ==n.骑自行车的人==
    - 【真题意群】 a professional cyclist 职业自行车手
- **cycle**: /'saɪk(ə)l/ = cycl + e = 环 ==v.循环(狭义的)==
    - 【真题意群】 the most essential cycle 最重要的循环
- **circuit**: /'sɜ:rkɪt/ = circ + u + it = 圆 + 走 ==v.n.巡游; n.电路==
- **bicycle**: /'baɪsɪkl/ = bi + cycl + e = 两个 + 圆 ==n.自行车==
    - 【真题意群】 get on a bicycle 骑上自行车
- **recycle**: /ˌri:'saɪk(ə)l/ = re + cycl + e = 再 + 环 ==v.重复利用==
    - **recycling**: /ˌri:'saɪklɪŋ/ = ==n.再循环==
    - **recyclable**: /ˌri:'saɪkləbl/ = ==a.可回收利用的==
- **encyclopedia**: /ɪnˌsaɪklə'pi:diə/ = en + cycle + ped + ia = 进入 + 圆 + 教育 + n. ==n.百科全书==
