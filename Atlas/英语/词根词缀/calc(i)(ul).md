# **calc(i)(ul) = 计算，石头**

> [!tip] 快速记忆
>  古代人最早是用小石头（calculus）来进行计数的，所以这个词根既有“计算”的意思，也有“石头、钙”的意思。

- **calculate**: /'kælkjuleɪt/ = calcul + ate = 计算 + v. ==v.计算==
- **calculus**: /'kælkjələs/ = ==n.微积分==
- **calcify**: /'kælsɪfaɪ/ = calci + fy = 石头 + v. ==v.钙化==
- **calcium**: /'kælsiəm/ = ==n.钙==
- **chalk**: /tʃɔ:k/ = chalk = 石头 ==n.粉笔 v.用粉笔写画==
