# **bas = 基础**
> [!tip] 快速记忆
> 贝斯（**bas**s）手是乐队的基础。考研中 base 和 basis 的区别在于：base 是具体的“底座”，basis 是抽象的“基础”。

1. **basis**: /ˈbeɪsɪs/ = bas + is = 基础 + n. ===n.基础；底部（抽象基础）==
    - 【真题意群】a biological basis 生物学基础
2. **base**: /beɪs/ = base = 基础 ===n.基础；底部（具体基础）==
    - 【真题意群】be based on a story 以故事为基础
3. **basic**: /ˈbeɪsɪk/ = bas + ic = 基础 + a. ===a.基础的；基本的==
    - 同义：elementary, fundamental
4. **basically**: /ˈbeɪsɪkli/ = basic + ally = 基础的 + ad. ===ad.基本上，主要地==
5. **basin**: /ˈbeɪs(ə)n/ = bas + in = 基础 + n. ===n.盆地==
    - 【真题意群】a shallow basin 浅盆地
6. **basement**: /ˈbeɪsmənt/ = base + ment = 基础 + n. ===n.地下室==
    - 【真题意群】a basement door 地下室的门
7. **debase**: /dɪˈbeɪs/ = de + bas + e = 向下 + 基础 ===v.降低质量；贬值==
8. **abase**: /əˈbeɪs/ = a + base = to + 底部 ===v.使谦卑；使感到羞愧==
9. **database**: /ˈdeɪtəbeɪs/ = data + base = 数据 + 基础 ===n.数据库==
10. **bay**: /beɪ/ = bay = 底部 ===n.湾；间隔==
