# **bar = 横木 → 障碍**
> [!tip] 快速记忆
> **bar** 本身是“酒吧”（有横木柜台），也是“阻挡”的意思。embarrass（使尴尬）拆解为 em（里面）+ barr（障碍）+ ass，就像被障碍困住出不来，人在尴尬时正是这种感受。

- **bar**: /bɑːr/ = bar = 横木 ===n.条，块，棒；酒吧==
    - 【真题意群】dance in a bar 在酒吧跳舞
- **barbecue**: /ˈbɑːrbɪkjuː/ = bar + becue = 栏杆 + 烤架 ===n.烧烤==
    - 【真题意群】have a barbecue 去烧烤
- **barrier**: /ˈbæriər/ = barr + ier = 障碍 + n. ===n.障碍物；障碍==
    - 【真题意群】a language barrier 语言障碍
- **embarrass**: /ɪmˈbærəs/ = em + barr + ass = 里面 + 障碍 + v. ===v.使窘迫，使局促不安==
    - “关在里面出不来”
    - 【真题意群】embarrass a customer 让顾客难堪
- **embarrassed**: /ɪmˈbærəst/ = embarrass + ed = 使尴尬 + a. ===a.尴尬的==
- **embarrassment**: /ɪmˈbærəsmənt/ = embarrass + ment = 使尴尬 + n. ===n.尴尬==
- **bargain**: /ˈbɑːrɡən/ = bar + gain = 障碍 + 获得 ===v.讨价还价；n.便宜货==
- **bacterium**: /bækˈtɪriəm/ = 源于 bar = 杆状 ===n.细菌==
    - bacteria（复数）
    - 【真题意群】study bacteria 研究细菌
