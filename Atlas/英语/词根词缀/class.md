# **class = 种类**

> [!tip] 快速记忆 
> 核心词就是 **class**（班级、阶级、种类）。把东西按种类(class)分好，就是 **classify**（分类）。

- **class**: /klæs/ = class = 种类 ==n.种类;班级、课;等级==
- **classify**: /'klæsɪfaɪ/ = ==v.分类==
    - 【真题意群】 classify some pictures 将照片分类
    - **classification**: /ˌklæsɪfɪ'keɪʃ(ə)n/ = ==n.分类==
- **classic**: /'klæsɪk/ = ==a.经典的; n.名著==
- **classical**: /'klæsɪk(ə)l/ = ==a.经典的;古典的==
