# **card cord = 心；绳子**

> [!tip] 快速记忆 
> 该词根最核心的意思是“心”(heart)。**core**（核心），**courage**（勇气，发自内心的力量）。另外它在演化中也有“绳索”的含义，如 **cord**。

- **record**: /'rekərd/ = re + cord = 回到 + 心里 ==v.记录; n.记录==
- **concord**: /'kɑ:nkɔ:rd/ = con + cord = 共同 + 心 ==n.一致;和谐==
- **discord**: /'dɪskɔ:rd/ = dis + cord = x + 心 ==n.不和;纷争==
- **courageous**: /kə'reɪdʒəs/ = courage + ous = 心→勇气 + a. ==a.勇敢的; ad.勇敢地==
    - **discourage**: /dɪs'kɜ:rɪdʒ/ = ==v.阻止;使气馁==
    - **encourage**: /ɪn'kɜ:rɪdʒ/ = ==v.鼓励;怂恿==
    - **courage**: /'kɜ:rɪdʒ/ = ==n.勇气==
- **core**: /kɔ:r/ = cor + e = 心 ==n.果核;核心 a.核心的主要的==
- **cordial**: /'kɔ:rdʒəl/ = cord + ial = 心 + a. ==a.友好的;可亲的==
- **cardinal**: /'kɑ:rdɪnl/ = card + inal = 心 + a. ==a.最重要的基本的 n.红衣主教==
- **cord**: /kɔ:rd/ = cord = 绳子 ==n.绳;电源线==
- **heart**: /hɑ:rt/ = heart = 心 ==n.心==
    - **hearten**: /'hɑ:rt(ə)n/ = ==v.鼓舞;使振作==
    - **hearty**: /'hɑ:rti/ = ==a.衷心的;热诚的;健壮的==
