# **cern cert cret = 确定**

> [!tip] 快速记忆 
> 核心词 **certain**（确定的）。这个词根的意思是“搞清楚、弄确定、辨别”。

- **concern**: /kən'sɜ:rn/ = con + cern = 加强 + 确定 ==v.关心==
    - **concerned**: /kən'sɜ:rnd/ = ==a.忧虑的==
    - **unconcerned**: /ʌnkən'sɜ:rnd/ = ==a.漠不关心的==
- **certain**: /'sɜ:rt(ə)n/ = cert + ain = 确定 + a. ==a.确定的;某个==
    - **uncertain**: /ʌn'sɜ:rt(ə)n/ = ==a.不确定的==
    - 【真题意群】 be uncertain about sth.对某事不确定
    - **certainly**: /'sɜ:rt(ə)nli/ = ==ad.当然==
    - **certainty**: /'sɜ:rt(ə)nti/ = ==n.确定;必然性==
- **ascertain**: /ˌæsər'teɪn/ = as + cert + ain = to + 确定 + v. ==v.查明;确定==
- **certificate**: /sər'tɪfɪkət/ = cert + ifi + cate = 确定 + v. + n. ==n.证书;执照==
    - 【真题意群】 a birth certificate 出生证明
    - **certify**: = ==v.证明==
    - **certification**: = ==n.证明==
- **certitude**: /'sɜ:rtɪtu:d/ = ==n.确信==
- **concert**: /'kɑ:nsərt/ = con + cert = 共同 + 确定—“强调统一性” ==n.和谐一致;音乐会; v.协调==
- **discern**: /dɪ'sɜ:rn/ = dis + cern = 分开 + 确定 ==v.辨别;觉察==
    - **discernible**: /dɪ'sɜ:rnəb(ə)l/ = ==a.可识别的;可辨别的==
