> [!tip] 快速记忆 
> 这些是讲义中单列的重要词汇，不以常见词根成组，但考频极高。

- **category**: /'kætəɡɔ:ri/ = cate + gory = 向下 + 阐述 ==n.种类==
- **cater**: /'keɪtər/ = “c”手抓动作 = 抓住对方喜好 ==v.满足;迎合==
- **character**: /'kærəktər/ = “刻下的印记” ==n.品质;性格;特性;人物角色==
- **characteristic**: /ˌkærəktə'rɪstɪk/ = ==a.典型的;特有的 n.特征;特性==
- **characterize**: /'kærəktəraɪz/ = ==v.描绘/具有……的特征特性==
- **check**: /tʃek/ = “c”手抓动作 = 拦下核验 ==v.n.阻止;抑制;核对检查==
- **cheque**: = (英)(check(美)) = 需要抓住检查的东西 ==n.支票==
- **combine**: /kəm'baɪn/ = com + bi(ne) = 共同 + 两个 ==v.(使)结合==
- **cunning**: /'kʌnɪŋ/ = cunn + ing = 同 can“知道;了解” + a. ==a.狡猾的;巧妙的==
- **cue**: /kju:/ = 发音同 q(提示符) ==n.提示;暗示==
- **colonial**: /kə'loʊniəl/ = colon + ial = 殖民 + a. ==a.殖民的==
- **clone**: /kloʊn/ = cl 切 = 切下来植物繁殖再生 ==v.克隆 n.克隆动物植物;复制品==
- **contrary**: /'kɑ:ntreri/ = contr + ary = 相反 + a. ==a.相反的==
- **council**: /'kaʊns(ə)l/ = co(u)n + cil = 共同 + 召集 ==n.委员会;地方议会==
- **chronic**: /'krɑ:nɪk/ = chron + ic = 时间 + a. ==a.慢性的;长期(患病)的==
- **celebrity**: /sə'lebrəti/ = celebr + ity = 繁忙 + n. ==n.名人;荣誉==
- **celebrate**: /'selɪbreɪt/ = ==v.歌颂;庆祝==
    - **celebration**: = ==n.庆祝;赞扬==
    - **celebrated**: /'selɪbreɪtɪd/ = ==a.有名的;著名的==
- **condemn**: /kən'dem/ = con + demn = 共同 + 惩罚 ==v.谴责;宣判==
- **comedy**: /'kɑ:mədi/ = come + dy = 来(娱乐) + n. ==n.喜剧;滑稽==
- **comic**: /'kɑ:mɪk/ = ==a.喜剧的;滑稽的 n.喜剧演员==
