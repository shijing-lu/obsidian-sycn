# **cav = hole 洞**

> [!tip] 快速记忆
>  **cav** 代表洞穴、空洞。比如 **cave** 就是山洞；**excavate** 就是向外(ex)挖洞(cav)，即“挖掘”。

- **cave**: /keɪv/ = cav + e = 洞 ==n.洞穴==
- **cavern**: /'kævərn/ = ==n.大山洞==
- **excavate**: /'ekskəveɪt/ = ex + cav + ate = out + 洞 + v. ==v.挖掘;开凿==
    - **excavation**: = ==n.挖掘;开凿==
    - **excavator**: /'ekskəveɪtər/ = ==n.挖掘机;开凿者==
