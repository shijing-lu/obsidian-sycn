
# **cent cant charm = 唱**

> [!tip] 快速记忆 
> 与“唱歌、吟唱”相关。引申为具有魔力的咒语，或者像歌声一样吸引人的“魅力” (**charm**)。

- **chant**: /tʃænt/ = 唱的异体 = 唱 ==n.圣歌; v.唱==
- **accent**: /'æksent/ = ac + cent = to + 唱 ==n.口音;强调; v.重读==
    - **accentuate**: /ək'sentʃueɪt/ = ==v.使突出==
- **incentive**: /ɪn'sentɪv/ = in + cent + ive = 里面 + 唱 + n. ==n.动机;刺激==
- **charm**: /tʃɑ:rm/ = charm = 唱 ==n.魅力==
    - **charming**: /'tʃɑ:rmɪŋ/ = ==a.迷人的==
