# **claim clam clare = 呼喊**

> [!tip] 快速记忆 
> 与 call 同源，表示“大声呼喊、声称”。比如 **claim** 是声称、索取；**exclaim** 则是向外(ex)大喊，即“惊叫”。

- **claim**: /kleɪm/ = claim = 呼喊 ==v.n.声称;索取==
- **exclaim**: /ɪk'skleɪm/ = ex + claim = out + 呼喊 ==v.呼喊==
- **acclaim**: /ə'kleɪm/ = ac + claim = to + 呼喊 ==v.称赞==
- **proclaim**: /proʊ'kleɪm/ = pro + claim = 向前 + 叫 ==v.(正式公开)宣告==
- **reclaim**: /rɪ'kleɪm/ = re + claim = 往回 + 喊 ==v.n.要求归还 v.开拓荒地;纠正感化==
- **recall**: /rɪ'kɔ:l/ = re + call = 往回 + 喊 ==v.召回(残次品);回想起 n.记忆力==
