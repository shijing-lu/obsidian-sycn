# **car(r) = 车；负载 (同源 cur,跑)**

> [!tip] 快速记忆 
> 和 `cur` 同源，意为“跑;车;负载”。汽车 **car** 本身就是载重跑的工具，引申出 **career** (拉着你跑一生的职业载体) 和 **charge** (装载责任/索取费用)。

- **car**: /kɑ:r/ = car = 车 ==n.车==
- **cargo**: /'kɑ:rɡoʊ/ = car + go = 车运输 + 走 ==n.货物==
- **carry**: /'kæri/ = car + ry = 车 + v. ==v.运送;携带==
- **carrier**: /'kæriər/ = ==n.搬运者;(车的)置物架==
    - 【真题意群】 a mail carrier 邮递员
- **career**: /kə'rɪr/ = car + eer = 车(负载) + n.“全程做的事” ==n.职业==
- **charge**: /tʃɑ:rdʒ/ = c(h)ar + ge = 负载 + v.“承载一些责任或义务” ==n.v.(使)负责→索要;费用;命令==
- **discharge**: /dɪs'tʃɑ:rdʒ/ = ==v.n.允许离开(清偿债务、卸货);释放(开火、发射、履行债务);解雇==
- **carriage**: /'kærɪdʒ/ = carr + i + age = 车 + n. ==n.四轮马车;(火车)客车厢==
    - 【真题意群】 a bright red carriage 亮红色的四轮马车
