# **cast = 扔**

> [!tip] 快速记忆 
> 核心动作是“扔、投掷”。比如 **broadcast** 是把信号向宽广(broad)的地方扔(cast)，即“广播”；**forecast** 是把目光投向前面(fore)，即“预测”。

- **cast**: /kæst/ = cast = 扔 ==v.扔,抛 n.演员表==
    - 【真题意群】 cast tomatoes at the crowd 朝人群扔西红柿
- **forecast**: /'fɔ:rkæst/ = fore + cast = 前面 + 扔 ==v.预言==
    - 【真题意群】 a weather forecast 天气预报
- **broadcast**: /'brɔ:dkæst/ = broad + cast = 宽广 + 扔 ==v.n.广播==
    - 【真题意群】 an evening broadcast 夜间广播
- **castle**: /'kæs(ə)l/ = cast + le = 投掷(防御) + n. ==n.城堡==
    - 【真题意群】 visit a castle 参观城堡
- **newscast**: /'nu:zkæst/ = news + cast = 新闻 + 扔 ==n.新闻广播==
