# **count quant = 计算，数量**

> [!tip] 快速记忆 
> 大家都认识 **count**（数数），而 **quant** 就是数量（quantity）。**account**（账户）就是用来算账的地方；**discount** 就是有一部分不计算钱了（打折）。

- **account**: /ə'kaʊnt/ = ac + count = 加强 + 计算 ==n.账户;描述 v.解释;记述;占据;导致==
    - 【真题意群】 a detailed account 详细的账目
    - **accounting**: /ə'kaʊntɪŋ/ = ==n.会计(学科)==
    - **accountant**: /ə'kaʊntənt/ = ==n.会计(职业)==
    - **accountable**: /ə'kaʊntəbl/ = ==a.有责任的==
- **discount**: /'dɪskaʊnt/ = dis + count = 不 + 计算“有一部分不算钱了” ==n.折扣 v.打折==
    - 【真题意群】 a different discount 一个不同的折扣
- **count**: /kaʊnt/ = count = 计算 ==v.数;指望;重要;包括;认为 n.数==
    - **countless**: /'kaʊntləs/ = ==a.无数的==
- **counter**: /'kaʊntər/ = ==n.计数器;柜台==
- **encounter**: /ɪn'kaʊntər/ = en + counter = 进入 + 计数“被发现了” ==v.n.遭遇;遇到==
- **quantity**: /'kwɑ:ntəti/ = quant + ity = 数 + n. ==n.数量==
    - **quantitative**: /'kwɑ:ntəteɪtɪv/ = ==a.定量的==
- **quota**: /'kwoʊtə/ = quot + a = 数量 ==n.配额;限额;指标==
- **quote**: /kwoʊt/ = quot + e = 计算(在内) ==v.引用==
    - **quotation**: /kwoʊ'teɪʃ(ə)n/ = ==n.引用==
