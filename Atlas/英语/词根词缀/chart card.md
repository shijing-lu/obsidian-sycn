# **chart card = 图、纸**

> [!tip] 快速记忆 
> 这个词根和“纸张、图表、卡片”有关。**card** 本身就是卡片；**chart** 则是纸上画的图表。

- **chart**: /tʃɑ:rt/ = chart = 纸 ==n.图表==
- **charter**: /'tʃɑ:rtər/ = chart + er = 图 + n. ==n.v.特许;宪章==
- **card**: /kɑ:rd/ = card = 纸 ==n.卡片==
- **discard**: /dɪ'skɑ:rd/ = dis + card = x + 卡片 ==n.v.丢弃==
- **cartoon**: /kɑ:r'tu:n/ = cart + oon = 图 + n. ==n.漫画;图画==
