# **celer = 快**

> [!tip] 快速记忆 
> 核心意思是“快速、加速”。最常见的词就是 **accelerate**（加速）。

- **accelerate**: /ək'seləreɪt/ = ac + celer + ate = to + 快 + v. ==v.加速==
    - **acceleration**: /əkˌselə'reɪʃ(ə)n/ = ==n.加速==
- **celerity**: /sə'lerəti/ = celer + ity = 快 + n. ==n.敏捷==
- **excel**: /ɪk'sel/ = ex + cel = out + 快 ==v.擅长;胜过==
    - **excellent**: /'eksələnt/ = ==a.极好的;优秀的==
