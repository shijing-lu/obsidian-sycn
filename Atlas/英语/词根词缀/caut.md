# **caut = 小心**

> [!tip] 快速记忆 
> 核心词是 **caution**（小心，谨慎）。为了防止危险提前(pre)小心(caution)，就是 **precaution**（预防措施）。

- **caution**: /'kɔ:ʃ(ə)n/ = caut + ion = 小心 + n. ==n.小心,谨慎;警告==
- **cautious**: /'kɔ:ʃəs/ = ==a.谨慎的,小心的==
    - 【真题意群】 be cautious about sth. 对某事谨慎
- **precaution**: /prɪ'kɔ:ʃn/ = pre + caut + ion = 提前 + 小心 + n. ==n.预防措施==
