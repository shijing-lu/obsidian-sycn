# **cru = 交叉；十字**

> [!tip] 快速记忆 
> 从“十字架”(cross) 引申而来。走到十字路口面临重要抉择，所以 **crucial** 表示“决定性的、关键的”。

- **crucial**: /'kru:ʃ(ə)l/ = cruc + ial = 十字 + a. ==a.决定性的;重要的==
- **cross**: /krɔ:s/ = cross = 交叉 ==n.v.十字;交叉==
- **cruise**: /kru:z/ = cru + ise = 交叉 + v. ==v.n.巡航;巡游==
- **discuss**: /dɪ'skʌs/ = dis + cuss = 离散 + cross 的变体→十字“不同主体想法相互碰撞” ==v.讨论==
