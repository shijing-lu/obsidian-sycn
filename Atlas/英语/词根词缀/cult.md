# **cult = 培养**

> [!tip] 快速记忆
>  来源于耕种、培养。**agriculture** (农业) 就是种地（培养植物）；**culture** (文化) 则是人类精神和智力的培养。

- **culture**: /'kʌltʃər/ = cult + ure = 培养 + n. ==n.文化==
    - **cultural**: /'kʌltʃərəl/ = ==a.文化的==
- **agriculture**: /'æɡrɪkʌltʃər/ = agri + cult + ure = 田地 + 耕种 + n. ==n.农业;农学==
    - 【真题意群】 american agriculture 美国农业
    - **agricultural**: /ˌæɡrɪ'kʌltʃərəl/ = ==a.农业的==
    - 【真题意群】 agricultural industry 农业生产
