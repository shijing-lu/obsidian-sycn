# **cid cis = 切**

> [!tip] 快速记忆 
> **cid/cis** 表示“切断、杀”。**decide**（决定）就是把犹豫的事情一刀切断（拍板）；**suicide**（自杀）是自己(sui)切断生命(cid)；**scissors**（剪刀）就是用来切的东西。

- **decide**: /dɪ'saɪd/ = de + cid + e = 加强 + 切“决断终结某事” ===v.决定==
    - **decision**: /dɪ'sɪʒ(ə)n/ = ===n.决定==
    - **decisive**: /dɪ'saɪsɪv/ = ===a.决定性的==
- **precise**: /prɪ'saɪs/ = pre + cis + e = 前 + 切掉(只切一点点的内涵) ===a.精准的==
    - 【真题意群】 a precise mixture of sth. 某物的精确混合
    - **precision**: /prɪ'sɪʒ(ə)n/ = ===n.精度;精确==
- **pesticide**: /'pestɪsaɪd/ = pest + i + cid + e = 害虫 + 切 ===n.杀虫剂==
- **biocide**: /'baɪoʊsaɪd/ = bio + cid + e = 生物 + 切 ===n.杀虫剂==
- **scissors**: /'sɪzərz/ = s + cis + s + or + s = 加强双写无实际内涵 + 切 + n. ===n.剪刀,剪子==
    - 【真题意群】 a pair of scissors 一把剪刀
- **suicide**: /'su:ɪsaɪd/ = sui + cid + e = 自己 + 切 ===n.自杀==
- **concise**: /kən'saɪs/ = con + cis + e = 全 + 切 ===a.简洁的==
- **incise**: /ɪn'saɪz/ = in + cis + e = 里面 + 切 ===v.切==
    - **incisive**: /ɪn'saɪsɪv/ = ===a.锋利的;敏锐的==
