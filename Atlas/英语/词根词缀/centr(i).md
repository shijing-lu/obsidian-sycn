# **centr(i) = 中心**

> [!tip] 快速记忆 
> 这个词根长得就和 **center**（中心）一模一样。**central** 是中心的；**concentrate** 就是把所有的东西集中到一个中心点（专心、集中）。

- **central**: /'sentrəl/ = centr + al = 中心 + a. ==a.中心的==
- **centre** / **center**: /'sentər/ = center = 中心 ==n.中心 v.以……为中心==
- **concentrate**: /'kɑ:ns(ə)ntreɪt/ = con + centr + ate = 加强 + 中心 + v. ==v.集中;专心==
    - **concentration**: /ˌkɑ:ns(ə)n'treɪʃ(ə)n/ = ==n.专心==
- **eccentric**: /ɪk'sentrɪk/ = ec + centr + ic = out + 中心 + a. ==a.古怪的==
