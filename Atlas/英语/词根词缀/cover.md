# **cover = 遮盖**

> [!tip] 快速记忆 
> 核心词 **cover**（覆盖）。**discover** 拿掉(dis)覆盖(cover)，就是“发现”；**recover** 再(re)覆盖回去，就是“恢复”。

- **cover**: /'kʌvər/ = cover = 盖 ===v.包括;覆盖;报道 n.覆盖物==
    - **coverage**: ===n.覆盖范围;新闻报道==
- **discover**: /dɪ'skʌvər/ = dis + cover = x(否定) + 覆盖 ===v.发现==
    - **discovery**: ===n.发现==
- **recover**: /rɪ'kʌvər/ = re + cover = 再 + 覆盖 ===v.恢复==
    - **recovery**: ===n.恢复==
- **unfold**: /ʌn'foʊld/ = x(否定) + 折叠 ===v.打开;展现 a.隐蔽的== _(注：讲义归于此类逻辑反向扩展)_
