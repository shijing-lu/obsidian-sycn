# **clos clud clus = 关闭**

> [!tip] 快速记忆
>  核心词是 **close**（关闭）。所有包含 clud / clus 的词都有“关起来”的意象。比如 **include** 是关在里面（包含）；**exclude** 是关在外面（排除）。

- **close**: /kloʊz/ = clos + e = 关闭 ==v.关闭
    - **closet**: = ==n.壁橱;小房间==
- **exclude**: /ɪk'sklu:d/ = ex + clud + e = out + 关 ==v.排除;排斥
    - **exclusive**: = ==a.互斥的;其他的==
- **conclude**: /kən'klu:d/ = con + clud + e = 加强 + 关 ==v.下结论;结束
    - 【真题意群】 conclude one's speech 结束某人的演讲
    - **conclusion**: = ==n.结论;结束==
    - 【真题意群】 draw a conclusion 得出结论
- **include**: /ɪn'klu:d/ = in + clud + e = 里面 + 关 ==v.包括
    - **inclusive**: = ==a.包括
- **enclose**: /ɪn'kloʊz/ = en + clos + e = 里面 + 关 ==v.包围;装入==
- **disclose**: /dɪs'kloʊz/ = dis + clos + e = x + 关 ==v.揭露;公开==
- **preclude**: /prɪ'klu:d/ = pre + clude = 前 + 关闭 ==v.阻止;排除;妨碍==
