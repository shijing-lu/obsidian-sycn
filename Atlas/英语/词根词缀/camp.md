# **camp = 田野**

> [!tip] 快速记忆 
> 核心词 **camp** (营地、田野)。从田野里的军营引申出 **campaign**（战役、运动）；大学里的“田野”就是 **campus**（校园）。

- **camp**: /kæmp/ = camp = 田野 ==n.野营 v.露营==
- **campus**: /'kæmpəs/ = camp + us = 田野 + n. ==n.大学校园==
- **campaign**: /kæm'peɪn/ = camp + aign = 田野 + n. ==n.运动;活动;战役==
    - 【真题意群】 a nationwide campaign 全国性的运动
- **champion**: /'tʃæmpiən/ = champ(camp) + ion = 田野(→战场) + n. ==n.冠军==
