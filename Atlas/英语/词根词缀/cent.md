# **cent = 百 hundred**

> [!tip] 快速记忆 
> **cent** 词根代表“一百”。**century** 是“百年（世纪）”；**percent** 是每(per)百(cent)，即“百分之...”。（1 美元等于 100 美分，所以 cent 也是“分”）。
- **cent**: /sent/ = cent = 百(分之一) ===n.分==
- **centigrade**: /'sentɪɡreɪd/ = cent + i + grade = 百 + 等级 ===a.摄氏度的==
- **century**: /'sentʃəri/ = cent + ury = 百 + n. ===n.百年==
- **percent**: /pər'sent/ = per + cent = 每 + 百 ===n.百分之==
    - **percentage**: ===n.百分比==
- **centimeter**: /'sentɪmi:tər/ = cent + i + meter = 百 + 测量 ===n.厘米==
