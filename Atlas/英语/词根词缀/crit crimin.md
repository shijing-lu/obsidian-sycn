# **crit crimin = 区分，判断；决断**

> [!tip] 快速记忆 
> 核心在于“批判、判断、区分”。**critic**（批评家，负责评判的人），**criminal**（罪犯，即被审判决断的人），**secret**（秘密，即区分开来不让别人知道的事）。

- **criterion**: /kraɪ'tɪriən/ = crit + er + ion = 判断 + n. + n. ==n.标准==
- **critic**: /'krɪtɪk/ = crit + ic = 判断 + n. ==n.批评家;评论家==
    - **critical**: /'krɪtɪk(ə)l/ = ==a.挑剔的;评论的;关键的==
    - **criticism**: /'krɪtɪsɪzəm/ = ==n.批评==
    - **criticize**: /'krɪtɪsaɪz/ = ==v.批评==
    - **critique**: /krɪ'ti:k/ = ==n.评论文章;批评==
- **hypocrisy**: /hɪ'pɑ:krəsi/ = hypo + cri + sy = 下 + 判断“判断都隐藏在下面” ==n.虚伪;伪善==
    - **hypocritical**: /ˌhɪpə'krɪtɪk(ə)l/ = ==a.伪善的;虚伪的==
- **crime**: /kraɪm/ = crim + e = 决断 ==n.犯罪;罪行==
    - **criminal**: /'krɪmɪn(ə)l/ = ==a.犯罪的; n.罪犯==
    - **incriminate**: /ɪn'krɪmɪneɪt/ = ==v.控告;归罪于==
- **discrimination**: /dɪˌskrɪmɪ'neɪʃ(ə)n/ = dis + crimin + ation = 分开 + 决断 + n. ==n.歧视==
    - **discriminate**: /dɪ'skrɪmɪneɪt/ = ==v.区别;歧视==
- **crisis**: /'kraɪsɪs/ = cris + is = 判断 + n. ==n.危机(关头)==
- **discreet**: /dɪ'skri:t/ = dis + creet = 分离 + 区分 ==a.谨慎的;朴素的==
- **discrepancy**: /dɪ'skrepənsi/ = dis + crep + ancy = 离散 + 区分 + n. ==n.差异;不一致==
- **secret**: /'si:krət/ = se + cret = 离开 + 区分—”一定要分开不能被获知的” ==a.秘密的 n.秘密==
    - **secretary**: /'sekrəteri/ = se + cret + ary = 分开 + 区分 + n.“经手要确定分开的信息的人” ==n.秘书==
