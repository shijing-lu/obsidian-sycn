# **clin cliv clim = 倾斜**
> [!tip] 快速记忆 
> 这个词根带有“弯曲、倾斜”的画面感。比如 **decline** 是向下(de)倾斜(cline)，即“下降、衰退”；**climate**（气候）原本是指太阳光倾斜照射地球的不同角度带来的气象变化。

- **decline**: /dɪ'klaɪn/ = de + clin + e = 向下 + 倾斜 ==v.n.下降;减少==
- **clinic**: /'klɪnɪk/ = clin + ic = 倾斜 + a.(此处为 n.) ==n.诊所==
    - 【真题意群】 a private clinic 私人诊所
    - **clinical**: /'klɪnɪk(ə)l/ = ==a.临床的==
- **climate**: /'klaɪmət/ = clim + ate = 倾斜 + n. ==n.气候==
    - 【真题意群】 a result of climate change 气候变化的结果
- **clement**: /'klemənt/ = ==a.(气候)温和的==
- **inclement**: /ɪn'klemənt/ = in + clement ==a.天气恶劣的==
- **incline**: /ɪn'klaɪn/ = in + clin + e = 进入 + 倾斜 ==v.n.倾斜;倾向于==
    - **inclination**: /ˌɪnklɪ'neɪʃ(ə)n/ = ==n.斜坡;倾斜度==
    - **inclined**: /ɪn'klaɪnd/ = ==a.易于……的;倾向于……的==
    - **disinclined**: /ˌdɪsɪn'klaɪnd/ = ==a.不愿意;勉强==
- **proclivity**: /prə'klɪvəti/ = pro + cliv + ity = 前 + 斜 + n. ==n.倾向==
- **climax**: /'klaɪmæks/ = cli + max = 倾斜 + 最大 ==n.顶点;高潮 v.达到顶点==
