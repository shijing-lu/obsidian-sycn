# **ced cede ceed cess = 走**
> [!tip] 快速记忆
> 
> 包含 **ced/cess** 的词往往与“走、行进、退让”相关。**proceed**（前进）= 向前(pro)走(ceed)；**succeed**（成功）= 从下面一直走上来(suc+ceed)；**access**（接近）= 走过去(ac+cess)
- **procedure**: /prə'si:dʒər/ = pro + ced + ure = 向前 + 走 + n.”前行的方式” ==n.过程,程序==
    - 【真题意群】 a fixed procedure 固定程序
- **access**: /'ækses/ = ac + cess = to + 走 ==n.通路;入口==
- **accessible**: /ək'sesəb(ə)l/ = ac + cess + ible ==a.易接近的,平易近人的==
    - 【真题意群】 be accessible 儿童可接近
- **inaccessible**: /ˌɪnək'sesəb(ə)l/ = in + accessible ==a.难以接近的==
- **ancestor**: /'ænsestər/ = an + cest + or = 前面 + 走 + 人—“先走一步的人” ==n.祖先==
    - 【真题意群】 a family's ancestor 家族的祖先
- **process**: /'prɑ:ses/ = pro + cess = 前 + 走 ==n.进程 v.处理;加工==
    - 【真题意群】 a continuing process 持续的过程
- **proceed**: /proʊ'si:d/ = pro + ceed = 向前 + 走 ==v.进行==
- **preceding**: /prɪ'si:dɪŋ/ = pre + ced + ing = 提前 + 走 + a. ==a.在先的;前面的==
- **proceeds**: /'proʊsi:dz/ = pro + ceeds = 走到前面来的东西 ==n.收益==
- **proceeding**: /proʊ'si:dɪŋ/ = pro + ceed + ing ==n.进行,进程;行动==
- **succeed**: /sək'si:d/ = suc + ceed = 下面 + 走(上来) ==v.成功;继承==
- **success**: /sək'ses/ = suc + cess = 下面 + 走 ==n.成功==
- **successful**: /sək'sesf(ə)l/ = success + ful ==a.成功的==
- **succession**: /sək'seʃ(ə)n/ = suc + cess + ion ==n.继承==
- **successive**: /sək'sesɪv/ = suc + cess + ive ==a.继承的;连续的==
- **cede**: /si:d/ = cede = 走开 ==v.割让;放弃==
- **necessary**: /'nesəseri/ = ne + cess + ary = 否认 + 走 + a.”离不开的” ==a.必要的==
- **necessity**: /nə'sesəti/ = ne + cess + ity ==n.必要性==
- **unnecessary**: /ʌn'nesəseri/ = un + necessary ==a.不必要的==
- **recede**: /rɪ'si:d/ = re + cede = 往回 + 走 ==v.后退==
- **recession**: /rɪ'seʃ(ə)n/ = re + cess + ion ==n.后退;经济不景气==
- **precede**: /prɪ'si:d/ = pre + cede = 提前 + 走到 ==v.在……之前==
- **precedent**: /'presɪdənt/ = pre + ced + ent ==n.先例==
- **unprecedented**: /ʌn'presɪdentɪd/ = un + precedent + ed ==a.前所未有的(事)==
- **exceed**: /ɪk'si:d/ = ex + ceed = out + 走 ==v.超过==
- **excess**: /ɪk'ses/ = ex + cess = out + 走 ==n.过量==
- **excessive**: /ɪk'sesɪv/ = ex + cess + ive ==a.过多的;过分的==
- **exceedingly**: /ɪk'si:dɪŋli/ = exceed + ing + ly ==ad.极其;非常==
- **cease**: /si:s/ = ceas + e = 走(开) ==n.v.终止==
- **concede**: /kən'si:d/ = con + cede = 加强 + 走开 ==v.让步;认输==
