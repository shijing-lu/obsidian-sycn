1. $\arccos(-x) = \pi - \arccos x$, $x \in [-1, 1]$.

2. $\arcsin x + \arccos x = \frac{\pi}{2}$, $x \in [-1, 1]$.

3. $\operatorname{arccot} x + \arctan x = \frac{\pi}{2}, \quad x \in (-\infty, +\infty)$

4. 

$$\arctan x + \arctan \frac{1}{x} = 
\begin{cases} 
\frac{\pi}{2}, & x > 0 \\ 
-\frac{\pi}{2}, & x < 0 
\end{cases}$$
