【例 1.4】
$$
\sin\left(\frac{3}{2}\pi - \alpha\right) = \underline{\quad },\quad 
\cos\left(\pi + \alpha\right) = \underline{\quad },\quad 
\tan\left(\frac{3}{2}\pi + \alpha\right) = \underline{\quad }
$$


答案：
- $\sin\left(\frac{3}{2}\pi - \alpha\right) = -\cos \alpha$
    
- $\cos(\pi + \alpha) = -\cos \alpha$
    
- $\tan\left(\frac{3}{2}\pi + \alpha\right) = -\cot \alpha$
