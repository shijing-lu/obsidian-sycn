
| 等价无穷小关系                         | 备注                 |
| ------------------------------- | ------------------ |
| $$\sin x\sim x$$                | 三角函数等价无穷小          |
| $$\tan x\sim x$$                | 三角函数等价无穷小          |
| $$\arcsin x\sim x$$             | 反三角函数等价无穷小         |
| $$\arctan x\sim x$$             | 反三角函数等价无穷小         |
| $$1-\cos x\sim\dfrac{x^2}{2}$$  | 三角函数等价无穷小          |
| $$\ln(1+x)\sim x$$              | 对数函数等价无穷小          |
| $$e^x-1\sim x$$                 | 指数函数等价无穷小          |
| $$(1+x)^\alpha-1\sim \alpha x$$ | 幂函数等价无穷小           |
| $$a^x-1\sim x\ln a$$            | 指数函数等价无穷小（\(a>0\)） |

$$
1 - \cos x \sim \frac{1}{2} x^2, \quad x - \ln(1 + x) \sim \frac{1}{2} x^2
$$

$$
x - \sin x \sim \frac{1}{6} x^3, \quad x - \arcsin x \sim -\frac{1}{6} x^3, \quad x - \tan x \sim -\frac{1}{3} x^3, \quad x - \arctan x \sim \frac{1}{3} x^3
$$
