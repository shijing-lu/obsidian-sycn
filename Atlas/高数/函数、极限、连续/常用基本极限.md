
| 类型      | 极限公式                                                | 备注             |
| ------- | --------------------------------------------------- | -------------- |
| 基本型     | $$\lim_{x\to 0}\frac{\sin x}{x}=1$$                 | 最基础的极限公式       |
| 重要极限1   | $$\lim_{x\to\infty}\left(1+\frac{1}{x}\right)^x=e$$ | $1^\infty$ 型极限 |
| 重要极限2   | $$\lim_{x\to 0}(1+x)^{1/x}=e$$                      | 重要极限的另一种形式     |
| 重要极限2变形 | $$\lim_{x\to 0}\frac{a^x-1}{x}=\ln a$$              | 指数函数的极限形式      |
| 对数型     | $$\lim_{x\to 0}\frac{\ln(1+x)}{x}=1$$               | 对数函数的极限形式      |
| 指数型     | $$\lim_{x\to 0}\frac{e^x-1}{x}=1$$                  | 自然指数函数的极限形式    |
| 幂函数型    | $$\lim_{x\to 0}\frac{(1+x)^\alpha-1}{x}=\alpha$$    | 幂函数的极限形式       |
