# **loc(o) = 位置**

> [!tip] 快速记忆 
> 地方、位置。**local** (当地的)；**allocate** (分配，就是给每个人指定位置)。

- **local**: /ˈloʊk(ə)l/ = loc + al = 位置 + a. ==a.当地的==
    - **locality**: /loʊˈkæləti/ = ==n.地点== (同 spot, position)
- **locate**: /ˈloʊkeɪt/ = loc + ate = 位置 + v. ==v.设置于; 定位== (be located in/at)
    - **location**: /loʊˈkeɪʃ(ə)n/ = ==n.位置==
- **allocate**: /ˈæləkeɪt/ = al + locate = to + 位置 ==v.分配; 分派==
    - **allocation**: /ˌæləˈkeɪʃ(ə)n/ = ==n.分配; 分派==
- **allowance**: /əˈlaʊəns/ = al + low + ance = to + 位置 + n. ==n.津贴; 补助==
