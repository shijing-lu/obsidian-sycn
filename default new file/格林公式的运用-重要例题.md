## 题目背景
> 求解**全微分方程**的通解，全微分方程形式为 $P(x,y)dx + Q(x,y)dy = 0$，若满足**与路径无关条件** $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$，则存在二元函数 $u(x,y)$ 使得 $du = Pdx + Qdy$，方程通解为 $u(x,y) = C$（$C$ 为任意常数）。
**给定方程**：$$y e^{y^2} dx + x(e^{y^2} + 2y^2 e^{y^2}) dy = 0$$



## 解题方法分类及详解

### 方法一：凑微分法
**目的**：通过对方程左边表达式进行代数变形，凑出某二元函数的全微分形式，直接积分得通解。

**步骤**：
1. **分析方程结构**：观察方程左边 $y e^{y^2} dx + x(e^{y^2} + 2y^2 e^{y^2}) dy$，尝试将其凑为某函数的全微分。
2. **凑全微分**：利用乘积微分公式 $d(uv) = u dv + v du$，令 $u = x$，$v = y e^{y^2}$，则：
   $$
   d(x \cdot y e^{y^2}) = y e^{y^2} dx + x \cdot d(y e^{y^2})
   $$
   计算 $d(y e^{y^2}) = e^{y^2} dy + y \cdot 2y e^{y^2} dy = e^{y^2}(1 + 2y^2) dy$，代入得：
   $$
   d(x y e^{y^2}) = y e^{y^2} dx + x e^{y^2}(1 + 2y^2) dy = y e^{y^2} dx + x(e^{y^2} + 2y^2 e^{y^2}) dy
   $$
   这与方程左边完全一致，故原方程可写为：
   $$
   d(x y e^{y^2}) = 0
   $$
3. **积分得通解**：两边积分后，得通解：
   $$
   x y e^{y^2} = C \quad (C \text{ 为任意常数})
   $$

---

### 方法二：偏积分法
**目的**：利用全微分的充要条件 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$，通过“先对 $x$ 积分（含待定函数）→ 对 $y$ 求偏导定待定函数”的步骤，构造势函数 $u(x,y)$。

**步骤**：
1. **设全微分形式**：令 $du = P dx + Q dy$，其中 $P = y e^{y^2}$，$Q = x(e^{y^2} + 2y^2 e^{y^2})$。
2. **对 $x$ 积分（$y$ 视为常数）**：
   $$
   u(x,y) = \int P dx + g(y) = \int y e^{y^2} dx + g(y) = x y e^{y^2} + g(y)
   $$
   （$g(y)$ 为仅含 $y$ 的待定函数，因积分时 $y$ 视为常数）。
3. **对 $y$ 求偏导并匹配 $Q$ **：
   对 $u(x,y)$ 关于 $y$ 求偏导：
   $$
   \frac{\partial u}{\partial y} = x \cdot \left[ e^{y^2} + y \cdot 2y e^{y^2} \right] + g'(y) = x(e^{y^2} + 2y^2 e^{y^2}) + g'(y)
   $$
   根据全微分定义，$\frac{\partial u}{\partial y} = Q$，即：
   $$
   x(e^{y^2} + 2y^2 e^{y^2}) + g'(y) = x(e^{y^2} + 2y^2 e^{y^2})
   $$
   化简得 $g'(y) = 0$，积分得 $g(y) = C$（$C$ 为任意常数）。
4. **确定势函数与通解**：
   势函数为 $u(x,y) = x y e^{y^2} + C$，故方程通解为：
   $$
   x y e^{y^2} = C_1 \quad (C_1 \text{ 为任意常数，合并 } C \text{ 后})
   $$

---

### 方法三：曲线积分法（利用“与路径无关”性质）
**目的**：当 $Pdx + Qdy$ 满足与路径无关时，选取**简单折线**（如从定点到动点的水平+垂直线段）计算曲线积分，结果即为势函数 $u(x,y)$。

**步骤**：
1. **验证与路径无关条件**：计算 $\frac{\partial P}{\partial y}$ 和 $\frac{\partial Q}{\partial x}$，验证是否相等：
   $$
   \frac{\partial P}{\partial y} = \frac{\partial}{\partial y} \left( y e^{y^2} \right) = e^{y^2} + 2y^2 e^{y^2}
   $$
   $$
   \frac{\partial Q}{\partial x} = \frac{\partial}{\partial x} \left[ x(e^{y^2} + 2y^2 e^{y^2}) \right] = e^{y^2} + 2y^2 e^{y^2}
   $$
   两者相等，故 $Pdx + Qdy$ 在单连通区域内与路径无关，可选择折线积分。

2. **选取折线路径**：选从 $(0,0)$ 到 $(x,0)$ 再到 $(x,y)$ 的折线（记为 $L_1 + L_2$）：
   - $L_1$：沿 $y=0$（$x$ 轴），$y=0$，$dy=0$，$x$ 从 $0$ 到 $x$；
   - $L_2$：沿 $x=x$（垂直直线），$x=x$（常数），$dx=0$，$y$ 从 $0$ 到 $y$。

3. **计算曲线积分**：
   曲线积分公式为 $u(x,y) = \int_{(0,0)}^{(x,y)} P dx + Q dy = \int_{L_1} P dx + \int_{L_2} Q dy$。
   - 第一段 $L_1$：$y=0$，代入 $P$ 得 $P(x,0) = 0 \cdot e^{0} = 0$，故 $\int_{L_1} P dx = \int_{0}^{x} 0 dx = 0$。
   - 第二段 $L_2$：$x=x$（常数），代入 $Q$ 得 $Q(x,y) = x(e^{y^2} + 2y^2 e^{y^2})$，故：
     $$
     \int_{L_2} Q dy = \int_{0}^{y} x(e^{t^2} + 2t^2 e^{t^2}) dt \quad (\text{令 } t = y, dt = dy)
     $$
     注意到 $d(x y e^{y^2}) = x(e^{y^2} + 2y^2 e^{y^2}) dy$，因此积分结果为 $x y e^{y^2}$（原函数的增量）。

4. **确定势函数与通解**：
   总积分 $u(x,y) = 0 + x y e^{y^2} + C = x y e^{y^2} + C$，故方程通解为：
   $$
   x y e^{y^2} = C \quad (C \text{ 为任意常数})
   $$

---

## 方法对比与总结
| 方法         | 核心思路                          | 适用场景                     | 特点                     |
|--------------|-----------------------------------|------------------------------|--------------------------|
| 凑微分法     | 逆向构造全微分                    | 表达式简洁、易凑型方程       | 快速直接，依赖经验       |
| 偏积分法     | 利用全微分条件分步积分            | 所有满足与路径无关的方程     | 步骤固定，需处理待定函数 |
| 曲线积分法   | 选简单路径计算积分                | 验证与路径无关后快速求势函数 | 避免凑微分，路径选择灵活 |

**最终通解**：
$$
\boxed{x y e^{y^2} = C \quad (C \text{ 为任意常数})}
$$
