
## 性质  
1. **性质 1（线性性）**：$\int_L aP(x,y)dx = a\int_L P(x,y)dx$（$a$ 为常数）  
2. **性质 2（路径可加性）**：设有向分段光滑曲线 $L = L_1 + L_2$（$L_1,L_2$ 与 $L$ 取向相同），则  
   $$\int_L P(x,y)dx + Q(x,y)dy = \int_{L_1} P(x,y)dx + Q(x,y)dy + \int_{L_2} P(x,y)dx + Q(x,y)dy$$  
3. **性质 3（方向性）**：设有向曲线 $L$，$\tilde{L}$ 表示与 $L$ 方向相反的曲线，则  
   $$\int_{\tilde{L}-} P(x,y)dx + Q(x,y)dy = -\int_L P(x,y)dx + Q(x,y)dy$$  
4. **性质 4（普通对称性）**：设积分曲线 $L$ 关于 $y$ 轴对称，则  
   $$\int_L P(x,y)dx = \begin{cases} 2\int_{L_1} P(x,y)dx, & P(-x,y)=P(x,y) \\ 0, & P(-x,y)=-P(x,y) \end{cases}$$  
   $$\int_L Q(x,y)dy = \begin{cases} 2\int_{L_1} Q(x,y)dy, & Q(-x,y)=Q(x,y) \\ 0, & Q(-x,y)=-Q(x,y) \end{cases}$$  
   （其中 $L_1$ 是 $L$ 在 $x$ 轴正半轴的部分）  

   当 $L$ 关于 $x$ 轴对称且 $P(x,y),Q(x,y)$ 关于 $y$ 有奇偶性时，结论类似。
