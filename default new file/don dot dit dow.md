# **don dot dit dow = 给予**

> [!tip] 快速记忆 
> 这一组词根的核心概念是“给 (give)”。比如 **donate**（捐赠 = 给予）；**tradition**（传统 = 一代代穿越时间传“给”下来的东西）。

- **pardon**: /'pɑ:rd(ə)n/ = par + don = 出现 + 给—“给予原来的东西” ==n.v.原谅==
- **donate**: /'doʊneɪt/ = don + ate = 给 + v. ==v.捐赠==
    - 【真题意群】 donate new shoes 捐赠新鞋
    - **donation**: /doʊ'neɪʃ(ə)n/ = ==n.捐赠;捐赠物==
    - **donor**: /'doʊnər/ = ==n.施主;捐赠者==
- **condition**: /kən'dɪʃ(ə)n/ = con + dit + ion = 共同 + 给 + n.—“周围环境的反馈” ==n.状况;条件==
    - **conditional**: /kən'dɪʃən(ə)l/ = ==a.有前提的;条件的==
    - **unconditional**: /ˌʌnkən'dɪʃən(ə)l/ = ==a.无条件的;绝对的==
- **tradition**: /trə'dɪʃ(ə)n/ = tra + dit + ion = 穿过 + 给 + n.—“穿越时间流传到现在” ==n.传统==
    - **traditional**: /trə'dɪʃən(ə)l/ = ==a.传统的==
- **edit**: /'edɪt/ = e + dit = out + 给 ==v.编辑==
    - **editor**: /'edɪtər/ = ==n.编辑==
    - **edition**: /ɪ'dɪʃn/ = ==n.版本==
    - 【真题意群】 the first edition 第一版
    - **editorial**: /ˌedɪ'tɔ:riəl/ = ==a.编辑的; n.社论==
- **anecdote**: /'ænɪkdoʊt/ = an + ec + dot + e = 没有 + 向外 + 给予 ==n.轶事==
    - 【真题意群】 pay for anecdote 为趣闻付稿费
- **endow**: /ɪn'daʊ/ = en + dow = 里面 + 给予 ==v.捐赠;资助==
- **dose**: /doʊs/ = dose = 给予 ==n.(药的)一剂;一份 v.给……服药==
