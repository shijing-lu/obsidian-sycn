# **cad cas cid cay = 降临**

> [!tip] 
> 快速记忆 这一组词根的核心概念是“掉落、降临”，引申为“发生（降临之事）”。比如 **accident**（意外事故）就是突然降临到(ac)身上的事(cid)；**case** 就是发生（降临）的事件或情况。

- **case**: /keɪs/ = cas + e = 降临——“降临之事” ==n.事件;情况==
- **casual**: /'kæʒuəl/ = cas + ual = 降临 + a. ==a.偶然的;非正式的==
    - 【真题意群】 in a casual way 不经意地
- **casualty**: /'kæʒuəlti/ = ==n.伤亡人员==
- **incident**: /'ɪnsɪdənt/ = in + cid + ent = 进入 + 降临 + n.—“进入和降临都能表示发生的内涵” ==n.事件==
    - 【真题意群】 an astronomical incident 天文事件
    - **incidental**: /ˌɪnsɪ'dent(ə)l/ = ==a.偶然的==
    - **incidence**: /'ɪnsɪdəns/ = ==n.发生率;影响==
- **accident**: /'æksɪdənt/ = ac + cid + ent = to + 降临 + n.—“降临表示发生的内涵” ==n.意外事故==
    - 【真题意群】 a case of accident 意外事故
- **occasional**: /ə'keɪʒən(ə)l/ = ==a.偶尔的==
- **coincidence**: /koʊ'ɪnsɪdəns/ = ==n.巧合==
- **decay**: /dɪ'keɪ/ = de + cay = 向下 + 降 ==v.衰减==
