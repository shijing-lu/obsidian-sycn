# **juven = 小的**

> [!tip] 快速记忆 
> 指“年少的、年轻的”。**junior** 指资历浅的/年少的；**juvenile** 指未成年人。

- **junior**: /ˈdʒuːniər/ = jun + ior = 小的 + a. ==a.年少的;资历浅的== (senior 反义词)
- **juvenile**: /ˈdʒuːvən(ə)l/ = juven + ile = 小 + a. ==a.少年的;幼稚的 n.少年==
- **young**: /jʌŋ/ = 源于 jun = 小的 ==a.年轻的 n.年轻人==
    - **youth**: /juːθ/ = ==n.青春;青年时期==
