
# **gress = 走**

> [!tip] 快速记忆
> 与“迈步、行走”紧密相连。踩到别人地盘上走就是 **aggressive** (侵略性的)；大家走到一起开会就是 **congress** (大会) 。

- **progress**:/ˈprɑːɡres/=pro+gress=前+走===v.n.进步==
	- **progressive**: /prəˈɡresɪv/===a.进步的；先进的==
- **aggressive**: /əˈɡresɪv/ = ==a.侵略性的;强势的==
    - 【真题意群】an aggressive voice 有攻击性的声音
    - **aggressor**: /əˈɡresər/ = ==n.侵略者==
- **congress**: /ˈkɑːnɡres/ = con + gress = 共同 + 走 ==n.大会==
- **digress**: /daɪˈɡres/ = di + gress = 分开 + 走 ==v.离题;走向岔道==
- **transgress**: /trænzˈɡres/ = trans + gress = 穿过 + 走 ==v.超过;违背==
