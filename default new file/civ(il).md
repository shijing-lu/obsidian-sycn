# **civ(il) = 公民**

> [!tip] 快速记忆
>  与“城市、市民、文明”紧密相连。**city**（城市）里住着 **citizen**（市民），市民组成的群体和规范就是 **civilization**（文明）。
- **civil**: /'sɪv(ə)l/ = civil = 公民 ===a.市民的;文明的(强调“人”)==
    - 【真题意群】 the civil war 内战
- **civilian**: /sə'vɪliən/ = ===n.平民==
- **civilization**: /ˌsɪvələ'zeɪʃ(ə)n/ = ===n.文明==
    - 【真题意群】 a successful civilization 成功的文明
- **civilize**: /'sɪvəlaɪz/ = ===v.使文明;教化==
- **civic**: /'sɪvɪk/ = ===a.市民的;城市的(强调城市)==
- **city**: /'sɪti/ = cit(civ 变体) + y = 公民 + n. ===n.城市==
- **citizen**: /'sɪtɪzn/ = ===n.市民==
    - 【真题意群】 the duty of a citizen 公民的义务
