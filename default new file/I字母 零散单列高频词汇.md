# **I 字母 单列高频词汇**

> [!tip] 快速记忆 这部分多是由介词前缀 (in-, inter-, im-) 与各种零散词根组合而成的高频词汇。

- **impractical**: /ɪmˈpræktɪk(ə)l/ = im + practical = × + 实践的 ==a.不切实际的;不现实的==
- **lobby**: /ˈlɑːbi/ = lob + by = 门廊 + 经由 ==v.游说 n.游说(团体);门厅==
- **lottery**: /ˈlɑːtəri/ = lot + t + ery = 运气 + n.“大乐透” ==n.彩票;碰运气的事==
- **intricate**: /ˈɪntrɪkət/ = in + tric + ate = 进入 + 三(琐碎) + a. ==a.错综复杂的==
- **investigate**: /ɪnˈvestɪɡeɪt/ = in + vestig + ate = 进入 + 踪迹 + v. ==v.调查;研究==
    - **investigation**: ==n.调查研究==
- **internal**: /ɪnˈtɜːrn(ə)l/ = intern + al = 中间 + a. ==a.内部的==
- **interior**: /ɪnˈtɪriər/ = inter + ior = 里面 + a. ==a.内部的 n.内部==
- **illuminate**: /ɪˈluːmɪneɪt/ = il + lumin + ate = to + 光 + v. ==v.照射;阐明==
- **infrared**: /ˌɪnfrəˈred/ = infra + red = 下 + 红 ==a.n.红外线(的)==
- **interval**: /ˈɪntərv(ə)l/ = inter + val = 中间 + 同 wall 墙 ==n.间隔(时间和空间)==
- **interim**: /ˈɪntərɪm/ = inter + im = 中间 + a. ==a.暂时的临时的==
- **inhale**: /ɪnˈheɪl/ = in + hal + e = 里面 + 呼吸 ==v.吸入;吸气==
- **inside**: /ˌɪnˈsaɪd/ = in + side = 里 + 边 ==n.a.ad.prep.里边==
- **intrude**: /ɪnˈtruːd/ = in + trude = 里面 + 走跑(tr 系列) ==v.侵入==
- **irrigate**: /ˈɪrɪɡeɪt/ = ir + rig + ate = to + 浇水 + v. ==v.灌溉;冲洗(引申为使清晰)==
- **irritate**: /ˈɪrɪteɪt/ = irrit + ate = 愤怒 + v. ==v.刺激;激怒==
- **inland**: /ˈɪnlənd/ = in + land = 里面 + 地 ==a.ad.n.内陆的(地)==
