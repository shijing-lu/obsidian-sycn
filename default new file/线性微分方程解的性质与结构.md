**1) 齐次线性微分方程解的性质与结构**
对于二阶齐次线性微分方程 $y'' + p(x)y' + q(x)y = 0 (*)$
- **定理 1**：如果函数 $y_1(x)$ 与 $y_2(x)$ 是方程 $(*)$ 的两个解，则 $y = C_1y_1(x) + C_2y_2(x)$ 也是方程 $(*)$ 的解。其中 $C_1$ 和 $C_2$ 为任意常数。
- **定理 2**：如果函数 $y_1(x)$ 与 $y_2(x)$ 是方程 $(*)$ 的两个线性无关的解，那么 $y = C_1y_1(x) + C_2y_2(x)$ 是方程 $(*)$ 的通解，其中 $C_1$ 和 $C_2$ 为任意常数。

> **注**：$y_1(x)$ 与 $y_2(x)$ 线性无关 $\Leftrightarrow \frac{y_1(x)}{y_2(x)} 
eqC$(常数)。
