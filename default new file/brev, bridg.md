# **brev / bridg = 短**
> [!tip] 快速记忆
> **bridg**e（桥）缩短了两岸的距离。所以**brev**e 表示简短，abbreviate（缩写）就是把词变短。句子 in brief（简而言之）几乎每年阅读都会出现。
1. **bridge**: /brɪdʒ/ = bridg + e = 短 ===n.桥==
    - “桥缩短了两岸的距离”
2. **brief**: /briːf/ = brie + f = 短 ===a.简短的==
    - 【真题意群】in brief 简而言之
3. **abridge**: /əˈbrɪdʒ/ = a + bridg + e = to + 短 ===v.删节；缩短==
    - 同义：condense, curtail, diminish
4. **abbreviate**: /əˈbriːvieɪt/ = ab + briev + i + ate = to + 短 + v. ===v.缩写==
5. **abbreviation**: /əˌbriːviˈeɪʃ(ə)n/ = abbreviate + ion = 缩写 + n. ===n.缩写==
