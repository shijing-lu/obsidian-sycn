# **cit = 引用 唤起**

> [!tip] 快速记忆 
> **cit** 词根有“唤起、呼喊、引用”之意。比如 **excite** 是把情绪向外(ex)唤起(cit)，即“使激动、刺激”；**recite** 是再(re)次呼唤出来，即“背诵”。
- **excite**: /ɪk'saɪt/ = ex + cit + e = out + 唤起 ===v.刺激==
    - **excited**: /ɪk'saɪtɪd/ = ===a.激动的==
    - **exciting**: /ɪk'saɪtɪŋ/ = ===a.令人激动的==
    - **excitement**: /ɪk'saɪtmənt/ = ===n.兴奋;刺激==
- **recite**: /rɪ'saɪt/ = re + cit = 又 + 唤起 ===v.背诵==
    - **recital**: /rɪ'saɪt(ə)l/ = ===n.背诵==
- **citation**: ===n.引用==
