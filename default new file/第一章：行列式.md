行列式的性质：
1. 行列转置（值不变）
2. 行列对换（反号）
3. ~倍乘（值倍乘）
4. ~全为 0 | 两~成比例（值为0）
5. ~拆分（某~变，其他不变）
6. 某~乘法运算加到其他~上（值不变）
