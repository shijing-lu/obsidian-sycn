# **fract frag fric = 打碎**

> [!tip] 快速记忆 
> 词根带有明显的碎裂感。**fragile** 易碎的；**fragment** 碎片。

- **fragile**: /ˈfrædʒ(ə)l/ = frag + ile = 碎 + a. ==a.易碎的==
- **frail**: /freɪl/ = frail = 打碎 ==a.脆弱的;虚弱的==
- **friction**: /ˈfrɪkʃ(ə)n/ = fric + tion = 打碎 + n. ==n.摩擦;摩擦力==
- **fragment**: /ˈfræɡmənt/ = frag + ment = 打碎 + n. ==n.碎片==
- **fraction**: /ˈfrækʃ(ə)n/ = fract + ion = 碎 + n. ==n.部分==
- **fracture**: /ˈfræktʃər/ = fract + ure = 打碎 + n. ==n.破裂;骨折==
- **fruit**: /fruːt/ = fruit = 打破(果实外壳) ==n.水果;果实==
    - **fruitful**: /ˈfruːtf(ə)l/ = ==a.成果丰硕的;富饶的;多产的==
