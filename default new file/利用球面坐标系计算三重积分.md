直角坐标与球坐标变换关系为
$$ \begin{cases} x = r\sin\varphi\cos\theta \\ y = r\sin\varphi\sin\theta \\ z = r\cos\varphi \end{cases} $$
其中 $0 \le r < +\infty, 0 \le \theta \le 2\pi, 0 \le \varphi \le \pi$. 此时，体积元素 $dv = r^2 \sin\varphi dr d\theta d\varphi$. 空间区域
$$ \Omega: \begin{cases} \theta_1 \le \theta \le \theta_2 \\ \varphi_1 \le \varphi \le \varphi_2 \\ r_1(\theta,\varphi) \le r \le r_2(\theta,\varphi) \end{cases} $$
有
$$ \iiint_{\Omega} f(x,y,z)dv = \iiint_{\Omega} f(r\sin\varphi\cos\theta, r\sin\varphi\sin\theta, r\cos\varphi) r^2 \sin\varphi dr d\theta d\varphi $$
$$ = \int_{\theta_1}^{\theta_2} d\theta \int_{\varphi_1}^{\varphi_2} \sin\varphi d\varphi \int_{r_1(\theta,\varphi)}^{r_2(\theta,\varphi)} f(r\sin\varphi\cos\theta, r\sin\varphi\sin\theta, r\cos\varphi) r^2 dr $$

注：适用于球面坐标系计算的三重积分——
1) $\Omega$ 易于用球面坐标表示，例如球体（或部分球体）、锥体与球体圆锥体；
2) 被积函数含 $f(\sqrt{x^2+y^2})$ 或 $f(x^2+y^2)$.
