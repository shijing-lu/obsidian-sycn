# idea ideo = 思想
> [!tip] 快速记忆 
> 核心就是 **idea** (想法)。意识形态 (ideology) 也就是思想的集合；理想 (ideal) 则是思想中最完美的状态。

- **idea**: /aɪˈdiːə/ = idea = 思想 ==n.想法==
- **ideal**: /aɪˈdiːəl/ = ==a.理想的== (同 perfect)
    - **idealistic**: /ˌaɪdiəˈlɪstɪk/ = ==a.理想主义的==
    - **idealist**: = ==n.理想主义者==
    - **idealism**: /aɪˈdiːəlɪzəm/ = ==n.理想主义==
    - **idealization**: /aɪˌdiːələˈzeɪʃn/ = ==n.理想化==
- **ideology**: /ˌaɪdiˈɑːlədʒi/ = ==n.意识形态==
    - **ideological**: /ˌaɪdiəˈlɑːdʒɪk(ə)l/ = ==a.思想的;意识形态的==
