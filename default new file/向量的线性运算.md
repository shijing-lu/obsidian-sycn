# 向量的线性运算

向量有两种基本运算：**加法** 和 **数乘**。这两种运算合称线性运算。

## 加法

对应分量分别相加：

$$
\alpha \pm \beta = (a_1 \pm b_1,\ a_2 \pm b_2,\ \cdots,\ a_n \pm b_n)
$$

## 数乘

每个分量都乘以常数 $k$：

$$
k\alpha = (ka_1,\ ka_2,\ \cdots,\ ka_n)
$$

## 内积（点积）

两个同维向量对应分量乘积之和：

$$
\alpha \cdot \beta = \alpha^T \beta = a_1b_1 + a_2b_2 + \cdots + a_nb_n
$$

- $\alpha^T \alpha = 0 \iff \alpha = \mathbf{0}$
- 零向量与任何向量正交（内积为 0）

## 向量的长度（模）

$$
\|\alpha\| = \sqrt{\alpha^T \alpha} = \sqrt{a_1^2 + a_2^2 + \cdots + a_n^2}
$$

- $\|\alpha\| = 1$ 时称为 **单位向量**
- 将非零向量 $\alpha$ 化为单位向量的过程：$\frac{\alpha}{\|\alpha\|}$，称为**单位化**
