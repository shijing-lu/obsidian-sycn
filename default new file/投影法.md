1) **投影法（先一后二法）**：设 $\Omega: (x,y) \in D_{xy}, z_1(x,y) \le z \le z_2(x,y)$，即将 $\Omega$ 投影到 $xoy$ 平面，$D_{xy}$ 是 $\Omega$ 投影区域，在投影区域内任意一点做平行于 $z$ 轴的直线穿过 $\Omega$，分别与 $\Omega$ 接触和离开的面为 $z=z_1(x,y), z=z_2(x,y)$，则

$$
\iiint_{\Omega} f(x,y,z)dv = \iint_{D_{xy}} dxdy \int_{z_1(x,y)}^{z_2(x,y)} f(x,y,z) dz;
$$
