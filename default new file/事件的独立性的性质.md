**性质**：
   - 若事件 $A$ 与事件 $B$ 相互独立，则 $A$ 与 $\bar{B}$，$\bar{A}$ 与 $B$，$\bar{A}$ 与 $\bar{B}$ 亦相互独立。
   - 任意事件都与概率为 0 或 1 的事件相互独立。
   - 若 $0<P(A)<1$，$0<P(B)<1$，则 $A$ 与 $B$ 独立 $\Rightarrow A$ 与 $B$ 不互斥；$A$ 与 $B$ 互斥 $\Rightarrow A$ 与 $B$ 不独立。
     **注**：若不说明 $0<P(A)<1$，$0<P(B)<1$，则 $A$ 与 $B$ 是否独立和 $A$ 与 $B$ 是否互斥无必然联系。
