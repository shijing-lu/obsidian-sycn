# **fortun = 运气**
- **fortune**: /ˈfɔːrtʃən/ = fortun + e = 运气 + n. ==n.运气;大笔的钱==
    - **fortunate**: /ˈfɔːrtʃənət/ = ==a.好运的==
    - **unfortunate**: /ʌnˈfɔːrtʃənət/ = ==a.不幸的==
    - **fortunately**: /ˈfɔːrtʃənətli/ = ==ad.幸运地==
    - **unfortunately**: /ʌnˈfɔːrtʃənətli/ = ==ad.不幸地==
- **misfortune**: /mɪsˈfɔːrtʃən/ = mis + fortune = - + 运气 ==n.厄运灾难不幸==
