
**方法**：各分段区间用求导公式求导，分段点处用导数定义、导函数极限等方法求导。

**定理**：设 $f(x)$ 在 $x = x_0$ 处连续，且在该点某去心邻域可导，则若 $\lim_{x \to x_0^-} f'(x)$ 存在，则 $f'_-(x_0)$ 存在，且 $f'_-(x_0) = \lim_{x \to x_0^-} f'(x)$。（$x \to x_0^+$ 同理）若存在极限 $\lim_{x \to x_0^-} f'(x) = A$，则 $f'_-(x_0) = A$。

> **注**：若 $\lim_{x \to x_0^-} f'(x)$ 不存在，$f'_-(x_0)$ 可能存在也可能不存在，此时需用导数定义求 $f'_-(x_0)$。
