# **dom domin = 家里 → 主人**

> [!tip] 快速记忆 
> 词根 **dom / domin** 源自拉丁语，意思是“家、屋顶”，引申为“主人、统治”。比如 **domestic**（家里的、国内的）；**dominate**（做主人 → 支配、统治）。

- **domestic**: /də'mestɪk/ = dom + estic = 家里 + a. ==a.家庭的;国内的==
- **dormitory**: /'dɔ:rmətɔ:ri/ = ==n.宿舍==
- **domesticate**: /də'mestɪkeɪt/ = ==v.驯化==
    - **domestication**: = ==n.驯养;教化==
    - **domesticated**: /də'mestɪkeɪtɪd/ = ==a.家养的==
- **dome**: /doʊm/ = dom + e = 家里 ==n.穹顶==
- **dorm**: /dɔ:rm/ = dorm = 家 ==n.宿舍==
- **dormant**: /'dɔ:rmənt/ = dorm + ant = 家 + a. ==a.休眠的;暂停活动的==
- **domain**: /doʊ'meɪn/ = dom + ain = 家里/主人 + n. ==n.领域==
- **domicile**: /'dɑ:mɪsaɪl/ = dom + icile = 家 + n. ==n.住宅;居住地==
- **dominate**: /'dɑ:mɪneɪt/ = domin + ate = 主人 + v. ==v.支配;统治;占优势==
    - **domination**: = ==n.统治==
    - **dominant**: /'dɑ:mɪnənt/ = ==a.支配的;统治的;占优势的==
    - **predominant**: /prɪ'dɑ:mɪnənt/ = ==a.明显的;占主导地位的==
    - **dominance**: /'dɑ:mɪnəns/ = ==n.优势;支配地位==
- **dominion**: /də'mɪnjən/ = ==n.领地==
- **kingdom**: /'kɪŋdəm/ = king + dom = 王 + 家 ==n.王国;领域==
- **doom**: /du:m/ = dom = 主宰→注定 ==n.厄运;死亡 v.注定==
