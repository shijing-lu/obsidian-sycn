# **ident = same 同一**

> [!tip] 快速记忆 
> 核心是“一致、相同”。ID 卡 (identity card) 就是证明你是你自己的同一性凭证；两件物品一模一样就是 **identical**。

- **identify**: /aɪˈdentɪfaɪ/ = ident + ify = 同一 + v. ==v.认出;识别== (同 recognize, distinguish)
    - **identification**: /aɪˌdentɪfɪˈkeɪʃ(ə)n/ = ==n.认出;确认==
    - 【真题意群】an identification number 识别码
- **identity**: /aɪˈdentəti/ = ==n.一致;身份== (例: ~ card 身份证)
- **identical**: /aɪˈdentɪk(ə)l/ = ==a.同一的== (同 alike, duplicate)
- **item**: /ˈaɪtəm/ = ident 变形 = 一样“彼此间类似” ==n.条款;项目;一则==
