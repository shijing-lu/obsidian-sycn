# **habit hibit = 拥有 (have / hold)**

> [!tip] 快速记忆
>  这个词根和“拥有、占据”有关。**habit** (习惯)就是你长期拥有的行为模式；**inhabit** 就是在里面(in)占据/拥有地盘（居住）；**exhibit** 则是把拥有的东西拿出去(ex)给别人看（展览）。

- **habit**: /ˈhæbɪt/ = habit = 拥有 ==n.习惯==
    - 【真题意群】in the ~ of 有…的习惯
    - **habitat**: /ˈhæbɪtæt/ = ==n.栖息地==
    - **habitant**: /ˈhæbɪtənt/ = ==n.居住者==
    - **habitation**: /ˌhæbɪˈteɪʃn/ = ==n.居住;住宅==
- **inhabit**: /ɪnˈhæbɪt/ = in + habit = 里面 + 拥有 ==v.居住==
    - **inhabitant**: /ɪnˈhæbɪtənt/ = ==n.居民;栖息在某地的动物==
- **prohibit**: /prəˈhɪbɪt/ = pro + hibit = 提前 + 拥有 ==v.阻止==
    - 【真题意群】~/stop/discourage/prevent sb from doing; ban doing; forbid doing
    - **prohibition**: /ˌproʊɪˈbɪʃ(ə)n/ = ==n.阻止==
- **exhibit**: /ɪɡˈzɪbɪt/ = ex + hibit = out + 拥有 ==v.展览== (同 display)
    - **exhibition**: /ˌeksɪˈbɪʃ(ə)n/ = ==n.展览==
- **inhibit**: /ɪnˈhɪbɪt/ = in + hibit = × + 拥有 ==v.抑制;禁止==
- **behave**: /bɪˈheɪv/ = be + have(变体) = 状态 + 占有 ==v.表现;举止得体==
    - **behavior**: = ==n.行为;态度==
    - **misbehave**: /ˌmɪsbɪˈheɪv/ = mis + behave = × + 行为 ==v.行为不端;故障失灵==
