# **jur jurs just = 正义；审判**

> [!tip] 快速记忆 
> 核心含义是“法律、正义、判断”。**justice** 是正义，**judge** 是法官/审判，**injure** (伤害) 就是不(in)正义(jure)的行为。

- **injure**: /ˈɪndʒər/ = in + jure = × + 正义 ==v.伤害==
    - 【真题意群】injure one’s neck 伤到某人的脖子
    - **injury**: /ˈɪndʒəri/ = ==n.伤害==
    - **injured**: /ˈɪndʒərd/ = ==a.受伤的==
- **jury**: /ˈdʒʊri/ = jury = 正义 ==n.陪审团==
- **jurisdiction**: /ˌdʒʊrɪsˈdɪkʃ(ə)n/ = juris + dict + ion = 正义 + 说 + n. ==n.司法权;管辖权==
- **just**: /dʒʌst/ = ==ad.恰好;只是;仅仅;刚刚 a.公正的;合理的;正确的==
    - **justice**: /ˈdʒʌstɪs/ = just + ice = 正义 + n. ==n.正义==
    - 【真题意群】enjoy full justice 享受司法公正
    - **injustice**: /ɪnˈdʒʌstɪs/ = ==n.不正义==
    - **justify**: /ˈdʒʌstɪfaɪ/ = ==v.辩护==
    - **justification**: /ˌdʒʌstɪfɪˈkeɪʃ(ə)n/ = ==n.辩护==
- **adjust**: /əˈdʒʌst/ = ad + just = 去 + 正确 ==v.调整==
    - 【真题意群】adjust one’s way 调整某人的方法
    - **adjustment**: /əˈdʒʌstmənt/ = ==n.调整;适应==
- **prejudice**: /ˈpredʒədɪs/ = pre + jud + ice = 提前 + 审判 + n. ==n.偏见== without ~; preference
    - 【真题意群】a deep prejudice 严重的偏见
- **judge**: /dʒʌdʒ/ = judg + e = 审判 ==v.评判;审判 n.法官==
    - 【真题意群】judge a fact 判断事实
    - **judgement**: /'dʒʌdʒm(ə)nt/ = ==n.审判== (有没有 e 都可以)
    - 【真题意群】reserve one’s judgement 保留某人的判断
    - **judicial**: /dʒuːˈdɪʃəl/ = ==a.司法的;法庭的;公正明断的==
