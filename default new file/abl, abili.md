# abl, abili (能力)
>[!tip] 快速记忆
> 最基础的单词 **able**（能够）衍生出的词根。
- **able**: /ˈeɪb(ə)l/=abl+e=能+a.=a.==能…的== be ~ to do 
- **inability**: /əˈbɪləti/=n.==能力== the ~ to do 
- **inability**: /ˌɪnəˈbɪləti/=n.==无能无力== 
- **unable**: /ʌnˈeɪb(ə)l/=a.不能的 
- **disability**: /ˌdɪsəˈbɪləti/=dis+ability=×+能力=n.==无能力；残疾== 
- **disable**: /dɪsˈeɪb(ə)l/=v.==使丧失能力；使伤残==
