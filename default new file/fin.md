# **fin = 范围 终点/终结**

> [!tip] 快速记忆 
> 联想 **finish** (结束)。引申为“界限”。**define** 下定义就是划定界限；**finite** 则是有限的。

- **finish**: /fınıf/ = fin+ish = 终点+v. ==v.完成==
- **final**: /faın( )l/ = fin+al = 终点+a. ==a.最终的==
- **finance**: / fainæns/ = fin+ance = 终结+n.—“用来结算的东西” ==n.财政;金融;财务==
    - **fine**: /fain/ = ==n.罚款==
    - **financial**: /fai næn∫( ) / = ==a.财务的;金融的==
- **define**: /dı fain/ = de+fin+e = 加强+界限 ==v.下定义==
    - **definite**: / definǝt/ = ==a.明确的==
    - **definition**: / defi'nı∫n/ = ==n.定义==
    - **definitive**: /dı fınətıv/ = ==a.最终的;权威的== conclusive
- **finite**: / fainait/ = fin+ite = 范围+a. ==a.有限的==
    - **infinite**: / infinət/ = ==a.无限的==
- **confine**: /kən fain/ = con+fin+e = 加强+界限 ==v.限制;关禁闭==
    - **confinement**: /kən fainment/ = ==n.禁闭==
- **refine**: /rı faın/ = re+fin+e = 再+边界(突破极限) ==v.提炼;改善==
