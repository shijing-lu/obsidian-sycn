# **im(i)(a) = 相似**

> [!tip] 快速记忆 表示“相像”。照镜子看到的 **image** (镜像/图像) 总是和原物相似；大脑里模拟相似的画面就是 **imagine** (想象)；跟着别人做相似的动作就是 **imitate** (模仿)。

- **image**: /ˈɪmɪdʒ/ = imag + e = 相似 ==n.影像;形象;图像==
- **imagine**: /ɪˈmædʒɪn/ = imag + ine = 相似 + v. ==v.想象==
    - **imaginary**: /ɪˈmædʒɪneri/ = ==a.想象中的;虚构的==
    - **imagination**: /ɪˌmædʒɪˈneɪʃ(ə)n/ = ==n.想象==
    - **imaginative**: /ɪˈmædʒɪnətɪv/ = ==a.富于想象力的==
- **imitate**: /ˈɪmɪteɪt/ = imit + ate = 相似 + v. ==v.模仿==
