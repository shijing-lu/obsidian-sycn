# **line = 线 排**

> [!tip] 快速记忆 
> 线、排。**deadline** (死线/截止日期)；**outline** (外面的线，也就是轮廓)。

- **line**: /laɪn/ = line = 线 ==n.线==
- **deadline**: /ˈdedlaɪn/ = dead + line = 死 + 线 ==n.截止日期==
- **headline**: /ˈhedlaɪn/ = head + line = 头 + 排 ==n.标题==
- **outline**: /ˈaʊtlaɪn/ = out + line = 外面 + 线 ==n.轮廓 v.概述== (同 profile, brief)
- **underline**: /ˌʌndərˈlaɪn/ = under + line = 下面 + 线 ==v.强调== (同 underscore, highlight, emphasize)
- **airline**: /ˈerlaɪn/ = air + line = 空气 + 线 ==n.航线; 航空公司==
- **guideline**: /ˈɡaɪdlaɪn/ = guide + line = 指导 + 线 ==n.方针==
