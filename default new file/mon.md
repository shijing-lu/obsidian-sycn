# **mon = 警告**

> [!tip] 快速记忆
> 
> 具有“警告、提醒、显示”的含义。**monitor** 监控是为了警告危险；**demonstrate** 则是显示/论证给大家看。

- **monster**: /ˈmɑːnstər/ = mon + ster = 警告 + n. ==n.怪物==
    - **monstrous**: /ˈmɑːnstrəs/ = ==a.骇人听闻的；巨大的== (同 giant)
- **demonstrate**: /ˈdemənstreɪt/ = de + monstr + ate = 加强 + 显示 + v. ==v.论证== (同 display, show, prove)
    - **demonstration**: /ˌdemənˈstreɪʃ(ə)n/ = ==n.论证；示范==
- **monitor**: /ˈmɑːnɪtər/ = monit + or = 警告 + n. ==n.v.监控 n.班长==
- **monument**: /ˈmɑːnjumənt/ = mon + u + ment = 警告 + n. ==n.纪念碑==
- **summon**: /ˈsʌmən/ = sum + mon = 下 + 警告 ==v.传唤；召集==
- **sermon**: /ˈsɜːrmən/ = ser + mon = 上 + 警告 ==v.说教；布道==
- **money**: /ˈmʌni/ = mon + ey = 警告 + n. (第一个铸币厂在罗马的警告女神庙) ==n.钱==
    - **monetary**: /ˈmɑːnɪteri/ = mon + et + ary = 警告 + n. + a. ==a.货币的==
