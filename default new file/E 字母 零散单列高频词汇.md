# **E 字母 零散单列高频词汇**

> [!tip] 快速记忆
>  这一部分词汇虽不属于大组，但极其高频，经常作为考研阅读和各类考试的核心考点出现。

- **eager**: /'i:ɡər/ = “e“向外 out=望眼欲穿 ==a.热切的; 渴望的==
- **enable**: /ɪ'neɪb(ə)l/ = en + able = 进入 + 有能力的 ==v.使能够==
- **entire**: /ɪn'taɪər/ = en + tir + e = 进入 + 拉 ==a.全部的; 整体的==
- **exchange**: /ɪks'tʃeɪndʒ/ = ex + change = out + 交换 ==v.n.交换==
- **endeavor**: /ɪn'devər/ = en + deav + or = 进入 + 同 debt 债务 + n. ==n.v.努力==
- **extra**: /'ekstrə/ = extra = out ==ad.a.额外地(的); n.额外的东西==
    - **extreme**: /ɪk'stri:m/ = extre + m + e = out + m 表最高级 ==a.极端的==
    - **extremely**: /ɪk'stri:mli/ = ==ad.极端地==
- **embryo**: /'embrioʊ/ = em + bryo = 进入 + 膨胀 ==n.胚芽; 胚胎; 初期 a.胚胎的; 初期的==
- **embrace**: /ɪm'breɪs/ = em + brace = 进入 + 手臂 ==v.n.拥抱==
- **enlarge**: /ɪn'lɑ:rdʒ/ = en + large = 进入 + 大 ==v.扩大==
- **entitle**: /ɪn'taɪt(ə)l/ = en + title = 进入 + 标题 ==v.定名为……; 赋予权利==
- **encounter**: /ɪn'kaʊntər/ = en + counter = 进入 + 相对 ==v.n.遭遇==
- **engage**: /ɪn'ɡeɪdʒ/ = en + gage = 进入 + 承诺 ==v.使参与==
    - **engagement**: /ɪn'ɡeɪdʒmənt/ = ==n.订婚; 约定==
- **ethic**: /'eθɪk/ = eth + ic = 礼貌 + a. ==a.道德的; n.道德规范==
- **exterior**: /ɪk'stɪriər/ = ex + ter + ior = 外 + 方向 + 比较级 ==a.外部的; 外面的 n.外观==
- **external**: /ɪk'stɜ:rn(ə)l/ = ex + ter + nal = 外 + 方向 + a. ==a.外部的==
- **exotic**: /ɪɡ'zɑ:tɪk/ = exo + tic = out + a. ==a.外来的; 异国的; 奇怪的; 引人注目的==
- **endorse**: /ɪn'dɔ:rs/ = en + dorse = 使 + 背部“原指在支票背部签字确认, 即背书” ==v.背书; 支持==
