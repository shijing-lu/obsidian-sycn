
### 4. 解自由项为多项式、指数函数的二阶常系数线性非齐次微分方程

**类型一** 若 $f(x) = P_m(x)e^{rx}$，其中 $P_m(x)$ 是一个 $x$ 的 $m$ 次多项式，$r$ 是一个实数，令
$$y^* = x^k Q_m(x)e^{rx}$$

其中，$Q_m(x)$ 是系数待定的 $m$ 次多项式，$k$ 等于 $r$ 作为特征方程根的重数：

1) 当 $r\neq\lambda_1, r \neq \lambda_2$ 时，$k = 0$
2) 当 $r =\lambda_1, r \neq \lambda_2$ 时，$k = 1$
3) 当 $r = \lambda_1, r = \lambda_2$ 时，$k = 2$

> **注**：若非齐次项 $f(x) = P_m(x)$，只需把它看成 $f(x) = P_m(x)e^{0x}$，且 $r=0$ 的情形即可。


**类型二** 若 $f(x) = e^{\alpha x}[P(x)\cos\beta x + Q_m(x)\sin\beta x]$，其中 $P(x)$ 和 $Q_m(x)$ 分别 $x$ 的 $l$ 和 $m$ 次多项式，$\alpha$ 是一个实数，令 $y^* = x^k e^{\alpha x}[M_n(x)\cos\beta x + N_n(x)\sin\beta x], n = \max\{l, m\}$，其中，$M_n(x), N_n(x)$ 是系数待定的 $n$ 次多项式，$k$ 的取法如下：
1) 当 $\alpha \pm \beta i$ 不是特征根时，$k = 0$；
2) 当 $\alpha \pm \beta i$ 是特征根时，$k = 1$。

> **注：**
> 1) 若自由项 $f(x) = P(x)\cos\omega x + P_n(x)\sin\omega x$，只需看作 $\alpha = 0$ 的特殊情况即可；
> 2) 若自由项只有 $P(x)\cos\beta x$ 或 $P_m(x)\sin\beta x$ 之一，特解 $y^*$ 仍应设为 $y^* = x^k e^{\alpha x}[M_n(x)\cos\beta x + N_n(x)\sin\beta x], n = \max\{l, m\}$。
