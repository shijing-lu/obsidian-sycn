# **dur = 持续，持久**

> [!tip] 快速记忆 
> 核心意思是“持久、坚硬”。比如知名电池品牌南孚（Duracell）和杜蕾斯（Durex）的名字里都有 dur，强调持久耐用。

- **durable**: /'dʊrəb(ə)l/ = dur + able = 持久 + a. ==a.耐用的==
- **duration**: /dʊ'reɪʃ(ə)n/ = dur + ation = 持久 + n. ==n.持续时间==
- **during**: /'dʊrɪŋ/ = dur + ing = 持续 + prep. ==prep.在……期间==
- **endure**: /ɪn'dʊr/ = en + dur + e = 里面 + 持续 ==v.忍受==
    - **endurance**: /ɪn'dʊrəns/ = ==n.忍受;耐力==
