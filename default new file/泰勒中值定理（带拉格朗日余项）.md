设 $f(x)$ 在包含 $x_0$ 的区间 $(a, b)$ 内有直到 $n+1$ 阶的导数，在区间 $[a, b]$ 上有 $n$ 阶连续导数，则对任意 $x \in [a, b]$ 有

$$
f(x) = f(x_0) + \frac{f'(x_0)}{1!}(x - x_0) + \frac{f''(x_0)}{2!}(x - x_0)^2 + \cdots + \frac{f^{(n)}(x_0)}{n!}(x - x_0)^n + R_n(x)
$$

其中

$$
R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x - x_0)^{n+1} \quad (\xi \text{ 在 } x_0 \text{ 与 } x \text{ 之间})
$$

称为 **拉格朗日余项**。该展开式称为 $f(x)$ 在区间 $[a, b]$ 上带拉格朗日余项的 $n$ 阶泰勒公式。

当 $x_0 = 0$ 时，也称为 ** $n$ 阶麦克劳林公式**。

如果 $\lim_{n \to \infty} R_n(x) = 0$，则泰勒公式就转化为泰勒级数。
