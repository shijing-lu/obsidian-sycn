**定义 1** 设 $f(x)$ 在区间 $I$ 上连续，如果对于 $I$ 上任意两点 $x_1, x_2 \ (x_1 \neq x_2)$，恒有
$$
f\left(\frac{x_1 + x_2}{2}\right) < \frac{f(x_1) + f(x_2)}{2},
$$
则称 $f(x)$ 在 $I$ 上的图形是**(向上)凹的**（或 **凹**）。
