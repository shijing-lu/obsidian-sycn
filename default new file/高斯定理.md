**定理** 设空间有界闭区域 $\Omega$ 是由分片光滑的闭曲面 $\Sigma$ 所围成，若函数 $P(x,y,z), Q(x,y,z), R(x,y,z)$ 在 $\Omega$ 上有一阶连续偏导数，则
$$\oint\!\!\!\oint_{\Sigma} P dydz + Q dzdx + R dxdy = \iiint_\Omega \left( \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z} \right) dV$$
这里 $\Sigma$ 是 $\Omega$ 的整个边界曲面的外侧。
**注：**
1. 高斯公式表明，在空间闭区域 $\Omega$ 上的三重积分可以通过出闭区域 $\Omega$ 的边界曲面 $\Sigma$ 上的曲面积分来表达。
2. 当题目满足高斯公式使用条件时，可以直接使用高斯公式法。但是当不满足高斯公式的使用条件时，可以采用以下思路方法：
   3) 曲面 $\Sigma$ 不是封闭曲面时，采用**补面法**，补一张或者多张面，使其成为一张封闭曲面；
   4) 曲面 $\Sigma$ 是封闭曲面围成的空间有界区域 $\Omega$，但是 $P, Q, R$ 以及偏导数在其所围成的有界区域 $\Omega$ 上不连续，此时可以采用**挖洞法**，将不连续的点去除，使其满足高斯公式的条件。
