# **mob mot mov = 动**

> [!tip] 快速记忆 
> 核心是“移动 (move)”。**remote** 就是移到很远的地方（遥远的）；**mobile** 就是可移动的；**motor** 则是提供移动动力的马达。

- **move**: /muːv/ = mov + e = 动 ==v.移动；感动==
    - **motion**: /ˈmoʊʃ(ə)n/ = mot + ion = 动 + n. ==n.运动== (例: in ~ 运转中)
    - **movement**: /ˈmuːvmənt/ = move + ment = 动 + n. ==n.运动== (强调特征: 匀速运动、政治运动)；【真题意群】new artistic movement 新艺术运动
- **motivate**: /ˈmoʊtɪveɪt/ = mot + iv(e) + ate = 动 + a. + v. ==v.促动== (同 stimulate, activate)
    - **motivation**: /ˌmoʊtɪˈveɪʃ(ə)n/ = ==n.动力==；【真题意群】have a strong motivation 有强烈的动机
    - **motivated**: /ˈmoʊtɪveɪtɪd/ = ==a.积极的；有动机的==
- **motive**: /ˈmoʊtɪv/ = ==a.运动的 n.动机== (同 incentive, intention)
- **emotion**: /ɪˈmoʊʃ(ə)n/ = e + mot + ion = out + 移动 + n.“内心喷薄而出的” ==n.情感==
    - **emotional**: /ɪˈmoʊʃən(ə)l/ = ==a.情绪的==
- **promote**: /prəˈmoʊt/ = pro + mot + e = 向前 + 移动 ==v.提升；提拔==
    - 【真题意群】promote unity and trust 促进团结和信任
    - **promotion**: /prəˈmoʊʃ(ə)n/ = ==n.提升；提拔==
- **remove**: /rɪˈmuːv/ = re + mov + e = 加强 + 移动 ==v.移走==
    - **removal**: /rɪˈmuːv(ə)l/ = ==n.移走==
    - **removable**: /rɪˈmuːvəbl/ = ==a.可移动的==
- **remote**: /rɪˈmoʊt/ = ==a.遥远的（时间和空间都可）==
    - 【真题意群】a remote area 偏远地区
- **motor**: /ˈmoʊtər/ = mot + or = 移动 + n. ==n.马达；汽车==
    - 【真题意群】ride a motor vehicle 骑机动车
    - **motorcycle**: /ˈmoʊtərsaɪk(ə)l/ = ==n.摩托车==
- **mobile**: /ˌmoˈbil/ = mob + ile = 动 + a. ==a.可移动的；流动的==
    - 【真题意群】update a mobile phone 更新移动电话
    - **mobilize**: /ˈmoʊbəlaɪz/ = ==v.调动；动员==
    - **mobility**: = ==n.流动性==
- **motto**: /ˈmɑːtoʊ/ = mot + to = 动 + n. ==n.座右铭，格言==
- **automobile**: /ˈɔːtəməbiːl/ = auto + mob + ile = 自动 + 动 ==n.汽车== (同 motor)
- **demote**: /diːˈmoʊt/ = de + mot + e = 向下 + 移动 ==v.降级==
    - **demotion**: = ==n.降级==
- **mob**: /mɑːb/ = mob = 移动 ==v.暴徒 v.包围围攻== (原文词性标注有两个 v.，结合语境通常为 n.暴徒 v.围攻)
