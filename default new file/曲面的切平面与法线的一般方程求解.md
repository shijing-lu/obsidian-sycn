
1. **一般方程**：设曲面 $\Sigma$ 的方程为 $F(x,y,z)=0$，$M(x_0,y_0,z_0)$ 为曲面 $\Sigma$ 上一点，设 $F(x,y,z)$ 的偏导数在该点连续且不同时为零. 则 $\Sigma$ 在点 $M(x_0,y_0,z_0)$ 处的

2) **法向量**：$\vec{n} = (F_x(x_0,y_0,z_0), F_y(x_0,y_0,z_0), F_z(x_0,y_0,z_0))$

3) **法线方程**：
   $$ \frac{x - x_0}{F_x(x_0,y_0,z_0)} = \frac{y - y_0}{F_y(x_0,y_0,z_0)} = \frac{z - z_0}{F_z(x_0,y_0,z_0)} $$

4) **切平面方程**：
   $$ F_x(x_0,y_0,z_0)(x - x_0) + F_y(x_0,y_0,z_0)(y - y_0) + F_z(x_0,y_0,z_0)(z - z_0) = 0 $$
