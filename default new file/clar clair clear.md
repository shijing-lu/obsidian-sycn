# **clar clair clear = 清楚**
> [!tip] 快速记忆 
> 核心词是大家都认识的 **clear**（清楚的）。含有 clar/clair 的词都和“清楚、明白、声明”有关。**declare** 就是让你清清楚楚地知道，即“宣布、声明”。
- **clear**: /klɪr/ = clear = 清楚 ===a.清楚的 v.清除;使干净==
- **clarify**: /'klærəfaɪ/ = ===v.澄清;阐明==
    - 【真题意群】 clarify one's position 澄清某人的立场
    - **clarity**: /'klærəti/ = ===n.清楚==
    - **clarification**: ===n.澄清;说明==
- **declare**: /dɪ'kler/ = de + clar + e = 加强 + 清楚 ===v.宣布==
    - 【真题意群】 declare the importance 声明重要性
    - **declaration**: /ˌdeklə'reɪʃn/ = ===n.宣布==
