# **mon(o) = 单一**

> [!tip] 快速记忆
> 
> **mono** 前缀代表“一、单一”。

- **monarch**: /ˈmɑːnərk/ = mon + arch = 单一 + 拱形（统治） ==n.君主==
    - **monarchy**: /ˈmɑːnərki/ = ==n.君主政体==
- **hierarchy**: /ˈhaɪərɑːrki/ = hier + arch + y = 神圣 + 统治 ==n.分层；等级制度==
- **monocracy**: /məˈnɑːkrəsi/ = mono + cracy = 单一 + 权力；统治 ==n.独裁政治==
    - **democracy**: ==n.民主政治== (相对立)
- **monopoly**: /məˈnɑːpəli/ = mono + poly = 单一 + 卖 ==n.垄断；垄断者==
