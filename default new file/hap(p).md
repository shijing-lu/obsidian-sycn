# **hap(p) = 运气**

> [!tip] 快速记忆 
> 与“运气、偶然发生”有关。**happen** 就是碰运气发生的事；**happy** 就是因为好运气（惊喜）带来的开心。

- **happen**: /ˈhæpən/ = happ + en = 运气 + v. ==v.碰巧发生==
    - 【真题意群】~ to do 碰巧做某事
- **happy**: /ˈhæpi/ = happ + y = 运气(惊喜) + a. ==a.高兴的==
    - 【真题意群】be ~ with
    - **happiness**: = ==n.幸福==
    - **unhappy**: /ʌnˈhæpi/ = ==a.不幸福的;不开心的==
- **perhaps**: /pərˈhæps/ = per + hap + s = 全部 + 运气 ==ad.也许== (同 possibly, maybe)
- **mishap**: /ˈmɪshæp/ = mis + hap = × + 运气 ==n.不幸== (同 misfortune)
- **haphazard**: /hæpˈhæzərd/ = hap + hazard = 运气 + 游戏 ==a.偶然的==
