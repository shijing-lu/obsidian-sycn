# **fend fens fenc (及 forc fort) = 打击 / 力量**

> [!tip] 快速记忆 
> 核心意思是“打击 (strike)”。防守 **defend** 就是把打过来的东西击退；冒犯 **offend** 则是主动去打击别人。**fort/forc** 则是衍生出的“力量”含义。

- **defend**: /dɪˈfend/ = de + fend = x + 打击 ==v.防御==
    - **defence**: /dɪˈfens/ = ==n.防卫==
    - **defensive**: /dɪˈfensɪv/ = ==a.防御性的==
- **offence**: /əˈfens/ = of + fenc + e = 对面 + 打击 ==n.冒犯==
    - **offend**: /əˈfend/ = ==v.冒犯==
    - **offender**: /əˈfendər/ = ==n.冒犯者==
- **fence**: /fens/ = fenc + e = 防御 ==n.栅栏==
- **effort**: /ˈefərt/ = ef + fort = out + 力量 ==n.努力==
- **comfort**: /ˈkʌmfərt/ = com + fort = 共同 + 力量 ==n.舒适==
    - **comfortable**: /ˈkʌmftəbl/ = ==a.舒适的==
    - **uncomfortable**: /ʌnˈkʌmftəb(ə)l/ = ==a.不舒适的==
    - **discomfort**: /dɪsˈkʌmfərt/ = ==n.不舒适;不安 v.使不安苦恼==
- **workforce**: /ˈwɜːrkfɔːrs/ = work + forc + e = 工作 + 力量 ==n.劳动力;全体职员==
