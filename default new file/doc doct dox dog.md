# **doc doct dox dog = 教**

> [!tip] 快速记忆 
> 跟“教导、证明、学说”有关。**doctor** 最初的意思其实是“传授知识的人（学者/博士）”，后来才引申为医生；**document**（文件）原本指用来证明或传授信息的材料。

- **dock**: /dɑːk/=dock=教导===n.码头==
- **doctor**: /'dɑ:ktər/ = doct + or = 教 + 人 ==n.博士;医生==
- **doctrine**: /'dɑ:ktrɪn/ = doct + rine = 教 + n. ==n.教条;学说==
- **document**: /'dɑ:kjumənt/ = docu + ment = 教(传授) + n. ==n.文件;文献==
    - **documentary**: /ˌdɑ:kju'mentri/ = ==a.文献的; n.纪录片==
- **dogma**: /'dɔ:ɡmə/ = dog + ma = 教条 + n. ==n.教条;教义==
- **orthodox**: /'ɔ:rθədɑ:ks/ = ortho + dox = 正确 + 教 ==a.正统的;传统的==
- **paradox**: /'pærədɑ:ks/ = para + dox = 旁边(相悖) + 教 ==n.悖论;自相矛盾的人或事==
