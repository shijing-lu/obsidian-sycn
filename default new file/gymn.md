# **gymn = 赤裸的**

> [!tip] 快速记忆 
> **gymn** 源自古希腊语，因为古希腊人在进行体育锻炼和竞技时，习惯赤裸着身体，所以该词根代表“赤裸的”。引申出来的 **gym** 就是大家挥洒汗水的健身房。

- **gymnastics**: /dʒɪmˈnæstɪks/ = gymn + as + tics = 赤裸的 + 体育技术 ==n.体操==
    - 【真题意群】learn gymnastics 学习体操
- **gym**: /dʒɪm/ = gym(n)的缩写 = 赤裸身体锻炼的地方 ==n.健身房;体育馆==
    - 【真题意群】go to the gym 去健身房
- **gymnasium**: /dʒɪmˈneɪziəm/ = gymn + asium = 赤裸锻炼的场所 ==n.体育馆;健身房==
