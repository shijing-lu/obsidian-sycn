# **duc duct = 引导**

> [!tip] 快速记忆 词根 **duc/duct** 表示“引导 (lead)”。**produce**（生产）就是向前(pro)引导出来；**reduce**（减少）则是往回(re)引；**educate**（教育）是把人向外(e)引导出好的方向。

- **introduce**: /ˌɪntrə'du:s/ = intro + duc + e = 里面 + 引导 ==v.引进;介绍==
    - **introduction**: /ˌɪntrə'dʌkʃ(ə)n/ = ==n.引进;介绍==
- **produce**: /prə'du:s/ = pro + duc + e = 向前 + 引导 ==v.引起;使产生==
    - **product**: /'prɑ:dʌkt/ = ==n.产品==
    - **production**: /prə'dʌkʃn/ = ==n.生产;产量==
    - 【真题意群】 raise production costs 增加生产成本
    - **producer**: /prə'du:sər/ = ==n.生产者;制片人==
    - **productive**: /prə'dʌktɪv/ = ==a.多产的==
    - **byproduct**: /'baɪprɑ:dʌkt/ = ==n.副产品;副作用==
    - **productivity**: /ˌproʊdʌk'tɪvəti/ = ==n.生产力==
- **reproduce**: /ˌri:prə'du:s/ = re + produce ==v.复制;再现;繁殖
- **reduce**: /rɪ'du:s/ = re + duc + e = 往回 + 引导 ==v.减少;降低==
    - 【真题意群】 reduce pollution
    - **reduction**: /rɪ'dʌkʃ(ə)n/ = ==n.下降
- **conduct**: /kən'dʌkt/ = con + duct = 加强 + 引导 ==v.指导;组织进行==
    - 【真题意群】 conduct a study 实
    - **conduction**: /kən'dʌkʃn/ = ==n.传导
    - **conductor**: /kən'dʌktər/ = ==n.指导者
    - 【真题意群】 an austrian conductor 一位
    - **semiconductor**: /'semɪkəndʌktər/ = ==n.半导体
- **educate**: /'edʒukeɪt/ = e + duc + ate = 向外 + 引导 + v. ==v.教育==
    - 【真题意群】 educate sb. to do sth. 教育
    - **education**: /ˌedʒu'keɪʃ(ə)n/ = ==n教育
    - **educational**: /ˌedʒu'keɪʃən(ə)l/ = ==a.教育的
    - **educator**: /'edʒukeɪtər/ = ==n.教育工作者
    - 【真题意群】 according to an educator 据一位
- **induce**: /ɪn'du:s/ = in + duc + e = 里面 + 引导 ==v.引诱==
- **deduct**: /dɪ'dʌkt/ = de + duct = 向下 + 引导 ==v.扣除,减去==
- **deduce**: /dɪ'du:s/ = de + duc + e = 向下 + 引导 ==v.演绎;推理==
    - **deduction**: /dɪ'dʌkʃ(ə)n/ = ==n演绎
- **conducive**: /kən'du:sɪv/ = con + duc + ive = 加强 + 引导 + a. ==a.有助于;有益于==
