假设函数在区间 $[0,l]$ 满足收敛定理的条件，先对函数 $f(x)$ 进行奇（偶）延拓，然后再将奇（偶）延拓后的函数展开成正弦级数和余弦级数。

1) **奇延拓**：令
$$ F(x) = \begin{cases} f(x), & 0 < x \le l \\ -f(-x), & -l \le x < 0 \\ 0, & x=0 \end{cases} $$
$f(x)$ 展开成正弦级数：$f(x) \sim \sum_{n=1}^{\infty} b_n \sin \frac{n\pi x}{l}, \quad x \in [0,l]$，其中
$$ b_n = \frac{2}{l} \int_{0}^{l} f(x) \sin \frac{n\pi x}{l} dx (n=1,2,3,\cdots) $$

> 注：若原函数 $f(0) 
eq 0$，奇延拓时也应修改定义为 $F(0)=0$。

2) **偶延拓**：令
$$
F(x) = \begin{cases}
f(x), & 0 \le x \le l \\
f(-x), & -l \le x < 0
\end{cases}
$$

$f(x)$ 展开成余弦级数：$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} a_n \cos \frac{n\pi x}{l}, \quad x \in [0,l]$。其中
$$
a_n = \frac{2}{l} \int_{0}^{l} f(x) \cos \frac{n\pi x}{l} dx \quad (n=1,2,3,\cdots)
$$
