# **lax leas = 松**

> [!tip] 快速记忆 
> 松开、放松。**relax** (放松)；**release** (再松开，即释放)。

- **lax**: /læks/ = lax = 松 ===松懈的；松弛的；不严格的；放纵的==
- **relax**: /rɪˈlæks/ = re + lax = 反复 + 松 ==v 休息，放松
    - **relaxation**: = ==n.放松; 消
    - **relaxed**: /rɪˈlækst/ = ==a.轻松的; 
- **lease**: /liːs/ = leas + e = 松开 ==v.出租 n.租约== (例: on ~; rent; l
- **release**: /rɪˈliːs/ = re + lease = 反复→加强 + 松开 ==v.释放、发布
- **lay**: /leɪ/ = lay = 松弛 ==v.躺下; 放下; 使平息
- **lazy**: /ˈleɪzi/ = ==a.懒惰的;
- **delay**: /dɪˈleɪ/ = de + lay = ! + 松弛 ==v.n.
- **lose**: /luːz/ = lease = 松开 ==v.松开；失去
- **relish**: /ˈrelɪʃ/ = re + lish = 后 + 松开 ==v.品味；享受；期待
