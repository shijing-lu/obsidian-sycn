**方向余弦**：
$$
\left\{
\begin{matrix}
\cos\alpha = \dfrac{a_x}{|\boldsymbol{a}|} = \dfrac{a_x}{\sqrt{a_x^2 + a_y^2 + a_z^2}} \\[10pt]
\cos\beta = \dfrac{a_y}{|\boldsymbol{a}|} = \dfrac{a_y}{\sqrt{a_x^2 + a_y^2 + a_z^2}} \\[10pt]
\cos\gamma = \dfrac{a_z}{|\boldsymbol{a}|} = \dfrac{a_z}{\sqrt{a_x^2 + a_y^2 + a_z^2}}
\end{matrix}
\right.
$$
称为向量 $\boldsymbol{a} = (a_x, a_y, a_z)$ 的方向余弦。

**注**：
1) 向量 $(\cos\alpha, \cos\beta, \cos\gamma)$ 是与 $\boldsymbol{a}$ 同方向的单位向量 $\boldsymbol{e}$。
2) $\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$
