# **her hes = stick 粘**

> [!tip] 快速记忆 
> 核心是“粘连、附着”。**hesitate** (犹豫)就像脚底粘住走不动；**adhere** (坚持)就是紧紧粘着目标；**inherent** (内在的)则是天生就粘在你骨子里的。

- **hesitate**: /ˈhezɪteɪt/ = hes + it + ate = 粘着 + 走 + v.—“反复在一个地方走” ==v.踌躇;犹豫==
    - 【真题意群】~ about; ~ to do
    - **hesitant**: /ˈhezɪtənt/ = ==a.踌躇的;迟疑的== (be ~ about)
    - **hesitance**: = ==n.犹豫不确定==
    - **hesitation**: /ˌhezɪˈteɪʃ(ə)n/ = ==n.不愿;犹豫==
- **cohesive**: /koʊˈhiːsɪv/ = co + hes + ive = 共同 + 粘 + a. ==a.统一的;团结的==
- **adhere**: /ədˈhɪr/ = ad + her + e = to + 粘 ==v.粘附;坚持==
    - 【真题意群】~/stick to
    - **adherence**: /ədˈhɪrəns/ = ==n.遵守;坚持;忠诚==
- **coherent**: /koʊˈhɪrənt/ = co + her + ent = 共同 + 粘 + a. ==a.连贯的;条理清晰的==
- **inherent**: /ɪnˈherənt/ = in + her + ent = 里面 + 粘 + a. ==a.内在的;固有的== (nature genius)
- **heir**: /er/ = heir = 粘 ==n.继承人==
    - **heritage**: /ˈherɪtɪdʒ/ = herit + age = 粘(留下来) + n. ==n.遗产==
    - **heredity**: = ==n.遗传==
    - **heritable**: = ==a.可遗传的;可继承的==
    - **inherit**: = ==v.继承==
