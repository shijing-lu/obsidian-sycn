# **mod = 模式**

> [!tip] 快速记忆 
> 核心是“模式 (mode)、模型”。引申出“调整使其符合模式”的动作。

- **model**: /ˈmɑːd(ə)l/ = mod + el = 模式 + n. ==n.模型；模特==
- **module**: /ˈmɑːdʒuːl/ = mod + ule = 模式 + n. ==n.模块；组件==
- **modest**: /ˈmɑːdɪst/ = mod + est = 模式 + a. ==a.谦虚的== (同 humble)
    - 【真题意群】a modest expectation 适度的期待
- **modern**: /ˈmɑːdərn/ = mod + ern = 模式 + a. ==a.现代的==
    - 【真题意群】modern art 现代艺术
    - **modernization**: = ==n.现代化==
- **modify**: /ˈmɑːdɪfaɪ/ = mod + ify = 模式 + v. ==v.修改；缓和==
    - **modification**: = ==n.修改；缓和==
- **mode**: /moʊd/ = mod + e = 模式 ==n.模式== (同 manner, pattern, style)
- **moderate**: /ˈmɑːdərət/ = mod + er + ate = 模式 + v. ==v.缓和 a.适度的；中等的==
    - **moderately**: = ==ad.适度地；普通地==
- **accommodate**: /əˈkɑːmədeɪt/ = ac + com + mod + ate = to + 加强 + 模式 + v. ==v.调整→提供住处== (引申狭义含义，来了客人一定要调整；同 adapt, suit, tailor, regulate, adjust)
    - **accommodation**: /əˌkɑːməˈdeɪʃ(ə)n/ = ==n.住处==；【真题意群】an accommodation agency 房屋经销处
- **modem**: /ˈmoʊdəm/ = mod + em = 模式 + n. ==n.调制解调器==
    - 【真题意群】modem road design 调制解调器线路设计
- **commodity**: /kəˈmɑːdəti/ = com + mod + ity = 同样 + 模式 + n.“市场上商品的重要特征之一标准化” ==n.商品== (同 goods, merchandise)
- **outmoded**: /ˌaʊtˈmoʊdɪd/ = out + mod + ed = 过 + 模式 + a. ==a.过时的== (同 outdated)
- **modulate**: /ˈmɑːdʒəleɪt/ = mod + ul + ate = 模式 + v.“使符合模式” ==v.调整== (同 adjust, adapt)
- **remodel**: /ˌriːˈmɑːd(ə)l/ = re + model = 再 + 模式 ==v.重构==
- **mood**: /muːd/ = 同 mode=思想的模式 ==n.心情；情绪；气氛==
- **mould**: /moʊld/ = mould = 模式 ==n.模具；性格 v.用模子做==
