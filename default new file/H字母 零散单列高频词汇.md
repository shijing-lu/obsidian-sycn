# **H 字母 单列高频词汇**

> [!tip] 快速记忆 
> 这些是极其高频且具有重要真题价值的核心独立词汇。

- **herb**: /ɜːrb/ = herb = 草 ==n.香草;药草==
    - 【真题意群】plant herbs 种植香草
- **heroic**: /həˈroʊɪk/ = hero + ic = 英雄 + a. ==a.英雄的;英勇的==
- **harbor**: /ˈhɑːrbər/ = har + bor = 军队 + 匿藏 ==n.海港==
- **hardly**: /ˈhɑːrdli/ = hard + ly = 坚硬 + ad. ==ad.几乎不==
- **hire**: /ˈhaɪər/ = “H”象形栅栏围墙=进入工作 ==v.n.雇佣==
- **historical**: /hɪˈstɔːrɪk(ə)l/ = histor + ical = 历史 + a. ==a.历史(学)的==
- **historic**: /hɪˈstɔːrɪk/ = histor + ic = 往事 + a. ==a.历史著名的;有历史意义的==
- **honorable**: /ˈɑːnərəbl/ = honor + able = 荣誉 + a. ==a.可敬的;光荣的==
- **horizon**: /həˈraɪz(ə)n/ = “H”象形栅栏围墙=界限 ==n.地平线;眼界视野;范围==
- **household**: /ˈhaʊshoʊld/ = house + hold = 家 + 持有 ==n.一家人 a.家庭的==
- **humor**: /ˈhjuːmər/ = hum + or = 湿 + n.—“古代认为人体的液体代表心情” ==n.幽默==
- **hurricane**: /ˈhɜːrəkeɪn/ = 演化词=玛雅神话中的雷暴与旋风之神胡拉坎 ==n.飓风==
- **housework**: /ˈhaʊswɜːrk/ = house + work = 家 + 工作 ==n.家务==
- **highlight**: /ˈhaɪlaɪt/ = high + light = 高 + 光 ==v.强调突出==
- **hitherto**: /ˌhɪðərˈtuː/ = hither + to = 到这里 + 到 ==ad.迄今为止==
