# **junct join = 连接**

> [!tip] 快速记忆 
> 核心意思是“连接 (join)”。**join** 加入；**conjunction** 是连词；**junction** 就是相交连接的接合点/枢纽。

- **join**: /dʒɔɪn/ = join = 连接 ==v.加入==
    - **joint**: /dʒɔɪnt/ = ==n.结合处;关节 a.共同的联合的==
- **conjunction**: /kənˈdʒʌŋkʃ(ə)n/ = con + junct + ion = 共同 + 连接 + n. ==n.结合;连词==
    - **conjunctive**: /kənˈdʒʌŋktɪv/ = ==a.连接的==
    - **disjunctive**: /dɪsˈdʒʌŋktɪv/ = ==a.分离的==
- **junction**: /ˈdʒʌŋkʃ(ə)n/ = junct + ion = 连接 + n. ==n.连接;接合点==
- **adjoin**: /əˈdʒɔɪn/ = ad + join = to + 连接 ==v.毗邻==
    - **adjoining**: /əˈdʒɔɪnɪŋ/ = ==a.毗邻的==
