# **fore = 前**

> [!tip] 快速记忆 
> 前缀 fore- 直接表示“在前面、提前”。

- **fore**: /fɔːr/ = fore = 前 ==n.前面部分 a.ad.(在)前面(的)==
- **forth**: /fɔːrθ/ = for + th = 前 ==ad.向前;向外;自……以后==
- **foremost**: /ˈfɔːrmoʊst/ = fore + most = 前面 + 最 ==a.最重要的;最前的 ad.首先==
- **forehead**: /ˈfɔːrhed/ = fore + head = 前 + 头 ==n.额头==
- **foreshadow**: /fɔːrˈʃædoʊ/ = fore + shadow = 前 + 影子(先看见了影子) ==n.v.预兆==
- **foresee**: /fɔːrˈsiː/ = fore + see = 前 + 看 ==v.预见==
- **forefather**: /ˈfɔːrfɑːðər/ = fore + father = 前 + 爹 ==n.祖先==
