# **grad(i)(u) = 迈步**

> [!tip] 快速记忆 
> 表示步伐、级别。一步步来，就是 **gradual** (逐渐的)，迈出校园的大步就是 **graduate** (毕业) 。

- **grade**: /ɡreɪd/ = grad + e = 迈步 ==v.分级 n.等级==
- **gradual**: /ˈɡrædʒuəl/ = ==a.逐渐的==
    - 【真题意群】the gradual change 逐渐变化
    - **gradually**: /ˈɡrædʒuəli/ = ==ad.渐渐==
- **degrade**: /dɪˈɡreɪd/ = de + grade = 向下 + 迈步 ==v.使退化==
- **graduate**: /ˈɡrædʒuət/ = gradu + ate = 迈步 + v. ==v.毕业 n.毕业生==
    - 【真题意群】a college graduate 大学毕业生
    - **graduation**: /ˌɡrædʒuˈeɪʃ(ə)n/ = ==n.毕业==
    - 【真题意群】a graduation ceremony 毕业典礼
- **postgraduate**: /ˌpoʊstˈɡrædʒuət/ = ==a.研究生的 n.研究生==
- **undergraduate**: /ˌʌndərˈɡrædʒuət/ = ==n.本科生==
- **centigrade**: /ˈsentɪɡreɪd/ = cent + i + grade = 百分 + 迈步(刻度) ==a.摄氏度的==
- **upgrade**: /ˈʌpɡreɪd/ = up + grade = 上 + 走 ==v.使升级;改善;提拔==
- **degree**: /dɪˈɡriː/ = de + gree = 加强 + 迈步 ==n.程度;学位;度数==
- **retrograde**: /ˈretrəɡreɪd/ = retro + grad + e = 往回 + 迈步 ==v.退步==
