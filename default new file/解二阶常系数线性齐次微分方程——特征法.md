### 3. 解二阶常系数线性齐次微分方程 —— 特征法

形如 $y'' + py' + qy = 0$，其中 $p, q$ 为常数，特征方程为 $\lambda^2 + p\lambda + q = 0$，按照特征根 $\lambda_1, \lambda_2$ 的三种不同情形对应二阶常系数齐次线性方程通解的三种形式：

(1) 当特征根 $\lambda_1 \neq \lambda_2$，微分方程的通解 $y = C_1e^{\lambda_1 x} + C_2e^{\lambda_2 x}$。

(2) 当特征根 $\lambda_1 = \lambda_2$，微分方程的通解 $y = (C_1 + C_2x)e^{\lambda_1 x}$。

(3) 当特征根为共轭复根 $\alpha \pm \beta i$，微分方程的通解 $y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x)$。
