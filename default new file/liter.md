# **liter = 文字**

> [!tip] 快速记忆 
> 字母、文字。**literature** (文学)；**illiterate** 就是没有(il)文字能力的文盲。

- **literature**: /ˈlɪtərətʃər/ = liter + ature = 文字 + n. ==n.文学==
    - 【真题意群】a degree in literature 文学专业学位
    - **literary**: /ˈlɪtəreri/ = ==a.文学的==
    - 【真题意群】a literary magazine 文学杂志
- **literacy**: /ˈlɪtərəsi/ = ==n.识字; 有文化==
    - **literate**: /ˈlɪtərət/ = ==a.受过教育的== (同 educated)
    - **literally**: /ˈlɪtərəli/ = ==ad.逐字地; 照字面地==
- **illiteracy**: /ɪˈlɪtərəsi/ = ==n.文盲; 无知==
    - **illiterate**: /ɪˈlɪtərət/ = ==a.文盲的==
- **literal**: /ˈlɪtərəl/ = liter + al = 文字 + a. ==a.文字的; 不夸张的==
- **obliterate**: /əˈblɪtəreɪt/ = ob + liter + ate = 对面 + 文字 + v. ==v.涂抹掉== (同 delete, eliminate)
- **delete**: /dɪˈliːt/ = de + let + e = × + 文字(同音同形) ==v.删除==
