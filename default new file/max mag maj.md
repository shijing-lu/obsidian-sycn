# **max mag maj = 大**

> [!tip] 快速记忆
> 
> 核心含义是“大、最大”。**maximum** (最大值)；**major** (主要的、大的)。

- **maximum**: /ˈmæksɪməm/ = maxi + m + um = 大 + n. ==a/n.最大量（的），最大限度（的）==
    - 【真题意群】with maximum effort 尽最大努力
- **major**: /ˈmeɪdʒər/ = maj + or = 大的 + a. ==a.大的；主要的==
    - 【真题意群】a major company 大公司
    - **majority**: /məˈdʒɔːrəti/ = ==n.大部分；大多数==
    - 【真题意群】the majority of peaple 大部分人
- **majesty**: /ˈmædʒəsti/ = maj + est + y = 大 + 最高级 a. + n. ==n.主权；陛下；庄严==
    - **majestic**: /məˈdʒestɪk/ = ==a.宏伟的；壮丽的==
- **magnify**: /ˈmæɡnɪfaɪ/ = magn + ify = 大 + v. ==v.放大；赞美==
- **magnitude**: /ˈmæɡnɪtuːd/ = magn + i + tude = 大 + n. ==n.巨大；重要性；量级==
- **magistrate**: /ˈmædʒɪstreɪt/ = magi + strate = 大 + n. ==n.地方官员；治安官==
- **master**: /ˈmæstər/ = mas + ter = 大 + n. ==n.主人；大师 v.掌握；精通==
    - **mistress**: /ˈmɪstrəs/ = mistr + ess = master + 女性 ==n.主妇；女主人==
    - **miss**: /mɪs/ = 缩写自 mistress=女士 ==n.女士；小姐==
- **mayor**: /ˈmeɪər/ = ma + yor = 大 + n. ==n.市长==
- **dismay**: /dɪsˈmeɪ/ = dis + ma + y = × + 大 + n. ==n.惊恐；焦虑 v.使惊愕；使失望==
