- **必要条件**：若 $(x_0, f(x_0))$ 为拐点，且 $f''(x_0)$ 存在，则 $f''(x_0) = 0$。
- **充分条件 1**：若 $f'(x)$ 在 $x = x_0$ 连续，在 $\overset{\circ}{U}(x_0, \delta)$ 内二阶可导，且 $f''(x)$ 在 $x = x_0$ 两侧异号，则 $(x_0, f(x_0))$ 为曲线的拐点。
- **充分条件 2**：若 $f'(x)$ 在 $x_0$ 三阶可导，$f''(x_0) = 0$，$f'''(x_0) \neq 0$，则 $(x_0, f(x_0))$ 为拐点。
- **推广的充分条件**：
设在 $x_0$ 处 $n$ 阶可导的函数 $f(x)$ 满足
$$
- f'(x_0) = f''(x_0) = \cdots = f^{(n-1)}(x_0) = 0, \quad f^{(n)}(x_0) \neq 0
 $$ 则
 若 $n$ 为奇数，$(x_0, f(x_0))$ 是 $y = f(x)$ 的**拐点**；若 $n$ 为偶数，则 $x = x_0$ 是**极值点**。

 > **注**：若曲线 $y = f(x)$ 光滑（处处可导），则其极值点与拐点不重合。
