1) 当 $f(x)$ 为 $[-l,l]$ 上可积的奇函数，$f(x) \sim \sum_{n=1}^{\infty} b_n \sin \frac{n\pi x}{l}$。

其中，$b_n = \frac{2}{l} \int_{0}^{l} f(x) \sin \frac{n\pi x}{l} dx (n=1,2,3,\cdots)$，即傅里叶级数为正弦级数。

2) 当 $f(x)$ 为 $[-l,l]$ 上可积的偶函数，$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} a_n \cos \frac{n\pi x}{l}$。

其中，$a_n = \frac{2}{l} \int_{0}^{l} f(x) \cos \frac{n\pi x}{l} dx (n=0,1,2,\cdots)$，即傅里叶级数为余弦级数。
