**泊松定理**：设 $\lambda>0$ 是一个常数，$n$ 是任意正整数，设 $\lambda=np_n$，则对于任意固定的非负整数 $k$ 有
   $$
   \lim_{n\rightarrow\infty} P\{X=k\}=\lim_{n\rightarrow\infty} C_n^k p_n^k(1-p_n)^{n-k}\approx\frac{(np_n)^k}{k!} e^{-np_n}\quad(k=0,1,2,\cdots)
   $$
   **注**：
   - 一般当 $n$ 很大 $(n\geq 20)$，$p$ 很小 $(p\leq 0.05)$ 时，二项分布 $B(n,p)$ 用泊松分布作近似效果较好。
