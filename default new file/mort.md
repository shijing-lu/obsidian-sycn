# **mort = 死亡**

> [!tip] 快速记忆
> 
> 核心是“死亡”。**immortal** 就是不(im)死(mort)的，即不朽的。

- **mortal**: /ˈmɔːrt(ə)l/ = mort + al = 死 + a. ==a.致命的；凡人的；总有一死的 n.人类；凡人==
    - **immortal**: /ɪˈmɔːrt(ə)l/ = ==a.不朽的==
- **mortality**: /mɔːrˈtæləti/ = ==n.死亡数；死亡率==
- **mortgage**: /ˈmɔːrɡɪdʒ/ = mort + gage = 死亡 + 承诺 ==n.抵押贷款 v.抵押==
- **murder**: /ˈmɜːrdər/ = murd(mort) + er = 死 + v. ==v.n.谋杀==
