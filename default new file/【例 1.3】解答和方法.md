## 证明套路（含导数 $f'(x)$ 的单中值 $\xi$ 等式）
**第一步：化简**  
将各项移至等号一侧，去分母，化为 $F'(\xi) = 0$ 的形式。
由
$$
\frac{f(\xi) - f(a)}{b - \xi} = f'(\xi)
$$
得
$$
f(\xi) - f(a) = f'(\xi)(b - \xi)
$$
移项：
$$
f(\xi) - f(a) - f'(\xi)(b - \xi) = 0
$$
即
$$
f'(\xi)(b - \xi) - f(\xi) + f(a) = 0
$$
**第二步：构造辅助函数**  
观察 $f'(\xi)(b - \xi) - f(\xi)$，它是 $[(b - x) f(x)]' = -f(x) + (b - x) f'(x)$ 的形式。
令
$$
F(x) = (b - x) f(x) + f(a) (x - a)
$$
则
$$
F'(x) = -f(x) + (b - x) f'(x) + f(a)
$$
且 $F(a) = (b - a) f(a) + 0 = (b - a) f(a)$，$F(b) = 0 + f(a)(b - a) = (b - a) f(a)$，故 $F(a) = F(b)$。
由罗尔定理，存在 $\xi \in (a, b)$ 使 $F'(\xi) = 0$，即
$$
-f(\xi) + (b - \xi) f'(\xi) + f(a) = 0
$$
即
$$
(b - \xi) f'(\xi) = f(\xi) - f(a)
$$
故
$$
\frac{f(\xi) - f(a)}{b - \xi} = f'(\xi)
$$
证毕。
