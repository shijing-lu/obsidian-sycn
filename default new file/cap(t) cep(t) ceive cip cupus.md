# **cap(t) cep(t) ceive cip cup = 抓**

> [!tip] 快速记忆
> 
> **cap / cept / ceive** 这一组词根的核心动作是“抓、拿”。比如 **accept**（接受）拆分为 ac (to) + cept (抓)，即“去接纳”；**receive**（收到）拆分为 re (回) + ceive (拿)，即“拿回来”；**occupy**（占据）则是 oc (对面) + cupy (抓)，把对面的东西抓过来
- **accept**: /ək'sept/ = ac + cept = to + 抓住 ==v.接受==
    - **acception** = ==n.接受==
    - **acceptance**: /ək'septəns/ = ==n.接纳;赞同;容忍==
- **except**: /ɪk'sept/ = ex + cept = out + 拿 ==v.免除 prep.除……外==
    - **exception**: /ɪk'sepʃn/ = ==n.例外==
    - **exceptional**: /ɪk'sepʃən(ə)l/ = ==a.例外的;异常的;卓越的==
- **excerpt**: /ek'sɜ:rpt/ = ex + crept(cept 变体) = out + 抓住 ==n.v.摘录;选段==
- **receive**: /rɪ'si:v/ = re + ceive = 回 + 收取 ==v.收到;接收==
	- **receiver**: /rɪ'si:vər/ = re + ceive + er ==n.听筒;接收者==
    - **reception**: /rɪ'sepʃ(ə)n/ = ==n.接待==
    - **receptionist**: /rɪ'sepʃənɪst/ = ==n.接待员==
- **receipt**: /rɪ'si:t/ = re + ceipt = 拿回 ==n.收据==
    - 【真题意群】 provide sales receipt 提供销售额收据
- **recipient**: /rɪ'sɪpiənt/ = re + cip + ient = 回 + 抓 + 人 ==n.接受者;领奖人==
- **reciprocal**: /rɪ'sɪprək(ə)l/ = re + cip + rocal = 反复 + 抓 + a. ==a.互惠的;互利的==
- **occupy**: /'ɑ:kjupaɪ/ = oc + cupy = 对面 + 抓 ==v.占据;占领==
    - 【真题意群】 occupy the mountaintop 占领山顶
    - **occupation**: /ˌɑ:kju'peɪʃ(ə)n/ = ==n.占有;职业==
	    - 【真题意群】 people's occupations 人们的职业
- **deceive**: /dɪ'si:v/ = de + ceive = 离开 + 抓走 ==v.欺骗==
    - **deception**: /dɪ'sepʃ(ə)n/ = ==n.欺骗==
    - **deceptive**: /dɪ'septɪv/ = ==a.欺骗的==
    - **deceit**: /dɪ'si:t/ = de + ceit = 下 + 抓 ==n.欺骗;欺诈==
- **perception**: /pər'sepʃ(ə)n/ = per + cept + ion = 贯穿 + 抓住—“透过现象看本质” + n. ==n.察觉;感知==
	- **perceive**: /pər'si:v/ = per + ceive = 贯穿 + 拿 ==v.察觉;感知==
- **capture**: /'kæptʃər/ = capt + ure = 抓 + n. ==n.v.俘虏==
- **capable**: /'keɪpəb(ə)l/ = cap + able ==a.能干的;能胜任的==
	- **capability**: /ˌkeɪpə'bɪləti/ = cap + ability ==n.能力==
- **captious**: /'kæpʃəs/ = capt + ious = 抓(错处) + a. ==a.吹毛求疵的==
- **cable**: /'keɪb(ə)l/ = cab(cap) + le = 抓 + n. ==n.电缆;缆绳==
- **capsule**: /'kæps(j)u:l/ = caps + ule = 抓 + n. ==n.(药物)胶囊;太空舱==
    - 【真题意群】 put sth. inside a capsule 把某物放在胶囊里
- **concept**: /'kɑ:nsept/ = con + cept = 共同 + 抓着 ==n.概念;设想==
    - 【真题意群】 a fixed concept 固化的观念
- **participate**: /pɑ:r'tɪsɪpeɪt/ = parti + cip + ate = 部分 + 拿 + v. ==v.参加==
- **escape**: /ɪ'skeɪp/ = es + cap + e = 向外 + 抓捕 ==n.逃跑 v.逃跑==
    - 【真题意群】 escape from punishment 逃脱惩罚
- **recipe**: /'resəpi/ = re + cip + e = 回 + 拿 + n.“引申为拿取处方、做法” ==n.食谱;方法==
    - 【真题意群】 use a recipe to cook 使用食谱做饭
- **conceive**: /kən'si:v/ = con + ceive = 加强 + 捕捉(想法) ==v.构思==
- **incept**: /ɪn'sept/ = in + cept = 进入 + 抓“开始掌权” ==v.开始;就职==
    - **inception**: /ɪn'sepʃ(ə)n/ = ==n.开端==
- **anticipate**: /æn'tɪsɪpeɪt/ = anti + cip + ate = 前面 + 抓 + v. ==v.预感;期望==
- **discipline**: /'dɪsəplɪn/ = dis + cip + line = 分开 + 抓 + (线)n. ==n.纪律;学科 v.训练==
- **susceptible**: /sə'septəb(ə)l/ = sus + cept + ible = 下 + 抓住 + a. ==a.易受影响的;易受感染的==
