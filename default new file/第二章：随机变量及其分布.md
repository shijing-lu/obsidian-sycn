分布律的充要条件：
   - $p_k \geq 0, \quad k=1,2,\cdots$
   - $\sum_{k=1}^{\infty} p_k = 1$

**加深理解**：
1) 只有离散型随机变量才有分布律吗？有分布律的一定是离散型随机变量吗？
   **答**：是的。只有离散型随机变量才有分布律；有分布律的一定是离散型随机变量。
2) 离散型随机变量的分布函数有何特点？只有离散型分布函数才有此特点吗？
   **答**：离散型随机变量的分布函数是阶梯函数，在 $X$ 的可能取值点处有跳跃间断点。只有离散型随机变量的分布函数才有此特点。

### 随机变量函数 $Y=g(X)$ 的分布
**离散型随机变量函数的分布**：设离散型随机变量 $X$ 的分布律为 $P\{X=x_k\}=p_k,\ (k=1,2,\cdots,n)$，则求 $Y=g(X)$ 的概率分布，步骤如下：
   - 计算 $Y$ 所有可能取到的值 $y_1, y_2, \cdots, y_k$；
   - 计算 $Y$ 取到 $y_1, y_2, \cdots, y_k$ 的概率。
