
1) 如果把 $x$ 和 $y$ 对调后，积分区域 $\Omega$ 不变，则

$$
\iiint_{\Omega} f(x,y,z)dv = \iiint_{\Omega} f(y,x,z)dv
$$

同理可得三重积分 $x$ 与 $z$，$y$ 与 $z$ 的轮换对称性.

2) 若积分区域 $\Omega$ 关于 $x,y,z$ 有轮换对称性（即用 $y$ 替换 $x$，$z$ 替换 $y$，$x$ 替换 $z$ 后，对调后，积分区域 $\Omega$ 不变），则

$$
\iiint_{\Omega} f(x,y,z)dv = \iiint_{\Omega} f(y,z,x)dv = \iiint_{\Omega} f(z,x,y)dv
$$

注：若积分区域 $\Omega$ 关于 $x,y,z$ 有轮换对称性，即解析式中 $x,y,z$ 的“地位平等”，

则有 $\iiint_{\Omega} f(x)dv = \iiint_{\Omega} f(y)dv = \iiint_{\Omega} f(z)dv = \frac{1}{3}\iiint_{\Omega} [f(x)+f(y)+f(z)]dv$.
