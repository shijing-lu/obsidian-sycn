## 根式代换

被积函数含 $\sqrt{ax+b}$，令 $t = \sqrt{ax+b}$，则 $x = \frac{1}{a}(t^2 - b)$，$dx = \frac{2t}{a} dt$。

---

## 3）倒代换

当被积函数分母的最高次数高于分子的最高次数时，可试用倒代换令 $x = \frac{1}{t}$，则 $dx = -\frac{1}{t^2} dt$。
