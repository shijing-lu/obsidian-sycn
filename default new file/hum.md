# **hum = 地**

> [!tip] 快速记忆 
> 古人认为“人是泥土捏的”，所以 **human** (人) 来自泥土(hum)；把自己放低到泥土里就是 **humble** (谦卑)。

- **human**: /ˈhjuːmən/ = hum + an = 地 + n. ==n.人类==
    - **humane**: /hjuːˈmeɪn/ = human + e = 人“性善论” ==a.仁爱的;慈善的==
    - **humanity**: /hjuːˈmænəti/ = ==n.人性;人类;人文学科==
- **humble**: /ˈhʌmb(ə)l/ = hum + ble = 地 + a. ==a.谦逊的;低下的==
    - **humility**: /hjuːˈmɪləti/ = ==n.谦逊== (同 modesty)
    - **humiliate**: /hjuːˈmɪlieɪt/ = hum + iliate = 地 + v. ==v.羞辱==
- **humid**: /ˈhjuːmɪd/ = hum + is = 地 + a. ==a.潮湿的==
    - **humidity**: /hjuːˈmɪdəti/ = ==n.湿度==
- **hominid**: /ˈhɑːmɪnɪd/ = homin + id = 人 + n. ==n.原人;类人动物==
