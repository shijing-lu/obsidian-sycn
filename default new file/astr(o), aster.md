# astr(o), aster (星星)
> [!tip] 快速记忆
> 宇航员（**astro**naut）就是去探索星星的人。灾难（disaster）在古人看来是星位不正造成的。

- **astronaut**: /ˈæstrənɔːt/=astro+naut=星星+航行.=n.==宇航员==；【真题意群】send a astronaut into space 送宇航员进太空 
- **astronomy**: /əˈstrɑːnəmi/=n.==天文学==；【真题意群】an astronomy program 天文学 项目 
- **astronomer**: /əˈstrɑːnəmər/=n.==天文学家== 
- **disaster**: /dɪˈzæstər/=dis+aster=×+星星 “灾星降世”=n.==灾难；不幸== natural ~; catastrophe；【真题意群】a natural disaster 自然灾害 
- **disastrous**: /dɪˈzæstrəs/=a.==灾难性的；极糟糕的== 
- **desire**: /dɪˈzaɪər/=de+sire=加强+星星—“仰望星空”=n.v.==渴望== 
- **desirable**: /dɪˈzaɪərəb(ə)l/=desir+able=渴望+a.=a.==理想的；令人满意的；值得拥有的==
