# n 维向量的定义

向量是线性代数中最基本的研究对象——可以理解为"带方向的量"的推广。

## 定义

由 $n$ 个数 $a_1, a_2, \cdots, a_n$ 组成的有序数组，称为一个 **n 维向量**。

- **行向量**：$\alpha = (a_1, a_2, \cdots, a_n)$，即 $1\times n$ 矩阵
- **列向量**：$\alpha = \begin{pmatrix} a_1 \\ a_2 \\ \vdots \\ a_n \end{pmatrix}$，即 $n \times 1$ 矩阵

考研中如不特殊说明，默认视为 **列向量**。

## 直观理解

- 二维向量 $\begin{pmatrix} x \\ y \end{pmatrix}$ → 平面上的一个点/箭头
- 三维向量 $\begin{pmatrix} x \\ y \\ z \end{pmatrix}$ → 空间中的一个点/箭头
- n 维向量 → 抽象空间中的一个"点"

## 相关概念

- **零向量**：所有分量为 0，记作 $\mathbf{0}$
- **相等**：两个 n 维向量各对应分量都相等
- **负向量**：$-\alpha = (-a_1, -a_2, \cdots, -a_n)$
