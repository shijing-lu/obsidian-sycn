# **ball / bol = 抛，舞，球**
> [!tip] 快速记忆
> 玩球（**ball**）就是抛来抛去。symbol（象征）拆开是 sym（共同）+ bol（抛），把两个东西“抛在一起”联想，就成了象征——用一个东西代表另一个东西。
1. **ball**: /bɔːl/ = ball = 球 ===n.球；舞会==
2. **ballet**: /bæˈleɪ/ = ball + et = 舞 + 小 ===n.芭蕾舞==
    - “小型舞表演”
3. **balloon**: /bəˈluːn/ = ball + oon = 球 + n. ===n.气球==
4. **baseball**: /ˈbeɪsbɔːl/ = base + ball = 基础 + 球 ===n.棒球==
    - “建立基础打球——垒球”
5. **football**: /ˈfʊtbɔːl/ = foot + ball = 脚 + 球 ===n.足球==
6. **volleyball**: /ˈvɑːlibɔːl/ = volley + ball = 投掷 + 球 ===n.排球==
7. **symbol**: /ˈsɪmb(ə)l/ = sym + bol = 共同 + 抛 ===n.象征==
    - “把两个东西抛在一起联想”
