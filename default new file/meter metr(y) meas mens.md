# **meter metr(y) meas mens = 测量**

> [!tip] 快速记忆
> 
> 接上一部分的词根。核心是“测量、尺度”。**dimension** (尺寸)；**immense** (无法测量的，即极大的)。

- **dimension**: /daɪˈmenʃn; dɪˈmenʃn/ = di + mens + ion = 穿过 + 测量 + n. ==n.尺寸，尺度；维（数）；方面==
    - 【真题意群】add a further dimension 增加更多的方面
    - **dimensional**: ==a.空间的；尺寸的==
- **diameter**: /daɪˈæmɪtər/ = dia + meter = 穿过 + 测量 ==n.直径==
- **immense**: /ɪˈmens/ = im + mens + e = × + 测量 ==a.极大的；巨大的==
- **symmetry**: /ˈsɪmətri/ = sym + metry = with + 测量 ==n.对称==
    - **asymmetry**: ==n.不对称==
