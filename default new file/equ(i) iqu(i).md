# **equ(i) iqu(i) = 相等**

> [!tip] 快速记忆
>  这个词根和“平等、相同 (equal)”有关。**equal** 本身就是相等的；**equation** 就是两边相等的算式（等式）。

- **equal**: /'i:kwəl/ = equ + al = 相等 + a. ==a.相等的==
- **equivalent**: /ɪ'kwɪvələnt/ = ==a.等价的; n.等价物==
- **equation**: /ɪ'kweɪʒ(ə)n/ = ==n.等式==
- **equate**: /ɪ'kweɪt/ = ==v.同等看待; 相当于==
- **equality**: /i'kwɑ:ləti/ = ==n.同等, 平等==
- **inequality**: /ˌɪnɪ'kwɑ:ləti/ = ==n.不平等; 不平衡==
- **equip**: /ɪ'kwɪp/ = equi + p = 相等 ==v.配备==
    - **equipment**: /ɪ'kwɪpmənt/ = ==n.装备==
- **adequately**: = ==ad.充分地==
