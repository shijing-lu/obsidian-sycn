# **mount = 山**

> [!tip] 快速记忆
> 
> 核心是“山、往上增加”。**mountain** 是山脉，**surmount** 是爬到山上面去（战胜）。

- **mountain**: /ˈmaʊnt(ə)n/ = mount + ain = 山 + n. ==n.山脉==
    - **mountainous**: /ˈmaʊntənəs/ = ==a.多山的==；【真题意群】a mountainous region 多山的地区
- **mount**: /maʊnt/ = mount = 山 ==v.增加；上升== (同 soar, surge, increase)
- **amount**: /əˈmaʊnt/ = a + mount = 加强 + 增加 ==n.数量==
    - 【真题意群】a large amount 大量
- **surmount**: /sərˈmaʊnt/ = sur + mount = 上 + 山 ==v.战胜；在…之上== (同 overcome, defeat)
