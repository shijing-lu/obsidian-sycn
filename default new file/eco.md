# **eco = 家**

> [!tip] 快速记忆 希腊语的 eco 原意为家庭。**economy** 本意是管家（引申为经济、节约）；**ecology** 是研究地球这个大家庭的（生态学）。

- **economy**: /ɪ'kɑ:nəmi/ = eco + nomy = 家 + 管理 ==n.经济; 节约==
    - **economic**: /ˌi:kə'nɑ:mɪk/ = ==a.经济的; 经济学的==
    - **economics**: /ˌi:kə'nɑ:mɪks/ = ==n.经济学==
    - **economical**: /ˌi:kə'nɑ:mɪk(ə)l/ = ==a.经济的; 节约的; 节俭的==
    - **economically**: = ==ad.在经济上; 节约地==
- **ecology**: /i'kɑ:lədʒi/ = eco + logy = 家 + 学科 ==n.生态学==
