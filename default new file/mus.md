# **mus = 娱乐**

> [!tip] 快速记忆
> 
> 来源于缪斯女神 (Muse)，引申为音乐和娱乐。

- **musical**: /ˈmjuːzɪk(ə)l/ = mus + ical = 娱乐 + a. ==a.音乐的==
    - 【真题意群】musical work 音乐作品
- **amuse**: /əˈmjuːz/ = a + mus + e = 加强 + 娱乐 + v. ==v.使人快乐；逗乐==
    - **amusement**: /əˈmjuːzmənt/ = ==n.娱乐：娱乐活动==
    - 【真题意群】public amusement 公共娱乐
