- **定理 3**：设 $y^*(x)$ 是二阶非齐次线性方程 $y'' + p(x)y' + q(x)y = f(x)$ 的一个特解。$y(x) = C_1y_1(x) + C_2y_2(x)$ 是对应齐次方程 $y'' + p(x)y' + q(x)y = 0$ 的通解，则 $y = y(x) + y^*(x)$ 是二阶非齐次线性微分方程 $y'' + p(x)y' + q(x)y = f(x)$ 的通解。
- **定理 4（叠加原理）**：设非齐次线性方程的右端 $f(x)$ 是两个函数之和，即 $y'' + p(x)y' + Q(x)y = f_1(x) + f_2(x)$，而 $y_1^*(x)$ 与 $y_2^*(x)$ 分别是 $y'' + p(x)y' + Q(x)y = f_1(x)$ 与 $y'' + p(x)y' + Q(x)y = f_2(x)$ 的解，则 $y_1^*(x) + y_2^*(x)$ 是原方程的解。
