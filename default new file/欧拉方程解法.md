#### 2. 解法：
$x^2 y'' + p_1 xy' + p_2y = g(x)$ 为二阶欧拉方程，求通解方法如下：
(1) 当 $x > 0$ 时，令 $x = e^t$，有 $y' = \frac{dy}{dx} = \frac{1}{x}\frac{dy}{dt}$，$y'' = \frac{d^2y}{dx^2} = \frac{1}{x^2}\frac{d^2y}{dt^2} - \frac{1}{x^2}\frac{dy}{dt}$
(2) 代入方程，将原方程化为 $y''(t) + (p_1 - 1)y'(t) + p_2y(t) = g(e^t)$，即以 $t$ 为自变量的常系数线性方程，求出通解后，再把变量 $t = \ln x$ 回代即可。
