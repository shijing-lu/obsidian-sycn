# **fall fail fals fault = 错误**

> [!tip] 快速记忆 
> 代表跌倒、失败和错误。**fail** 是失败，**false** 是错误的/假的，**fault** 是过错。

- **fail**: /feɪl/ = fail = 错误 ==v.失败;衰弱==
    - **failure**: /ˈfeɪljər/ = ==n.失败==
- **fall**: /fɔːl/ = fall = 错误 ==v.下落;跌倒==
- **false**: /fɔːls/ = fals + e = 错误 ==a.错误的;假的==
- **fault**: /fɔːlt/ = fault = 错误 ==n.过错==
    - **faulty**: /ˈfɔːlti/ = ==a.有错误的;有缺点的==
- **default**: /dɪˈfɔːlt/ = de + fault = ! + 错误 ==v.违约;默认==
