# **fabl fabul fess = 说**

> [!tip] 快速记忆 
> 与“诉说、名声”相关。**professor** 就是在人前(pro)公开说(fess)的人（教授）；**fable** 是一代代说下来的寓言；**famous** 是大家都说的（著名的）。

- **profession**: /prəˈfeʃ(ə)n/ = pro + fess + ion = 向前 + 说 + n. ==n.职业==
    - **professional**: /prəˈfeʃən(ə)l/ = ==a.专业的 n.行业专家==
    - **professor**: /prəˈfesər/ = ==n.教授==
- **confess**: /kənˈfes/ = con + fess = 全部 + 说 ==v.承认;坦白==
    - **confession**: /kənˈfeʃ(ə)n/ = ==n.坦白;承认==
- **fable**: /ˈfeɪb(ə)l/ = fabl + e = 说 ==n.寓言==
- **fabulous**: /ˈfæbjələs/ = ==a.传说的;极好的==
- **affable**: /ˈæfəb(ə)l/ = af + fabl + e = to + 说 ==a.友善的==
- **famous**: /ˈfeɪməs/ = fame + ous = 说“名声” + a. ==a.著名的==
    - **fame**: /feɪm/ = ==n.名声;名誉==
- **fate**: /feɪt/ = fat + e = (神)说 ==n.命运==
    - **fatal**: /ˈfeɪt(ə)l/ = ==a.致命的;命中注定的==
- **fairy**: /ˈferi/ = fa + iry = 说 + n. ==n.仙子;小精灵==
