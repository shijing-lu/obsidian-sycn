**band / bond = 捆绑**
> [!tip] 快速记忆
> **band** 是乐队（被音乐“捆绑”在一起的一群人），也是带子。**bond**（纽带、契约）是更抽象的捆绑，a powerful bond（强有力的联结）这个短语在完形中可能出现。

- **band**: /bænd/ = band = 捆 ===n.乐队；带==
    - 【真题意群】a member of the band 乐队成员
- **bandage**: /ˈbændɪdʒ/ = band + age = 捆绑 + n. ===n.绷带==
- **bond**: /bɑːnd/ = bond = 捆 ===n.契约；联结 v.黏合==
    - 【真题意群】a powerful bond 强有力的结合
