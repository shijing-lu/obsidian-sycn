# **graph gram = 写画**
> [!tip] 快速记忆 
> 这组词根代表“写、刻画、画图”。**graph** 本身是图表，**grammar** 则是把写字的规范变成“语法” 。

- **graph**: /ɡræf/ = graph = 写 ==n.图表==
    - 【真题意群】read a graph 查看图表
- **gram**: /ɡræm/ = gram = 写(刻画内涵) ==n.克==
    - 【真题意群】weigh 500 grams 重量为 500 克
- **photograph**: /ˈfoʊtəɡræf/ = photo + graph = 光 + 写 ==v.拍照 n.照片==
    - 【真题意群】study a photograph 细看一张照片
    - **photographer**: /fəˈtɑːɡrəfər/ = ==n.摄影师==
    - 【真题意群】a gifted photographer 一位有天赋的摄影师
- **program**: /ˈproʊɡræm/ = pro + gram = 提前 + 写 ==n.程序;计划;大纲 v.编程==
    - **programmer**: /ˈproʊɡræmər/ = ==n.程序员==
- **grammar**: /ˈɡræmər/ = gram + mar = 写 + n. ==n.语法==
    - **grammatical**: /ɡrəˈmætɪkl/ = ==a.语法的==
- **diagram**: /ˈdaɪəɡræm/ = dia + gram = 穿过 + 书写内容 ==n.图表==
- **biography**: /baɪˈɑːɡrəfi/ = bio + graph + y = 生命 + 写 ==n.传记==
    - **biographer**: /baɪˈɑːɡrəfər/ = ==n.传记作者==
    - **biographical**: /ˌbaɪəˈɡræfɪkl/ = ==a.传记的==
- **paragraph**: /ˈpærəɡræf/ = para + graph = 旁边 + 写 ==n.段落==
    - 【真题意群】in the second paragraph 在第二段
- **telegram**: /ˈtelɪɡræm/ = tele + gram = 远、电 + 写 ==n.电报==
- **telegraph**: /ˈtelɪɡræf/ = tele + graph = 远 + 写 ==n.电报 v.用电报发==
