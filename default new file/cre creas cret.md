# **cre creas cret = 生长*
> [!tip] 快速记忆
> 
> 这个词根包含“生长、创造”的内涵。**create**（创造）即让新事物生长出来；**increase**（增加）即向内(in)不断生长(creas)；**concrete**（具体的/混凝土）即共同(con)生长(crete)凝固在一起
- **create**: /kri'eɪt/ = cre + ate = 生长 + v. ==v.创造==
- **creation**: /kri'eɪʃ(ə)n/ = cre + ation = 生长 + n. ==n.创造;产物==
- **creator**: /kri'eɪtər/ = cre + ator = 生长 + 人 ==n.创造者==
- **creative**: /kri'eɪtɪv/ = cre + ative = 生长 + a. ==a.有创造力的==
- **creature**: /'kri:tʃər/ = cre + ature = 生长 + n. ==n.创造物;生物;人==
- **creativity**: /ˌkri:eɪ'tɪvəti/ = creative + ity ==n.创造性;创造力==
- **procreate**: /'proʊkrieɪt/ = pro + cre + ate = 向前 + 生长 + v. ==v.生产;生育繁殖==
- **recreation**: /ˌrekri'eɪʃ(ə)n/ = re + cre + ation = 再 + 生长 + n.“消遣带来恢复的结果” ==n.消遣==
- **recreate**: /'rekrieɪt/ = re + cre + ate = 再 + 创造 ==v.再创造;消遣==
- **recreational**: /ˌrekri'eɪʃən(ə)l/ = recreation + al ==a.消遣的==
- **decrease**: /dɪ'kri:s/ = de + creas + e = 向下 + 生长 ==v.减少==
- **decreasing**: /dɪ'kri:sɪŋ/ = decrease + ing ==a.减少的==
- **decreasingly**: /dɪ'kri:sɪŋli/ = decreasing + ly ==ad.越来越少地==
- **increase**: /ɪn'kri:s/ = in + creas + e = 进入 + 生长 ==v.增加==
- **increasing**: /ɪn'kri:sɪŋ/ = increase + ing ==a.不断增加的==
- **increasingly**: /ɪn'kri:sɪŋli/ = increasing + ly ==ad.越来越多地==
- **concrete**: /'kɑ:nkri:t/ = con + crete = 共同 + 生长 ==n.混凝土 a.确实的,具体的==
    - 【真题意群】 concrete advice 具体的建议
- **crew**: /kru:/ = cre(w) = 一起发展的人 ==n.全体员工==
- **recruit**: /rɪ'kru:t/ = re + cru + it = 再 + 生长 + v. ==v.招募 n.新兵;新成员==
