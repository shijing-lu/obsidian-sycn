# **flect flex = 弯折**

> [!tip] 快速记忆 
> 核心动作是“弯曲、折叠”。**reflect** 是光线往回(re)折射(flect)；**flexible** 就是身体或规则能够弯折的（灵活的/柔韧的）。

- **reflect**: /rɪˈflekt/ = re + flect = 往回 + 弯折 ==v.反射;反思==
    - **reflection**: /rɪˈflekʃ(ə)n/ = ==n.反射;反思==
    - **reflective**: /rɪˈflektɪv/ = ==a.反光的;深思熟虑的==
- **flexible**: /ˈfleksəb(ə)l/ = flex + ible = 折 + a. ==a.灵活的;柔韧的==
    - **flexibility**: /ˌfleksəˈbɪləti/ = ==n.灵活性==
- **deflect**: /dɪˈflekt/ = de + flect = 加强 + 折 ==v.(使)偏转==
    - **deflection**: /dɪˈflekʃn/ = ==n.偏转==
    - **deflective**: /dɪˈflektɪv/ = ==a.偏转的==
