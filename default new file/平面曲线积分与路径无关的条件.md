设 $D$ 为单连通区域，$P(x,y),Q(x,y)$ 在 $D$ 上有连续一阶偏导数，则以下四命题等价：  
1. 对任意分段光滑封闭曲线 $C$，有 $\oint_C Pdx + Qdy = 0$；  
2. 曲线积分 $\int_L Pdx + Qdy$ 与路径无关；  
3. 恒有 $\boldsymbol{\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}}$；  
4. 存在二元函数 $u(x,y)$，使 $\boldsymbol{du(x,y) = P(x,y)dx + Q(x,y)dy}$  

### 注  
若 $D$ 内以 $A,B$ 为端点的逐段光滑曲线 $L$，积分 $\int_L Pdx + Qdy$ 仅与 $A,B$ 有关（与路径无关），则称该曲线积分与路径无关。
