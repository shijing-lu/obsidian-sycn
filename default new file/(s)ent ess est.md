# **(s)ent ess est = 存在**

> [!tip] 快速记忆 
> 表示“存在”。**present** 在你面前存在的（出席、现在）；**absent** 不存在的（缺席）；**essence** 存在的最深层（本质）。

- **absent**: /'æbsənt/ = ab + sent = 离开 + 存在 ==a.缺席的 v.使缺席==
    - **absence**: = ==n.缺席==; 【真题意群】in an absence of social skills 缺乏社会技能
- **present**: /'prez(ə)nt/ = pre + (s)ent = 在前面 + 存在 ==n.现在; 礼物 a.现在的 v.呈现==
    - **presentation**: /ˌpri:z(ə)n'teɪʃ(ə)n/ = ==n.呈现==; 【真题意群】interrupt a presentation 打断报告
    - **presence**: /'prez(ə)ns/ = ==n.存在; 出席; 风度==
    - **presently**: /'prez(ə)ntli/ = ==ad.目前; 不久==
- **interest**: /'ɪntrəst/ = inter + est = 相互 + 存在 ==n.兴趣; 利益; 利息 v.使感兴趣==
- **represent**: /ˌreprɪ'zent/ = re + pre + sent = 加强 + 前 + 存在 ==v.代表==; 【真题意群】represent new technology 代表新技术
    - **representative**: /ˌreprɪ'zentətɪv/ = ==n.代表 a.有代表性的==; 【真题意群】be representative of a trend 代表一种趋势
- **essential**: /ɪ'senʃ(ə)l/ = ess + ent + ial = 存在 + 存在 + a. ==a.必要的 n.本质; 必需品==
    
    - **essentially**: /ɪ'senʃəli/ = ==ad.本质上; 根本上==
- **essence**: /'es(ə)ns/ = ==n.本质==
- **entity**: /'entəti/ = ent + ity = 存在 + n. ==n.实体==
