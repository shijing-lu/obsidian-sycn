# **mini = 小**

> [!tip] 快速记忆 看到 mini 就联想“迷你、微小”。比如 **minimum** (最小值)，**minor** (较小的/次要的)。

- **mini**: /ˈmɪni/ = mini = 小 ==a.袖珍的==
- **minimize**: /ˈmɪnɪmaɪz/ = ==v.使最小化==
- **minimum**: /ˈmɪnɪməm/ = ==n.最小值== (反义 maximum；同量 quantity, tiny)
    - 【真题意群】the minimum requirements 最低要求
- **miniature**: /ˈmɪnətʃər/ = ==a.小型的微小的 n.微小模型==
- **minute**: /ˈmɪnɪt/ = min + ute = 小 + a. ==a.微小的；n.分钟== (例: up to the minute)
- **minor**: /ˈmaɪnər/ = min + or = 小 + a. ==a.低级的；较小的== (反义 major)
    - **minority**: /maɪˈnɔːrəti/ = min + or + ity = 小 + n. + n. ==n.少数；少数民族==；【真题意群】a minority of young people 少数年轻人
- **minus**: /ˈmaɪnəs/ = min + us = 小 + n. ==conj./prep./adj.减(的);减去 n.负号== (反义 plus)
    - 【真题意群】a minus number 负数
- **minister**: /ˈmɪnɪstər/ = mini + st + er = 小 + 站 + 人 ==n.大臣；部长== (例: the prime minister)
    - 【真题意群】the agriculture minister 农业部长
    - **ministry**: /ˈmɪnɪstri/ = ==n.部门==
- **administration**: /ədˌmɪnɪˈstreɪʃn/ = ad + ministr + ation = to + 部长 + n. ==n.管理==
    - **administer**: /ədˈmɪnɪstər/ = ==v.管理==
- **diminish**: /dɪˈmɪnɪʃ/ = di + min + ish = 离散 + 小 + v. ==v.使减少缩小；贬低==
- **prominent**: /ˈprɑːmɪnənt/ = pro + min + ent = 前 + 小 + a. ==a.突出的，显著的==
- **menu**: /ˈmenjuː/ = menu = 小“小而详细的列表” ==n.菜单==
- **menace**: /ˈmenəs/ = men + ace = 突出（小尖）+ n. ==n.v.威胁恐吓==
- **eminent**: /ˈemɪnənt/ = e + min + ent = out + 突出 + a. ==a.卓越的；杰出的==
