
若幂级数 $\sum_{n=0}^{\infty} a_n(x-x_0)^n$ 的每项都是幂函数，则称 $\sum_{n=0}^{\infty} a_n(x-x_0)^n$ 为**幂级数**。其一般形式为
$$ \sum_{n=0}^{\infty} a_n(x-x_0)^n = a_0 + a_1(x-x_0) + a_2(x-x_0)^2 + \cdots + a_n(x-x_0)^n + \cdots $$
称为 $x-x_0$ 处的幂级数，其中常数 $a_0, a_1, a_2, \cdots, a_n, \cdots$ 称为幂级数的**系数**。
** $x=0$ 时的幂级数为**
$$ \sum_{n=0}^{\infty} a_n(0-x_0)^n = a_0 + a_1(-x_0) + a_2(-x_0)^2 + \cdots + a_n(-x_0)^n + \cdots $$
