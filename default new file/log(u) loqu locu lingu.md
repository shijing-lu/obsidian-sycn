# **log(u) loqu locu lingu = 说 语言**

> [!tip] 快速记忆 
> 和“说话、语言”紧密相关。**dialogue** (对话)；**linguist** (语言学家)；**logic** (逻辑) 则是使语言表达合理的东西。

- **log**: /lɔːɡ/ = log = 说 ==n.记录; 日志 v.伐木; 记录==
- **catalogue**: /ˈkætəlɔːɡ/ = cata + logue = 下面 + 要说的话 ==n.目录== (同 content)
- **dialogue**: /ˈdaɪəlɔːɡ/ = dia + logue = 穿过 + 说话 ==n.对话== (同 conversation, talk)
- **apology**: /əˈpɑːlədʒi/ = apo + log + y = 离开 + 说话 ==n.道歉==
    - 【真题意群】owe sb. an apology 欠某人一个道歉
    - **apologize**: /əˈpɑːlədʒaɪz/ = ==v.道歉==
    - 【真题意群】apologize publicly 公开道歉
- **prologue**: /ˈproʊlɔːɡ/ = pro + logue = 前面说的话 ==n.序言; 开场白== (同 foreword, preface)
- **linguist**: /ˈlɪŋɡwɪst/ = lingu + ist = 语言 + n.人 ==n.语言学家==
    - **linguistics**: /lɪŋˈɡwɪstɪks/ = ==n.语言学== (同 statistics)
    - **linguistic**: /lɪŋˈɡwɪstɪk/ = ==a.语言的; 语言学的==
    - **bilingual**: /ˌbaɪˈlɪŋɡwəl/ = bi + lingu + al = 两个 + 语言 + a. ==a.双语的==
    - **multilingual**: /ˌmʌltiˈlɪŋɡwəl/ = ==a.多语的==
- **logic**: /ˈlɑːdʒɪk/ = log + ic = 说 + n.“使语言表达合理的东西” ==n.逻辑(学)==
    - **logical**: /ˈlɑːdʒɪk(ə)l/ = ==a.逻辑学的; 合理的==
    - **logician**: /ləˈdʒɪʃn/ = ==n.逻辑学家==
- **analogy**: /əˈnælədʒi/ = ana + log + y = 旁边 + 说 + n. ==n.类比; 比喻==
    - **analogous**: /əˈnæləɡəs/ = ==a.相似的==
- **eloquent**: /ˈeləkwənt/ = e + log + uent = out + 说 + a. ==a.雄辩的; 有说服力的==
