# **gen(e) gener geni(t) = 出生**

> [!tip] 快速记忆 
> 核心是生命的“产生、出生”。比如生来就有的优质属性就是 **genius** (天才)；同一时期出生的人就是 **generation** (一代人) 。

- **gene**: /dʒiːn/ = gene = 出生 ==n.基因==
    - **genetic**: /dʒəˈnetɪk/ = ==a.基因的;遗传的;起源的==
    - **genetics**: /dʒəˈnetɪks/ = ==n.遗传学==
- **generation**: /ˌdʒenəˈreɪʃ(ə)n/ = gener + ation = 出生 + n. ==n.一代人;产生==
    - 【真题意群】the young generation 年轻的一代
- **generous**: /ˈdʒenərəs/ = ==a.慷慨大方的==
    - 【真题意群】the generous subsidies 丰富的财政补贴
- **generate**: /ˈdʒenəreɪt/ = ==v.出生==
- **degenerate**: /dɪˈdʒenəreɪt/ = ==v.a.堕落(的);退化(的);恶化(的)==
- **genius**: /ˈdʒiːniəs/ = gen + i + us = 出生 + n. ==n.天赋;天才==
- **general**: /ˈdʒen(ə)rəl/ = gener + al = 出生 + a. ==a.普遍的;综合的;一般的==
    - **generally**: /ˈdʒen(ə)rəli/ = ==ad.一般意义上;通常上==
    - **generalize**: /ˈdʒen(ə)rəlaɪz/ = ==v.概括归纳;使一般化==
- **gentle**: /ˈdzent(e)l/ = gent + le = 出生(初生的无压力的活泼轻松的) ==a.温和的==
    - 【真题意群】a gentle cat 温柔的猫
    - **gentleman**: /ˈdzent(ə)lmən/ = ==n.绅士==
- **hydrogen**: /ˈhaɪdrədʒən/ = hydro + gen = 水 + 生成 ==n.氢==
- **oxygen**: /ˈɑːksɪdʒən/ = oxy + gen = 氧、酸 + 生成 ==n.氧气==
    - 【真题意群】burn up oxygen 燃烧氧气
- **engine**: /ˈendʒɪn/ = en + gin + e = 里面 + 同 gen,出生 ==n.发动机,引擎==
    - 【真题意群】a steam engine 蒸汽发动机
- **engineer**: /ˌendʒɪˈnɪr/ = en + gin + eer = 使 + 同 gen,产生 ==n.工程师;技工==
    - 【真题意群】work as an engineer 做工程师的工作
    - **engineering**: /ˌendʒɪˈnɪrɪŋ/ = ==n.工程(学)==
- **engender**: /ɪnˈdʒendər/ = en + gend + er = 进入 + 出生 ==v.产生;造成==
- **pregnant**: /ˈpregnənt/ = pre + gn + ant = 前 + 同 gen,出生 ==a.怀孕的;饱含的==
- **genuine**: /ˈdzenjuɪn/ = gen + u + ine = 出生 + a. ==a.真实的==
- **ingenious**: /ɪnˈdʒiːniəs/ = in + geni + ous = 里面 + 产生 ==a.聪明的;有创造力的==
- **genre**: /ˈʒɑːnrə/ = genre = 出生 ==n.类型==
- **gender**: /ˈdʒendər/ = gend + er = 出生 ==n.性别==
- **germ**: /dʒɜːrm/ = germ = 出生 ==n.微生物;细菌==
- **homogeneous**: /ˌhoʊməˈdʒiːniəs/ = homo + gene + ous = 同 + 出生 ==a.同性质的同类的==
- **nitrogen**: /ˈnaɪtrədʒən/ = nitro + gen = 硝石 + 出生 ==n.氮气==
