# **dec = 十 / 合适**

> [!tip] 快速记忆 
> 一是数字“十”（decade）；二是“合适、装饰”。

- **decade**: /'dekeɪd/ = dec + ade = 十 + n. ==n.十年==
- **decent**: /'di:snt/ = dec + ent = 合适 + a. ==a.体面的;正派的==
- **decorate**: /'dekəreɪt/ = dec + or + ate = 合适 + 状态 + v. ==v.装饰==
    - **decoration**: /ˌdekə'reɪʃ(ə)n/ = ==n.装饰;装饰品==
    - **decorative**: /'dekəreɪtɪv/ = ==a.装饰性的==
- **deck**: /dek/=deck=装饰===n.甲板 v.装饰==
