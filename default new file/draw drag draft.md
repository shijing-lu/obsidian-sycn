# **draw drag draft = 拉**

> [!tip] 快速记忆 
> “拉、拖拽”。**draw** 画画，其实就是笔尖在纸上拉出来的线条；**draft** 也是笔在纸上拉线，引申为“起草、草稿”。

- **draw**: /drɔ:/ = draw = 拉 ==v.拉;画;得出==
    - **drawer**: /drɔ:r/ = ==n.抽屉==
- **drag**: /dræɡ/ = drag = 拉 ==v.拉;拽;拖累==
- **draft**: /dræft/ = draft = 拉—“拉出的线条” ==n.草稿;气流 v.起草==
- **drawback**: /ˈdrɔːbæk/=draw+back=拉+回=n.==缺点；缩回== 
	- 【真题意群】regard sth.as a drawback 将某方面视为缺点 
- **withdraw**: /wɪðˈdrɔː/=with+draw=保留+拉=v.==收回== 
	- 【真题意群】 withdraw from one’s marriage 退出某人的婚姻
