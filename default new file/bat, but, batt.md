# **bat = 打击**
> [!tip] 快速记忆
> 蝙蝠侠（**Bat**man）打击犯罪。de**bat**e（争论）就是双方在语言上互相“打击”，**bat**tle（战斗）则是真正的打击。

1. **battle**: /ˈbæt(ə)l/ = batt + le = 打 + n. ===n.战斗==
    - 【真题意群】face a battle 面对战斗
2. **debate**: /dɪˈbeɪt/ = de + bat + e = 加强 + 打 ===v.n.争论==
    - 同义：a heated ~ ; dispute; argue
    - 【真题意群】debate about a topic 关于某主题的辩论
3. **abet**: /əˈbet/ = a + bet = to + 打 ===v.教唆（犯罪）；煽动怂恿==
4. **battery**: /ˈbætəri/ = batt + ery = 打击 + n. ===n.电池==
    - “形容电池放电过程中的电流的持续运动”
    - 【真题意群】a small nuclear battery 小型核电池
5. **button**: /ˈbʌt(ə)n/ = butt + on = 打 + n. ===n.按钮；纽扣 v.扣纽扣==
    - 【真题意群】button from the right 从右边扣纽扣
6. **bat**: /bæt/ = bat = 打击 ===n.（棒球/板球的）球棒；蝙蝠==
    - 【真题意群】a baseball bat 棒球球棒
7. **combat**: /ˈkɑːmbæt/ = com + bat = 共同彼此 + 打 ===v.与…搏斗==
    - 同义：~ with; fight
