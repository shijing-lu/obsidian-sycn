# **fl flu flux = 流动**

> [!tip] 快速记忆 
> 与水流相关。**fluent** (流利的) 是说话像流水一样；**influence** (影响) 是像水一样流进去潜移默化；**flood** (洪水)。

- **influence**: /ˈɪnfluəns/ = in + flu + ence = 里面 + 流 ==n.v.影响==
    - **influential**: /ˌɪnfluˈenʃ(ə)l/ = ==a.有影响力的 n.有影响力的人==
- **fluency**: /ˈfluːənsi/ = flu + ency = 流 + n. ==n.流畅==
    - **fluent**: /ˈfluːənt/ = ==a.流利的==
- **flood**: /flʌd/ = fl + ood = 流 + v. ==v.淹没;涌出 n.洪水==
- **flu**: /fluː/ = flu = 流 ==n.流行性感冒==
- **fluid**: /ˈfluːɪd/ = flu + id = 流 + a.n. ==a.流动的 n.流体==
- **flush**: /flʌʃ/ = flu + sh = 流 + v. ==v.冲刷;脸红==
- **affluent**: /ˈæfluənt/ = af + flu + ent = to + 流 + a. ==a.富裕的==
    - **affluence**: /ˈæfluəns/ = ==n.富裕==
- **superfluous**: /suːˈpɜːrfluəs/ = super + flu + ous = 超过 + 流 + a. ==a.多余的;不必要的==
- **overflow**: /ˌoʊvərˈfloʊ/ = over + flow = 上 + 流 ==v.溢出;充满 n.泛滥==
- **fluctuate**: /ˈflʌktʃueɪt/ = fluctu + ate = 流 + v. ==v.波动;涨落==
