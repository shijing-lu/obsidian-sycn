**【例 2.7】** 设区域 $D = \{(x, y) \mid x^2 + y^2 \leq 4, x \geq 0, y \geq 0\}$，$f(x)$ 为 $D$ 上的正值连续函数，$a, b$ 为常数，求
$$
I = \iint_D \frac{a\sqrt{f(x)} + b\sqrt{f(y)}}{\sqrt{f(x)} + \sqrt{f(y)}} d\sigma.
$$
