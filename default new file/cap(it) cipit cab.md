# **cap(it) cipit cab = head 头**
> [!tip] 快速记忆
> 
> 词根 **cap** 演变自帽子（戴在头上），由此引申为“头、首脑”。例如 **capital**（首要的城市 = 首都 / 首要的资金 = 资本）；**captain**（军队或团队的“头” = 首领、队长）；**chief**（主要负责的“头”）。
- **cap**: /kæp/ = cap = 头 ==n.帽子==  
- **captain**: /'kæptɪn/ = cap + tain = 首要 + 抓—“擒贼先擒王” ==n.首领==
    - 【真题意群】 a british captain 英国上校  
- **capital**: /'kæpɪt(ə)l/ = capit + al = 首要 + n.“最重要的东西或地方” ==n.首都;资本==  
- **cabbage**: /'kæbɪdʒ/ = cab + b + age = 头 + n.“形状像人头” ==n.卷心菜,洋白菜==  
- **cattle**: /'kæt(ə)l/ = cat + tle = 头 + n. ==n.牛(最开始用头计数的牲畜)==  
- **capitulate**: /kə'pɪtʃuleɪt/ = capit + ulate = 头 + v.—“头部(下低)的动作” ==v.投降==
    - **capitulation**: /kəˌpɪtʃu'leɪʃn/ = ==n.投降==  
- **precipitate**: /prɪ'sɪpɪteɪt/ = pre + cipit + ate = 前 + 头 + v. ==v.促成;沉淀==  
- **chief**: /tʃi:f/ = chief = 头 ==a.主要的; n.负责人;首领==
    - **mischief**: /'mɪstʃɪf/ = mis + chief = 坏 + 头 ==n.损害;胡闹==  
- **chef**: /ʃef/ = chef = 头 ==n.主厨;厨师==  
- **achievement**: /ə'tʃi:vmənt/ = a + chieve(头) + ment = to + 头 + n. ==n.成就;达成==
    - **achieve**: /ə'tʃi:v/ = ==v.实现;达成==  
- **chapter**: /'tʃæptər/ = chapt + er = 头 + n. ==n.章节==
