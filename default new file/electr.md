# **electr = 电**

> [!tip] 快速记忆 
> 开头就是 elec-，直接联想电 (electricity)。

- **electric**: /ɪ'lektrɪk/ = electr + ic = 电 + a. ==a.带电的==; 【真题意群】an electric car 电动汽车
- **electrical**: /ɪ'lektrɪk(ə)l/ = ==a.用电的==; 【真题意群】an electrical line 电路
- **electricity**: /ɪˌlek'trɪsəti/ = ==n.电; 电能==; 【真题意群】pay electricity bill 付电费
- **electron**: /ɪ'lektrɑ:n/ = ==n.电子==
- **electronic**: /ɪˌlek'trɑ:nɪk/ = ==a.电子的==; 【真题意群】an electronic book 电子书
    - **electronics**: /ɪˌlek'trɑ:nɪks/ = ==n.电子学==
- **electrician**: /ɪˌlek'trɪʃ(ə)n/ = ==n.电工==
