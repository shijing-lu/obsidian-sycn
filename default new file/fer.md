# **fer = 带来**

> [!tip] 快速记忆 
> 核心含义是“带来、拿、承受”。**offer** 是拿给你，**prefer** 是提前拿（偏好），**transfer** 是穿过两地拿（转移）。

- **confer**: /kən'f 3:r/ = con+fer = 共同+带——“带来各自想法” ==v.协商==
    - **conference**: /'ka:nfərəns/ = ==n.会议==; 【真题意群】 a press conference 新闻发布会
- **ferry**: / feri/ = fer+ry = 带+n. ==n.渡船;v.来往行驶==; 【真题意群】an evening ferry 夜晚渡船
- **offer**: / :fer/ = of+fer = 对面+带——“对面带给” ==v.提供;n.工作机会;入学准许== present
- **differ**: / difer/ = dif+fer = 离开+带 ==v.相异==; 【真题意群】 differ slightly 略有不同
    - **different**: / difrənt/ = ==a.相异的==
    - **indifferent**: /ın dıfrənt/ = ==a.漠不关心的==
    - **difference**: /'dıfrəns/ = ==n.差异==
    - **differentiate**: / difǝ renſieit/ = ==v.区别==
- **prefer**: /pri'f 3:r/ = pre+fer = 提前+带——“提前带走” ==v.偏爱== ~atob; 【真题意群】 prefer a to b 相对而言,更喜欢 a
    - **preference**: / prefrəns/ = ==n.偏爱==; 【真题意群】a preference for sth.对某物有偏好
    - **preferable**: / prefrǝb(ə)l/ = ==a.更好的;更合心意的;更可取的==
- **refer**: /rı f 3:r/ = re+fer = 回+带——“回到…身上” ==v.提及;参考== ~(a) to b
    - **reference**: /'ref( )r( )ns/ = ==n.参考== with~to; 【真题意群】a literature reference 文献参考书目
    - **referee**: / refəri:/ = ==n.裁判员==
- **suffer**: / safer/ = suf+fer = 下面+带“承受负担” ==v.遭受== ~from;【真题意群】suffer from water shortage 因缺水而受苦
    - **suffering**: / səfəriŋ/ = ==n.痛苦,苦难==; 【真题意群】 sink to a terrible suffering 陷入巨大痛苦中
- **infer**: /in'f 3:r/ = in+fer = 进入+带一“带着信息去思考” ==v.推断== conclude deduce
    - **inference**: / infərəns/ = ==n.推断==
- **transfer**: /træns f 3:r/ = trans+fer = 穿过+带 ==v.转移== ~ from a to b
- **fertile**: /'f 3:rt( )l/ = fer+tile = 带来+a. ==a.多产的;富饶的== rich
    - **fertilizer**: / f 3:rtəlaızər/ = ==n.肥料==;
- **defer**: /dı f 3:r/ = de+fer = x+带一“没带来只能推迟了” ==v.延迟== postpone put off
- **interfere**: / inter fır/ = inter+fer+e = 中间+带 ==v.干涉妨碍==
    - **interference**: / inter fırəns/ = ==n.干涉介入;阻碍物==
- **metaphor**: / metəfər/ = meta+phor = 改变+带 ==n.隐喻暗喻;象征==
