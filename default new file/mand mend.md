# **mand mend = 命令**

> [!tip] 快速记忆
> 
> 核心是“命令、要求”。**command** (命令)；**demand** (强烈要求)。

- **command**: /kəˈmænd/ = com + mand = 加强 + 命令 ==v.n.命令；指挥== (同 order, instruct)
    - 【真题意群】command an army 命令一支部队
- **demand**: /dɪˈmænd/ = de + mand = 加强 + 命令 ==v.要求==
    - 【真题意群】demand real passion 需要真正的激情
    - **demanding**: /dɪˈmændɪŋ/ = ==a.劳神的；费时的==
- **countermand**: /ˈkaʊntərmænd/ = counter + mand = 反向 + 命令 ==v.撤回== (同 cancel, revoke)
- **mandate**: /ˈmændeɪt/ = mand + ate = 命令 + v. ==v.n.授权；委任；命令==
    - **mandatory**: /ˈmændətɔːri/ = ==a.强制的；命令的==
