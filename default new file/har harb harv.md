# **har harb harv = 军队**

> [!tip] 快速记忆 
> 与军队、庇护所、骚乱有关。军队驻扎的地方引申为港口(haven/harbor)，军队带来的混乱引申为破坏(havoc)和骚扰(harassment)。

- **harness**: /ˈhɑːrnɪs/ = har + ness = 军队 + n. ==n.马具 v.利用;控制==
	- 伤害：harm
- **haven**: /ˈheɪv(ə)n/ = hav + en = 军队 + n. ==n.港口;安全的地方== 
	- 天堂：heaven
- **havoc**: /ˈhævək/ = hav + oc = 军队 + n. ==n.大破坏;浩劫==
- **hurry**: /ˈhɜːri/ = hurr + y = 军队 + n. ==n.急忙 v.匆匆地走==
- **harassment**: /həˈræsmənt/ = harass + ment = 军队 + n. ==n.骚扰;折磨人的东西;烦恼==
