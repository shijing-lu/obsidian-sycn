# **head = 头**

> [!tip] 快速记忆 
> **head** 既指人体的头部，也指事物的首要部分、领头人。

- **headline**: /ˈhedlaɪn/ = head + line = 头 + 行 ==n.标题;提要==
    - 【真题意群】read a headline 读标题
- **headmistress**: /ˌhedˈmɪstrəs/ = head + mistr + ess = 头 + 领导 + 女性 ==n.女校长==
    - 【真题意群】a british headmistress 英籍女校长
- **headmaster**: /ˌhedˈmæstər/ = ==n.男校长==
