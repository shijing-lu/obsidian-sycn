# **dem(o) = 人民**

> [!tip] 快速记忆 
> 词根 demo 代表“人民、大众”。**democracy** 就是由人民(demo)来统治(cracy)，即民主；**epidemic** (流行病) 就是在人民(dem)中传播(epi)的疾病。

- **democracy**: /dɪ'mɑ:krəsi/ = demo + cracy = 人民 + 统治 ==n.民主==
    - **democratic**: /ˌdemə'krætɪk/ = ==a.民主的==
    - **democratize**: /dɪ'mɑ:krətaɪz/ = ==v.使民主化==
- **demographic**: /ˌdemə'ɡræfɪk/ = demo + graph + ic = 人民 + 写(画) + a. ==a.人口特征的==
- **epidemic**: /ˌepɪ'demɪk/ = epi + dem + ic = 传播 + 人民 + n. ==n.流行病;蔓延==
- **pandemic**: /pæn'demɪk/ = pan + dem + ic = 广泛 + 人民 + n. ==n.大流行病==
