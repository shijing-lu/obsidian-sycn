# **it = 走**

> [!tip] 快速记忆 
> 拉丁词根 it 表示“走 (go)”。最典型的就是 **exit** (出口) = 向外(ex) + 走(it)；**visit** (参观) 就是走去看。

- **initial**: /ɪˈnɪʃ(ə)l/ = in + it + i + al = 进入 + 走 + a. ==a.开始的;最初的==
- **initiate**: /ɪˈnɪʃieɪt/ = ==v.开始;发起==
    - 【真题意群】~ sb into sth 使某人开始了解某事
    - **initiation**: /ɪˌnɪʃiˈeɪʃn/ = ==n.开始== (同 beginning)
    - **initiative**: /ɪˈnɪʃətɪv/ = ==n.倡议;新方案;主动性==
- **ambition**: /æmˈbɪʃ(ə)n/ = amb + it + ion = 周围 + 走 + n. ==n.目标;抱负==
	- Ambiguous 摸棱兩可的
    - 【真题意群】artistic ambition 艺术抱负
    - **ambitious**: /æmˈbɪʃəs/ = ==a.有抱负的==
- **exit**: /ˈeksɪt/ = ex + it = out + 走 ==v.出去 n.出口==
- **transit**: /ˈtrænzɪt/ = trans + it = 穿过 + 走 ==v.n.通过;运输==
    - **transition**: /trænˈzɪʃ(ə)n/ = ==n.过渡==
    - **transitive**: /ˈtrænzətɪv; ˈtrænsətɪv/ = ==a.过渡的；及物的==
    - **transitory**: /ˈtrænzətɔːri/ = ==a.短暂的==
    - **transient**: /ˈtrænʃ(ə)nt/ = ==a.短暂的;流动性的==
- **circuit**: /ˈsɜːrkɪt/ = circu + it = 圆环 + 走 ==v.n.环行==
    - **circuity**: /sɜːrˈkjʊəti/ = ==n.迂回==
    - **circuitous**: /sərˈkjuːɪtəs/ = ==a.迂回的;绕行的==
- **inevitable**: /ɪnˈevɪtəb(ə)l/ = in + ev + it + able = × + out + 走 + a. ==a.不可避免的;必然发生的==
- **perish**: /ˈperɪʃ/ = per + ish(=it) = 贯穿 + 走 ==v.死亡;毁灭;腐烂==
- **traitor**: /ˈtreɪtər/ = tra + it + or = 穿过 + 走 + n. ==n.背叛者;卖国贼==
