# **lud lus = 玩→欺诈**

> [!tip] 快速记忆
>  玩弄、欺骗。**illusion** (错觉/幻想)就是被幻象玩弄；**delude** (加强欺诈) 则是欺骗。

- **illusion**: /ɪˈluːʒ(ə)n/ = il + lus + ion = to + 玩弄 + n. ==n.错觉; 幻想==
    - **illusory**: /ɪˈluːsəri/ = ==a.错觉的; 虚假的==
- **allude**: /əˈluːd/ = al + lud + e = to + 玩耍—“通过非正式形式的表现” ==v.提及; 暗指==
- **delude**: /dɪˈluːd/ = de + lud + e = 加强 + 欺诈 ==v.欺骗== (同 deceive)
    - **delusion**: /dɪˈluːʒn/ = ==n.欺骗==
- **elude**: /ɪˈluːd/ = e + lud + e = out + 欺诈 ==v.躲避; 逃避== (同 avoid, escape, circumvent)
    - **elusive**: /ɪˈluːsɪv/ = ==a.难以捉摸的; 找不到的== (同 complicated, complex)
