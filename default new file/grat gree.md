# **grat gree = 使人愉悦**

> [!tip] 快速记忆 
> 与高兴、愉悦的情绪相关。**agree** (同意)就是让大家都高兴的妥协；**gratitude** 则是让人感到愉快的“感激” 。

- **grateful**: /ˈɡreɪtf(ə)l/ = grat + e + ful = 愉悦 + a. ==a.感谢的;令人愉快
    - **gratitude**: /ˈɡrætɪtuːd/ = ==n.感激==
- **agree**: /əˈɡriː/ = a + gree = to + 使人愉悦 ==v.同意==
    - **agreeable**: /əˈɡriːəb(ə)l/ = ==a.令人赞同的==
    - **disagree**: /ˌdɪsəˈɡriː/ = ==v.不同意==
    - **agreement**: /əˈɡriːmənt/ = ==n.同意;协定;相符==
- **congratulate**: /kənˈɡrætʃuleɪt/ = con + grat + ul + ate = 共同 + 高兴 + v. ==v.祝贺,庆贺;感到高兴==
    - **congratulation**: /kənˌɡrætʃuˈleɪʃn/ = ==n.祝贺==
    - 【真题意群】receive congratulations 收到祝贺
- **grace**: /ɡreɪs/ = grac + e = 愉悦 ==n.优雅==
    - **graceful**: /ˈɡreɪsf(ə)l/ = ==a.优雅的==
    - **gracious**: /ˈɡreɪʃəs/ = ==a.亲切和蔼的==
    - **disgrace**: /dɪsˈɡreɪs/ = ==v.使丢脸 n.耻辱;不光彩==
- **greet**: /ɡriːt/ = greet = 高兴 ==v.同…打招
- **regret**: /rɪˈɡret/ = re + gret = 反 + 高兴 ==v.n.后悔;遗憾
