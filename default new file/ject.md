# **ject = 投射**
> [!tip] 快速记忆 
> 词根 **ject** 的核心是“投射、扔 (throw)”。**reject** 往回(re)扔就是拒绝；**project** 往前(pro)投射就是计划/投影；**inject** 往里(in)扔就是注射。

- **jet**: /dʒet/ = jet = 投射 ==n.喷气式飞机 v.喷射==
- **object**: /ˈɑːbdʒekt/ = ob + ject = 前面 + 投射 ==n.物体;对象 v.反对==
    - **objective**: /əbˈdʒektɪv/ = ==a.客观的 n.目标==
    - **objection**: /əbˈdʒekʃ(ə)n/ = ==n.异议;反对==
- **subject**: /ˈsʌbdʒekt/ = sub + ject = 下面 + 投射 ==n.主题;学科;实验对象 v.服从== ~ to
    - **subjective**: /səbˈdʒektɪv/ = ==a.主观的==
- **project**: /ˈprɑːdʒekt/ = pro + ject = 向前 + 投射 ==v.投射 n.计划==
    - **projector**: /prəˈdʒektər/ = ==n.放映机;投影仪==
- **reject**: /rɪˈdʒekt/ = re + ject = 往回 + 投射 ==v.拒绝== refuse
    - 【真题意群】reject the order request 拒绝订单要求
    - **rejection**: = ==n.拒绝==
- **inject**: /ɪnˈdʒekt/ = in + ject = 里面 + 投射 ==v.注射== ~ sb/sth with sth; infuse
    - **injection**: /ɪnˈdʒekʃ(ə)n/ = ==n.注射==
- **eject**: /ɪˈdʒekt/ = e + ject = out + 扔 ==v.驱逐;喷射== expel
- **adjacent**: /əˈdʒeɪs(ə)nt/ = ad + jac + ent = to + 投射 + a. ==a.临近的;毗邻的==
