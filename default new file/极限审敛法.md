
**（1）无穷限反常积分**：设 $\displaystyle\int_a^{+\infty}f(x)dx$，$f(x), g(x)$ 在 $[a,+\infty)$ 上连续，$f(x),g(x)\ge 0$。令

$$
l = \lim_{x\to+\infty}\frac{f(x)}{g(x)}
$$

- 若 $l = +\infty$：$\displaystyle\int_a^{+\infty}g(x)dx$ 发散 ⇒ $\displaystyle\int_a^{+\infty}f(x)dx$ 发散；
- 若 $l = 0$：$\displaystyle\int_a^{+\infty}g(x)dx$ 收敛 ⇒ $\displaystyle\int_a^{+\infty}f(x)dx$ 收敛；
- 若 $0 < l < +\infty$：$\displaystyle\int_a^{+\infty}f(x)dx$ 与 $\displaystyle\int_a^{+\infty}g(x)dx$ **敛散性相同**。

**（2）瑕积分**：设 $\displaystyle\int_a^b f(x)dx$，$x=a$ 为瑕点，$f(x), g(x)\ge 0$ 在 $(a,b]$ 上连续。令

$$
l = \lim_{x\to a^+}\frac{f(x)}{g(x)}
$$

- 若 $l = +\infty$：$\displaystyle\int_a^b g(x)dx$ 发散 ⇒ $\displaystyle\int_a^b f(x)dx$ 发散；
- 若 $l = 0$：$\displaystyle\int_a^b g(x)dx$ 收敛 ⇒ $\displaystyle\int_a^b f(x)dx$ 收敛；
- 若 $0 < l < +\infty$：二者**敛散性相同**。
