# **M 字母 单列高频词汇**

> [!tip] 快速记忆
> 
> 本组汇总了 M 开头的其他高频重点词汇。

- **mature**: /məˈtʃʊr/ = ma=（成为）母亲 ==a.成熟的==
- **miserable**: /ˈmɪzrəb(ə)l/ = miser + able = 可怜 + a. ==a.悲惨的==
- **mistaken**: /mɪˈsteɪkən/ = mis + take + (e)n = × + 理解 + v. ==v.误解==
- **marriage**: /ˈmærɪdʒ/ = marr(y)i + age = 结婚 + n. ==n.婚姻（生活）==
- **mere**: /mɪr/ = mer + e = 明亮的不掺杂东西的“谐音：没有” ==a.仅仅；只不过；纯粹的==
- **merit**: /ˈmerɪt/ = mer + it = 发光→分配 + v.“my right” ==v.值得；应获得 n.优点；价值==
- **moreover**: /mɔːrˈoʊvər/ = more + over = 更多 + 在…上 ==ad.此外；而且==
- **myth**: /mɪθ/ = 本身就是某拟声起源=“秘史” ==n.神话==
- **mysterious**: /mɪˈstɪriəs/ = myst + er + ious = 神秘 + n. + a. ==a.神秘的==
    - **mystery**: = my + stery=我的+story=n.秘密 ==a.神秘的== (真正词根是 myst- 神秘)
- **military**: /ˈmɪləteri/ = milit + ary = 军人 + a. ==a.军事的 n.军队==
    - **militarily**: /'militərili/ = ==ad.军事上地==
- **martial**: /ˈmɑːrʃ(ə)l/ = 谐音“马首” ==a.军事的（希腊神话战神马尔斯）；n.军队==
- **malignant**: /məˈlɪɡnənt/ = mal + i + gn + ant = × + 出生 + a.“生来就不好的” ==a.恶性的；致命的==
- **microwave**: /ˈmaɪkrəweɪv/ = micro + wave = 微 + 波 ==n.微波炉==
    - 【真题意群】a microwave sausage 微波炉加热的香肠
- **mend**: /mend/ = mend=改错 ==v.修理；治愈==
    - 【真题意群】mend one’s bike 修理某人的自行车
