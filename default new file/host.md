# **host = 客人**

> [!tip] 快速记忆 
> 很有意思的词根，既表示“招待客人的主人(host)”，又引申出“接待客人的地方(hospital/hotel)”，甚至引申为“对客人不友好的敌对(hostile)”。

- **host**: /hoʊst/ = host = 客人“招待客人的人” ==n.主人;节目主持人 v.主持==
    - 【真题意群】ask the host’s permission 请求主人的许可
    - **hostess**: /ˈhoʊstəs/ = ==n.女主人==
- **hostage**: /ˈhɑːstɪdʒ/ = host + age = 客人 + n. ==n.人质;抵押品==
- **hospital**: /ˈhɑːspɪt(ə)l/ = hosp + ital = 客人 + n. ==n.医院==
- **hospitality**: /ˌhɑːspɪˈtæləti/ = ==n.殷勤好客;款待==
- **hostile**: /ˈhɑːst(ə)l/ = host + ile = 客人 + a. ==a.敌对的==
    - **hostility**: /hɑːˈstɪləti/ = ==n.敌意==
- **hotel**: /hoʊˈtel/ = hot + el = 客人 + n. ==n.旅馆==
