# **erg org = 活动**

> [!tip] 快速记忆 
> 核心意思是“能量、活动、器官”。**energy**（能量/精力）就是里面的活动；**organize**（组织）就是把活动/器官协调起来。
- **energy**: /'enərdʒi/ = en + erg + y = 里面 + 活动 ==n.精力; 能量== (例: ~ consumption; ~ saving; ~ conservation 能量守恒)
    - **energetic**: = ==a.精力充沛的== (替换 vigorous)
    - **energize**: = ==v.给予……精力==
- **organize**: /'ɔ:rgənaɪz/ = organ + ize = 活动 + v. ==v.组织; 筹备; 安排==; 【真题意群】organize a fundraising 组织一场募捐
    - **organization**: /ˌɔ:rgənə'zeɪʃ(ə)n/ = ==n.组织; 机构; 团体==; 【真题意群】a political organization 政府机构
    - **organizer**: /'ɔ:rgənaɪzər/ = ==n.组织者; 发起人==
- **organ**: /'ɔ:rgən/ = organ = 活动 ==n.器官; 机关, 机构==; 【真题意群】take oxygen to organs 将氧气送入器官
    - **organic**: /ɔ:r'ɡænɪk/ = ==a.有机的; 器官的==
    - **organism**: /'ɔ:rgənɪzəm/ = ==n.有机体==
- **alert**: /ə'lɜ:rt/ = al + ert = to + 活动—“关注有活动的地方” ==a.警惕的; n.惊觉; v.警告== (例: on the alert; be ~ to sth)
- **exert**: /ɪɡ'zɜ:rt/ = ex + ert = out + 功 ==v.施加影响; 运用== (例: ~ influence on)
- **urge**: /ɜ:rdʒ/ = urg + e = 去活动 ==v.催促 n.冲动; 强烈的欲望==
    - **urgent**: /'ɜ:rdʒənt/ = ==a.紧急的; 催促的==
- **surgeon**: /'sɜ:rdʒən/ = s + urg + eon = 手(缩写自希腊语) + 活动 + n. ==n.外科医生==
    - **surgery**: /'sɜ:rdʒəri/ = ==n.外科手术==
