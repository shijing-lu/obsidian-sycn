# **labor = 劳动**

> [!tip] 快速记忆 
> 劳动、工作。**collaborate** 是一起(col)劳动，即合作；**elaborate** 则是付出很多劳动去精心制作。

- **labour**: /ˈleɪbər/ = labour(同 labor) = 劳动 ==n.v.劳动== (例: ~ force 劳动力/workforce)
    - 【真题意群】physical labour 体力劳动
    - **laborer**: = ==n.劳动者==
    - **laborious**: /ləˈbɔːriəs/ = ==a.勤劳的; 辛苦的==
- **laboratory**: /ˈlæbrətɔːri/ = ==n.实验室==
- **collaborate**: /kə'læbəreɪt/ = col + labor + ate = 共同 + 劳动 + v. ==v.合作==
- **elaborate**: /ɪˈlæbərət/ = e + labor + ate = out + 劳动 + v.“付出很多劳动” ==v.精心制作 a.精心制作的== (~ on)
    - **elaboration**: = ==n.精心制作==
