# **form = 形成;形式;形状**

> [!tip] 快速记忆
>  **form** 本身就是“形状”。**transform** 就是改变(trans)形状(form)；**uniform** 是统一的(uni)形状(form)。

- **form**: /form/ = form = 形式形状形成 ==v.形成 n.形式==
    - **formation**: /fo:'meı∫( )n/ = ==n.形成;构成;排列== the~ of sth
    - **formative**: /fo:rmətıv/ = ==a.形成的;造型的==
- **formal**: / form( ) / = form+al = ==a.正式的==
	- **informal**: /ın'fo:rm ( )l/ = ==a.非正式的==
- **format**: /'fo:rmæt/ = ==n.格式==
- **inform**: /ın fɔ:rm/ = in+form = 传递进去+形式 ==v.通知== ~sb of/about sth.; 【真题意群】inform sb. of sth.告诉某人某事
    - **information**: / infər meis( )n/ = ==n.信息==
    - **informed**: /ın fɔ:rmd/ = ==a.有学问的;明智的==
- **reform**: /rı fɔ:rm/ = re+form = 再+形成 ==v.改革== renovate;【真题意群】as social reform 社会改革
    - **reformation**: / refer mein/ = ==n.改革==
- **transform**: /træns fɔ:rm/ = trans+form = 穿过+形状 ==v.改变;变形==
    - **transformation**: = ==n.变化;转换==
- **uniform**: / ju:nıfɔ:rm/ = uni+form = 唯一+形式 ==a.一样的;n.制服== suit; 【真题意群】 wear school uniform 穿校服
- **perform**: /pər fə:rm/ = per+form = 贯穿+形式 ==v.执行 表演== implement fulfill; 【真题意群】 perform different tasks 执行不同的任务
    - **performance**: /pər fɔ:rməns/ = ==n.表现==; 【真题意群】 a free performance 免费的演出
    - **performer**: /pər fərmər/ = ==n.表演者;演员==; 【真题意群】a street performer 街头表演者
- **platform**: / plætfɔ:rm/ = plat+form = 平+形状 ==n.平台==; 【真题意群】a new learning platform 新的学习平台
- **conform**: /kən fə:rm/ = con+form = 共同+形式 ==v.遵守;使一致;a.顺从的== ~to(符合)/with(遵从)
- **deform**: /dı fɔ:rm/ = de+form = x(否定)+形状 ==v.使变形;使畸形==
- **formulate**: /'fo:rmjuleit/ = form+ula+(a)te = 形式+n.+v. ==v.构想出==
    - **formulation**: / fɔ:rmju lei∫( )n/ = ==n.构想;规划==
    - **formula**: /fo:rmjələ/ = ==n.公式;套话==
