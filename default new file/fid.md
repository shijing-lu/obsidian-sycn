# **fid = 信念**

> [!tip] 快速记忆 
> 核心是“相信、忠诚”。**confidence** 就是共同拥有强烈的信念(信心)；WiFi 也就是无线(Wireless)忠诚/高保真(Fidelity)的缩写。

- **confidence**: /ˈkɑːnfɪdəns/ = con + fid + ence = 强 + 信念 + n. ==n.信心;信任==
    - **confident**: /ˈkɑːnfɪdənt/ = ==a.有信心的;自信的==
    - **confidential**: /ˌkɑːnfɪˈdenʃ(ə)l/ = ==a.机密的;秘密的==
- **faith**: /feɪθ/ = fid 变形 = 信念 ==n.信仰;信念;信心==
    - **faithfully**: /ˈfeɪθfəli/ = ==ad.忠诚地==
- **diffident**: /ˈdɪfɪdənt/ = dif + fid + ent = - + 信念 + a. ==a.缺乏自信的==
    - **diffidence**: /ˈdɪfɪdəns/ = ==n.缺乏自信==
- **federal**: /ˈfedərəl/ = feder + al = 信任 + a. ==a.联邦制的;联邦政府的==
    - **federation**: /ˌfedəˈreɪʃ(ə)n/ = ==n.联邦;同盟;联合会==
- **defy**: /dɪˈfaɪ/ = de + fy = x + 信任 ==v.违抗;挑战;经受住==
