# **F 字母 零散单列高频词汇**
> [!tip] 快速记忆 
> 这些是不成大组但极度高频的核心词汇，可以直接当做生词本重点攻克。


- **fierce**: /fɪrs/ = fier + ce = 野的 + a. ==a.猛烈的;激烈的==
- **favour**: /ˈfeɪvər/ = (同 favor) = 好意 ==n.支持;恩惠,帮助 v.较喜欢==
    - **favorable**: /ˈfeɪvərəb(ə)l/ = ==a.有利的;赞成的==
- **perfume**: /pərˈfjuːm/ = per + fum + e = 通过 + 烟 ==n.香水;香气==
- **fountain**: /ˈfaʊnt(ə)n/ = fount + ain = 流 + n. ==n.喷泉==
- **furniture**: /ˈfɜːrnɪtʃər/ = furniture = 提供 + n. ==n.家具==
- **fairly**: /ˈferli/ = fair + ly = 公平的 + ad. ==ad.公平地;相当地==
- **fasten**: /ˈfæs(ə)n/ = fast + en = 固定的 + v. ==v.系牢;系紧==
- **feed**: /fiːd/ = (来自 food) ==v.喂养==
- **fellow**: /ˈfeloʊ/ = fe(fee) + llow = 钱 + 放下(一起掏钱的人) ==n.同伴;同事==
- **fetch**: /fetʃ/ = fet(feet) + ch = 脚 + v. ==v.取来==
- **focus**: /ˈfoʊkəs/ = (古意火炉=燃烧的中心) ==n.焦点;中心 v.(使)集中==
- **fond**: /fɑːnd/ = fon (fun) + d = 傻→喜爱 + a. ==a.喜欢的==
- **frighten**: /ˈfraɪt(ə)n/ = fright(脸上刻给罪犯的印记) + en ==v.使惊恐==
- **malfunction**: /ˌmælˈfʌŋkʃ(ə)n/ = mal + funct + ion = x + 功能 + n. ==n.v.故障;失灵==
- **framework**: /ˈfreɪmwɜːrk/ = frame + work = 框架 + 作品 ==n.框架;结构;机制==
- **feedback**: /ˈfiːdbæk/ = feed + back = 提供 + 回 ==n.反馈==
- **fashionable**: /ˈfæʃ(ə)nəb(ə)l/ = fashion + able = 时尚 + a. ==a.流行的==
- **affiliate**: /əˈfɪlieɪt/ = af + fili + ate = to + 儿子 + v. ==v.隶属于;并入 n.附属机构==
