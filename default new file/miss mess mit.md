# **miss mess mit = 送**

> [!tip] 快速记忆 
> 核心动作是“送出、发送”。**missile** 是送出去的导弹；**permit** 是允许通过（贯穿送）；**commit** 则是把承诺送出去。

- **miss**: /mɪs/ = miss = 送你离开千里之外 ==v.思念；失误 n.失误失手==
    - **mission**: /ˈmɪʃ(ə)n/ = miss + ion = 送 + n. ==n.使命；代表团==
    - **missing**: /ˈmɪsɪŋ/ = miss + ing = 送 + a. ==a.丢失的；失踪的；遗漏的==
    - **missile**: /ˈmɪs(ə)l/ = miss + ile = 送 + n. ==n.导弹==
- **permit**: /pərˈmɪt/ = per + mit = 贯穿 + 送 ==v.允许==
    - 【真题意群】permit automatic driving 允许自动驾驶
    - **permission**: /pərˈmɪʃ(ə)n/ = ==n.允许==；【真题意群】give sb. permission 给某人许可
    - **permissive**: /pərˈmɪsɪv/ = ==a.允许的；宽容自由的==
- **admit**: /ædˈmɪt/ = ad + mit = to + 送 ==v.准入；承认== (同 acknowledge)
    - 【真题意群】admit one’s weakness 承认某人的缺点
    - **admission**: /ədˈmɪʃ(ə)n/ = ==n.准入；承认==；【真题意群】the admission to college 被大学录取
- **commit**: /kəˈmɪt/ = com + mit = 加强 + 送 ==v.承诺；犯罪== (~ to… 把…托付给；~ suicide 自杀; 同 pledge, vow, promise, keep)
    - 【真题意群】commit crime 犯罪
    - **commitment**: /kəˈmɪtmənt/ = ==n.承诺；犯罪==；【真题意群】a commitment to do sth. 承诺做某事
    - **committed**: = ==a.坚定的== (注: 原文 commited 鉴定的 为拼写输入笔误)
- **submit**: /səbˈmɪt/ = sub + mit = 下面 + 送 ==v.提交；屈服== (~ to)
    - 【真题意群】submit sth. to sb. 给某人提交某物
    - **submission**: /səbˈmɪʃ(ə)n/ = ==n.提交；屈服==
- **transmit**: /trænzˈmɪt/ = trans + mit = 穿过 + 送 ==v.传播==
    - **transmission**: /trænzˈmɪʃ(ə)n/ = ==n.传播==
- **dismiss**: /dɪsˈmɪs/ = dis + miss = 四面八方 + 送 ==v.解散== (同 fire)
    - 【真题意群】dismiss an administrator 遣散管理人员
- **message**: /ˈmesɪdʒ/ = mess + age = 送 + n. ==n.消息==
- **committee**: /kəˈmɪti/ = com + mitt + ee = 加强 + 派 + n. ==n.委员会==
    - 【真题意群】form a committee 组成委员会
- **omit**: /əˈmɪt/ = o + mit = 对面 + 送 ==v.省略；删掉==
    - **omission**: /əˈmɪʃ(ə)n/ = ==n.省略；删掉==
- **emit**: /iˈmɪt/ = e + mit = 外 + 送 ==v.散发==
    - **emission**: /ɪˈmɪʃ(ə)n/ = ==n.发出==
- **commission**: /kəˈmɪʃ(ə)n/ = com + miss + ion = 共同 + 送 + n. ==n.委托；委员会==
- **promise**: /ˈprɑːmɪs/ = pro + mis + e = 前 + 送“未来会给你啥啥啥” ==v.许诺==
    - **promising**: /ˈprɑːmɪsɪŋ/ = ==a.有希望的；有前途的==
    - **compromise**: /ˈkɑːmprəmaɪz/ = com + promise = 共同 + 许诺 ==v.n.妥协折中；损害==
- **premise**: /ˈpremɪs/ = pre + mis + e = 提前 + 送（放出） ==n.前提；假定==
