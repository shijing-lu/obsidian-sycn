# **em empt an ampl = 拿**

> [!tip] 快速记忆 
> 核心是“拿走、获取”。**empty**（空的）就是里面的东西全被拿走了；**example**（例子）就是从中拿出一个来展示。

- **empty**: /'empti/ = empt + y = 拿 ==a.空的==
- **example**: /ɪɡ'zæmp(ə)l/ = ex + ampl + e = out + 拿 ==n.例子==
    - **exemplify**: /ɪɡ'zemplɪfaɪ/ = ==v.例证== (替换 demonstrate, illustrate, confirm)
- **exempt**: /ɪɡ'zempt/ = ex + empt = out + 拿 ==v.免除==
    - **exemption**: = ==n.免除==
- **redeem**: /rɪ'di:m/ = re(d) + eem = 往回 + 拿 ==v.赎回; 补偿==
- **examine**: /ɪɡ'zæmɪn/ = ex + am + ine = out + 拿 + v. ==v.检查==
- **premium**: /'pri:miəm/ = pre + (e)m + ium = 前 + 拿 + n. ==n.额外费用; 附加费 a.高昂的; 优质的==
- **ample**: /'æmp(ə)l/ = ampl + e = 拿 ==a.大量的; 充裕的==
    - **amplify**: /'æmplɪfaɪ/ = ==v.放大; 增强; 充实==
