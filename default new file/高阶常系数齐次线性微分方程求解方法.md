特征方程为 $\lambda^n + a_1\lambda^{n-1} + \cdots + a_{n-1}\lambda + a_n = 0$，根据特征根的符合以下的类型来判断微分方程其解的情况：
1) 特征根为 $n$ 个不同的单实根 $\lambda_1, \lambda_2, \cdots, \lambda_n$，则微分方程通解为 $y = C_1e^{\lambda_1 x} + C_2e^{\lambda_2 x} + \cdots + C_ne^{\lambda_n x}$
2) 若特征根 $\lambda_0$ 为 $k$ 重实根，则微分方程通解中含有 $(C_1 + C_2x + \cdots + C_kx^{k-1})e^{\lambda_0 x}$
3) 若特征根 $\alpha \pm \beta i$ 为 $k$ 重复根，则微分方程通解中含有 $e^{\alpha x}[(C_1 + C_2x + \cdots + C_kx^{k-1})\cos\beta x + (D_1 + D_2x + \cdots + D_kx^{k-1})\sin\beta x]$
