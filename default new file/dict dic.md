# **dict dic = 说**

> [!tip] 快速记忆 
> **dict / dic** 代表“说 (speak)”。**dictionary** (字典) 是教你怎么“说”的书；**predict** (预测) 是在事情发生之“前(pre)”就“说(dict)”出来；**dictate** (听写/命令) 则是口述。

- **addict**: /'ædɪkt/ = ad + dict = to + 说 ==v.上瘾==
    - **addiction**: /ə'dɪkʃ(ə)n/ = ==成瘾==
    - **addicted**: /ə'dɪktɪd/ = ==a.上瘾的==
    - 【真题意群】 get addicted to tv 
- **dictionary**: /'dɪkʃəneri/ = dict + ion + ary = 说 + n. + n.—“告诉你如何措辞的东西” ==n.词典==
- **contradict**: /ˌkɑ:ntrə'dɪkt/ = contra + dict = 相反 + 说 ==v.反驳;相矛盾==
    - **contradictory**: /ˌkɑ:ntrə'dɪktəri/ = ==a.矛盾的==
    - **contradiction**: /ˌkɑ:ntrə'dɪkʃn/ = ==n.反驳
- **predict**: /prɪ'dɪkt/ = pre + dict = 提前 + 说 ==v.预言==
    - 【真题意群】 predict natural disasters 预
    - **prediction**: /prɪ'dɪkʃn/ = ==n.预测==
    - **predictable**: /prɪ'dɪktəb(ə)l/ = ==a.可预测的==
- **indicate**: /'ɪndɪkeɪt/ = in + dic + ate = 里面 + 说明 + v.“把心里的说出来” ==v.指出;表示==
    - 【真题意群】 indicate the end of a meeting 表
    - **indication**: /ˌɪndɪ'keɪʃ(ə)n/ = ==n.表明
    - **indicative**: /ɪn'dɪkətɪv/ = ==a.象征的;指示的;
- **dictation**: /dɪk'teɪʃ(ə)n/ = dict + ation = 说 + n. ==n.口述;听写==
- **dictate**: /'dɪkteɪt/ = ==v.口述;命令==
- **index**: /'ɪndeks/ = in + dex(dic) = 里面 + 说“说明内容每一部分在哪里的” ==n.索引;指数==
- **dedicate**: /'dedɪkeɪt/ = de + dic + ate = 下(引申为完全) + 说 + v. ==v.致力;献身==
    - **dedication**: /ˌdedɪ'keɪʃ(ə)n/ = ==n.奉献
    - **dedicated**: /'dedɪkeɪtɪd/ = ==a.专注的;
- **verdict**: /'vɜ:rdɪkt/ = ver(真实) + dict = 真实 + 说 ==n.裁决;结论==
