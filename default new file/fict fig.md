# **fict fig = 虚构, 塑造**

> [!tip] 快速记忆 
> 包含塑造、描绘以及衍生的“做”的变形。**figure** 有塑造出的人物/图形之意；而 function, feasible 等词也是由“做”的动作衍生而来。

- **figure**: /'fıgjer/ = fig+ure = 做+n. ==n.人物;图形;画像;数字 v.描绘;计算==; 【真题意群】 earn close to six figures 挣钱接近六位数
- **feasible**: / fi:zəb(ə)l/ = feas+ible = 做+能……的 ==a.可行的==
- **proficient**: /prə fıs(ə)nt/ = pro+fic+i+ent = 提前+做+a. ==a.精通熟练的== accomplished skilled adept
    - **proficiency**: /prə fı∫(ə)nsi/ = ==n.熟练;精通==
- **office**: / a:fis/ = of+fic+e = 对面+做 ==n.办公室==
    - **officer**: /'a:fıser/ = ==n.职员;公务员==
    - **official**: /ə fıs(ə)l/ = ==a.官方的 n.官员==
- **deficit**: / defisit/ = de+fic+it = 下+做+n. ==n.差额;赤字;亏损==
    - **deficiency**: = ==n.缺乏;不足;缺陷==
- **magnificent**: /mæg'nıfıs( )nt/ = magni+fic+ent = 大+制作+a. ==a.壮丽的;宏伟的==
- **function**: / fak∫( )n/ = funct+ion = 做+n. ==n.功能作用;函数 v.运行==
    - **functional**: /mæg nıfıs ( )nt/ = ==a.功能的;有多种用途的==
- **fake**: = fake = 做 ==v.伪造 n.假货 a.假的;伪造的==
