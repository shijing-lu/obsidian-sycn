# **found fund = 建立**

> [!tip] 快速记忆 
> 与“建立基础、提供资金”相关。**found** 是建立，**foundation** 是地基/基金会；做一件事最基础的东西就是 **fundamental**（根本的）。

- **fund**: /fʌnd/ = fund = 建立 ==v.为……提供资金;资助 n.基金;现金储备==
- **refund**: /ˈriːfʌnd/ = re + fund = 再 + 资金 ==v.n.退还;归还;偿还==
- **foundation**: /faʊnˈdeɪʃ(ə)n/ = found + ation = 建立 + n. ==n.基础;建立==
- **found**: /faʊnd/ = ==v.建立==
    - **founder**: /ˈfaʊndər/ = ==n.建立者==
    - **unfounded**: /ʌnˈfaʊndɪd/ = ==a.无事实根据的;无基础的==
- **fundament**: /ˈfʌndəmənt/ = fund + a + ment = 建立 + n. ==n.基础==
    - **fundamental**: /ˌfʌndəˈment(ə)l/ = ==a.基本的;必要的==
- **profound**: /prəˈfaʊnd/ = pro + found = 提前 + 建立 ==a.深远的;深刻的==
    - **profundity**: /prəˈfʌndəti/ = ==n.深奥;深刻==
