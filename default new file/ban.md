# **ban = 禁止**
> [!tip] 快速记忆
> 颁布（**ban**）禁令就是禁止。考研中 abandon（放弃）可以拆成 a（to）+ ban（禁止）+ don（给），即“禁止给某人某物”，意味着彻底放弃。

1. **ban**: /bæn/ = ban = 禁止 ===v.n.禁止==
    - 同义：prohibition
    - 【真题意群】district fire bans 地区禁火令
2. **banish**: /ˈbænɪʃ/ = ban + ish = 禁止 + v. ===v.放逐==
3. **abandon**: /əˈbændən/ = a + ban + don = × + 禁止 + 给出 ===v.放弃==
