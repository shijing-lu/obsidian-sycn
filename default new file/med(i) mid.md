# **med(i) mid = 中间**

> [!tip] 快速记忆 
> 核心是“中间的 (middle)”。**media** 是夹在信息与受众中间的媒体；**mediate** 是在双方中间调解。

- **media**: /ˈmiːdiə/ = medi + a = 中间 + n. ==n.媒体== (例: the mass ~ 大众传媒)
- **middle**: /ˈmɪd(ə)l/ = mid + dle = 中间 + a.n. ==a.n.中间的== (例: in the middle of 在…中间；忙于…)
- **midnight**: /ˈmɪdnaɪt/ = mid + night = 中间 + 夜晚 ==n.午夜；a.半夜的==
- **midday**: /ˌmɪdˈdeɪ/ = mid + day = 中间 + 白天 ==a.中午的；n.正午==
- **midst**: /mɪdst/ = mid + st = 中间 + 站 ==n.中间 prep.在…中间==
- **mediate**: /ˈmiːdieɪt/ = med + i + ate = 中间 + v. ==v.调解==
    - **mediation**: = med + i + at(e) + ion = 中间 + v. + n. ==n.仲裁；调解==
- **immediate**: /ɪˈmiːdiət/ = im + med + i + ate = × + 中间 + a. ==a.立即的==
    - **immediately**: = ==ad.立即==
- **medium**: /ˈmiːdiəm/ = med + i + um = 中间 + n. ==n.媒介 a.适中的== (复数是 media 或者 mediums)
    - 【真题意群】the most influential medium 最有影响力的媒体
- **intermediate**: /ˌɪntərˈmiːdiət/ = inter + med + i + ate = 中间 + 中间 + a. ==a.中间的== (常与 basic, advanced 并列)
- **intermediary**: /ˌɪntərˈmiːdieri/ = ==a.中间的；调解的 n.中间人；调解人==
- **meddle**: /ˈmed(ə)l/ = med + dle = 中间 + v. ==v.干预== (同 interfere, intervene)
- **midway**: /ˌmɪdˈweɪ/ = mid + way = 中间 + 路 ==n.中途；a.中途的==
- **amid**: /əˈmɪd/ = a + mid = to + 中间 ==prep.在…中；四周是==
- **medieval**: /ˌmiːdˈiːv(ə)l/ = medi + ev + al = 中间 + 世纪 + a. ==a.中古的，中世纪的==
- **medicine**: /ˈmedɪs(ə)n/ = med + ic + ine = 中间 + a. + 化学物质 ==n.医学；药物==
    - **medical**: /ˈmedɪk(ə)l/ = ==a.医学的；药物的 n.医生；检查==
- **remedy**: /ˈremədi/ = re + med + y = 再 + 中间 + n. ==v.改正；补救 n.治疗法；补救办法==
- **meditate**: /ˈmedɪteɪt/ = med + it + ate = 中间 + 走 + v. ==v.沉思；打算==
    - **meditation**: /ˌmedɪˈteɪʃ(ə)n/ = ==n.默想；沉思==
