# **long leng = 长**

> [!tip] 快速记忆 
> 长度、长久。**prolong** (向前拉长，即延长)；**belong** (长久拥有，即归属)。

- **long**: /lɔːŋ/ = long = 长 ==a.长的 v.渴望==
    - **length**: /leŋθ/ = ==n.长度==
    - **lengthen**: /ˈleŋθən/ = ==v.延长==
    - **longing**: /ˈlɔːŋɪŋ/ = ==n.渴望 a.渴望的==
    - **longingly**: /ˈlɔːŋɪŋli/ = ==ad.渴望地==
- **along**: /əˈlɔːŋ/ = a + long = to + 长 ==prep.沿着 ad.一起; 向前==
- **belong**: /bɪˈlɔːŋ/ = be + long = 使长久拥有 ==v.属于== (~ to)
- **prolong**: /prəˈlɔːŋ/ = pro + long = 向前 + 长 ==v.延长== (同 extend)
