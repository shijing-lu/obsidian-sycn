# **lect lig leg = 选择**

> [!tip] 快速记忆 
> 核心含义是“挑选、收集”。**select** 是分开选出来；**collect** 是一起选过来（收集）；**elegant** 则是精挑细选出来的（优雅的）。

- **intelligence**: /ɪnˈtelɪdʒəns/ = intel + lig + ence = 里面 + 选 + n. ==n.智商==
    - 【真题意群】develope one’s intelligence 提升某人的智力
    - **intelligent**: /ɪnˈtelɪdʒənt/ = ==a.聪明的==
    - **intellect**: /ˈɪntəlekt/ = ==n.智慧== (同 intelligence)
    - **intellectual**: /ˌɪntəˈlektʃuəl/ = ==a.智力的; n.知识分子==
    - **intelligible**: /ɪnˈtelɪdʒəb(ə)l/ = ==a.可理解的==
- **select**: /sɪˈlekt/ = se + lect = 分离 + 选 ==v.选择==
    - 【真题意群】select a channel 选择一条途径
    - **selection**: /sɪˈlekʃ(ə)n/ = ==n.选择==
    - **selective**: /sɪˈlektɪv/ = ==a.选择性的; 可选的==
- **elegant**: /ˈelɪɡənt/ = e + leg + ant = out + 选 + a. ==a.优雅的==
    - 【真题意群】an elegant writher 一位文雅的作家
    - **elegance**: = ==n.高雅; 优雅==
- **collect**: /kəˈlekt/ = col + lect = 共同 + 选 ==v.收集==
    - **collection**: /kəˈlekʃ(ə)n/ = ==n.收集==
    - 【真题意群】sell one’s collections 出售某人的藏品
    - **collector**: /kəˈlektər/ = ==n.收集者==
    - **collective**: /kəˈlektɪv/ = ==a.集体的==
    - **recollect**: /ˌrekəˈlekt/ = ==v.想起; 回忆起==
- **elect**: /ɪˈlekt/ = e + lect = out + 选 ==v.选举==
    - **election**: /ɪˈlekʃ(ə)n/ = ==n.选举==
    - **elector**: /ɪˈlektər/ = ==n.选举者==
    - **elective**: /ɪˈlektɪv/ = ==a.选择的==
- **neglect**: /nɪˈɡlekt/ = neg + lect = × + 选择 ==v.疏忽== (同 ignore, overlook)
    - **negligence**: /ˈneɡlɪdʒəns/ = ==n.疏忽==
    - **negligible**: /ˈneɡlɪdʒəb(ə)l/ = ==a.可忽略的== (同 insignificant, trifling)
- **college**: /ˈkɑːlɪdʒ/ = col + leg + e = 共同 + 选择 ==n.学院==
- **elite**: /ɪˈliːt/ = e + lit + e = out + 选择 ==n.精英 a.出类拔萃的==
- **eligible**: /ˈelɪdʒəb(ə)l/ = e + lig + ible = out + 选 + a. ==a.有资格的; 合格的==
