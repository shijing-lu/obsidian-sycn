# **fac = 脸面**

> [!tip] 快速记忆 
> 和面部相关。**surface** 就是最上面(sur)的面(face)。

- **face**: /feɪs/ = fac + e = 脸面 ==n.脸;外表 v.面对==
    - **facial**: /ˈfeɪʃ(ə)l/ = ==a.面部的;表面的==
- **interface**: /ˈɪntərfeɪs/ = ==n.v.连接;接口==
- **surface**: /ˈsɜːrfɪs/ = sur + face = 上 + 面 ==n.表面 a.表面的==
- **preface**: /ˈprefəs/ = pre + face = 前面 + 脸 ==n.序言;前言==
- **superficial**: /ˌsuːpərˈfɪʃ(ə)l/ = super + fic + ial = 上面 + 脸 + a. ==a.表面的;肤浅的==
- **facet**: /ˈfæsɪt/ = fac + et = 脸 + 小物体 ==n.方面;部分==
