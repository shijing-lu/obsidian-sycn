# **G 字母 单列高频词汇**

> [!tip] 快速记忆 这些是讲义中没有组成庞大词根大组、但同样在真题中高频现身的单独核心词 。

- **grand**: /ɡrænd/ = grand = 大 ==a.宏伟的==
- **glory**: /ˈɡlɔːri/ = glor + y = 荣誉 + n. ==n.荣誉;光荣==
    - 【真题意群】original glory 最初的荣耀
- **gather**: /ˈɡæðər/ = gath = 聚拢集中的内涵 ==v.收集;聚拢==
- **glance**: /ɡlæns/ = 词源同冰川，指不欢迎、冷落的态度 ==n.v.匆匆一瞥==
- **grasp**: /ɡræsp/ = 词源同 grab，抓住 ==n.v.抓住;理解==
- **greedy**: /ˈɡriːdi/ = “g”抓的内涵，什么都要 ==a.贪婪的;贪吃的==
- **guarantee**: /ˌɡærənˈtiː/ = guar(d) + antee = 保卫 + n. ==v.n.担保;保证==
- **guilty**: /ˈɡɪlti/ = guilt + y = 有罪、内疚 ==a.有罪的;内疚的==
- **gigantic**: /dʒaɪˈɡæntɪk/ = gigan + tic = 巨大 + a. ==a.巨大的==
- **giant**: /ˈdʒaɪənt/ = ==n.a.巨大(的)==
- **government**: /ˈɡʌvənmənt/ = govern + ment = 统治 + n. ==n.政府;管辖==
