# **du(o) dub dou(b) = 二**

> [!tip] 快速记忆 
> 这些词根都和数字“二、双”有关。引申出的含义除了“成双成对”，还有“站在两个岔路口摇摆不定”，也就是“怀疑、犹豫”。**double** (双倍)；**doubt** (怀疑 = 摇摆不定)。

- **dual**: /'du:əl/ = du + al = 二 + a. ==a.双的;双重的==
- **duplicate**: /'du:plɪkeɪt/ = du + plic + ate = 二 + 折叠 + v. ==v.复制;复印;重复==
    - 【真题意群】 duplicate nature 重复的性质
    - **duplication**: /ˌdu:plɪ'keɪʃ(ə)n/ = ==n.复制==
- **dubious**: /'du:biəs/ = dub + ious = 二(犹豫不决) + a. ==a.怀疑的==
- **double**: /'dʌb(ə)l/ = doub + le = 二 + a. ==a.双重的;两倍的 v.加倍==
    - 【真题意群】 double income 双份收入
- **doubt**: /daʊt/ = doub + t = 二(犹豫) + v. ==v.n.怀疑==
    - **undoubtedly**: /ʌn'daʊtɪdli/ = ==ad.毋庸置疑地==
