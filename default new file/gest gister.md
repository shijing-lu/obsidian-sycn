# **gest gister = 带**
> [!tip] 快速记忆 
> 词根 **gest / gister** 带有“带、运送”的含义。比如 **gesture** (姿势) 是身体所携带的信息；**suggest** (建议) 是在下面(sug)带出想法 。
- **gesture**: /ˈdʒestʃər/ = gest + ure = 带(信息) + n. ==n.姿势;手势==
    - 【真题意群】a pleasant gesture 愉快的姿态
- **register**: /ˈredʒɪstər/ = re + gister = 回 + 带来——“让信息带回去” ==v.登记;注册==
    - 【真题意群】register a bike 登记自行车信息
    - **registration**: /ˌredʒɪˈstreɪʃ(ə)n/ = ==n.登记;注册==
- **digest**: /daɪˈdʒest/ = di + gest = 四面八方 + 带 ==v.消化吸收;理解==
    - **digestion**: /daɪˈdʒestʃən/ = ==n.消化;理解==
- **suggest**: /səˈdʒest/ = sug + gest = 下面 + 带 ==v.提议;暗示==
    - **suggestion**: /səˈdʒestʃən; sədˈʒestʃən/ = ==n.提议;暗示==
- **congest**: /kənˈdʒest/ = con + gest = 共同 + 带 ==v.拥挤;堵塞==
    - **congestion**: /kənˈdʒestʃən/ = ==n.堵塞;拥挤==
- **exaggerate**: /ɪɡˈzædʒəreɪt/ = ex + ag + ger + ate = out + 走 + 带 + v. ==v.夸张夸大==
