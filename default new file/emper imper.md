# **emper imper = 统治**

> [!tip] 快速记忆 
> 与“帝国、统治、专制”相关。

- **empire**: /'empaɪər/ = empir + e = 统治 ==n.帝国== (例: the roman ~)
    - **emperor**: /'empərər/ = ==n.统治者==
    - **imperial**: /ɪm'pɪriəl/ = imper + i + al = 统治 + a. ==a.帝国的; 皇帝的== (例: the ~ palace)
- **imperative**: /ɪm'perətɪv/ = ==a.命令的; 强制的== (替换 necessary, urgent)
- **imperious**: /ɪm'pɪriəs/ = ==a.专横的; 飞扬跋扈的== (替换 overbearing, arrogant)
