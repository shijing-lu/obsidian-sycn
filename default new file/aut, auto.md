# 自己
> [!tip] 快速记忆
> **Auto**matic（自动挡）就是汽车自己换挡。

- **automatic**： /ˌɔːtəˈmætɪk/=auto+mat+ic=自己+同 mot(动)+a.=a.==自动的== 
- **automation**： /ˌɔ:tə'meiʃən/=auto+mat+ion=自己+动+n.=n.==自动化== 
- **authentic**： /ɔːˈθentɪk/=aut+hent+ic=自己+做+a.=a.==真正的==（诸如原作者之类的）； ==可靠的== 
- **autonomous**： /ɔːˈtɑːnəməs/=auto+nom+ous=自己+统治+a.=a.==自治的==；【真题意群】 a autonomous vehicle 自主驾驶车辆 
- **autonomy**： /ɔːˈtɑːnəmi/=n.自治 automobile /ˈɔːtəməbiːl/=auto+mobile=自己+机动的=n.==汽车== 
- **autograph**： /ˈɔːtəɡræf/=auto+graph=自己+写=n.v.==亲笔签名== 
- **autobiography**： /ˌɔːtəbaɪˈɑːɡrəfi/=auto+bio+graphy=自己+生命+写=n.==自传==
