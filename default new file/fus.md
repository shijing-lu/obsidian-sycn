# **fus = 流(到一起)；融合**

> [!tip] 快速记忆 
> 和 flu 类似，但更强调“融化、流到一起”。**confuse** (困惑) 是脑子里的东西全融到一起分不清了；**refuse** (拒绝) 则是往回(re)推开不让融合。

- **fuse**: /fjuːz/ = fus + e = 流 ==v.融合;熔化 n.保险丝;导火线==
    - **fusion**: /ˈfjuːʒ(ə)n/ = ==n.融合;熔化==
- **futile**: /ˈfjuːt(ə)l/ = fut + ile = 融了 ==a.无效的;徒劳的==
- **refuse**: /rɪˈfjuːz/ = re + fus + e = x + 融合 ==v.拒绝==
    - **refusal**: /rɪˈfjuːz(ə)l/ = ==n.拒绝==
- **refute**: /rɪˈfjuːt/ = re + fut + e = 往回 + 流 ==v.驳斥==
- **confuse**: /kənˈfjuːz/ = con + fus + e = 全部 + 融合 ==v.使混乱;使困惑==
    - **confused**: /kənˈfjuːzd/ = ==a.困惑的==
    - **confusion**: /kənˈfjuːʒ(ə)n/ = ==n.困惑==
    - **confusing**: /kənˈfjuːzɪŋ/ = ==a.令人困惑的==
- **diffuse**: /dɪˈfjuːz/ = dif + fus + e = 离散 + 流 ==v.扩散==
    - **diffusion**: /dɪˈfjuːʒ(ə)n/ = ==n.扩散==
- **infuse**: /ɪnˈfjuːz/ = in + fus + e = 进入 + 流 ==v.灌输;加入==
- **refuge**: /ˈrefjuːdʒ/ = re + fug + e = 回 + 流 ==n.避难所==
    - **refugee**: /ˌrefjuˈdʒiː/ = ==n.难民==
- **subterfuge**: /ˈsʌbtərfjuːdʒ/ = subter + fug + e = 下面 + 流 ==n.借口==
