# **leg legis = law 法律**

> [!tip] 快速记忆 
> 法律。**legal** (合法的)；**legislate** (立法)。

- **legal**: /ˈliːɡ(ə)l/ = leg + al = 法律 + a. ==a.法律上的; 合法的== (例: ~ affairs)
    - 【真题意群】a legal document 法律文件
    - **illegal**: /ɪˈliːɡ(ə)l/ = ==a.非法的==
    - 【真题意群】an illegal hunter 非法偷猎者
    - **legality**: /lɪˈɡæləti/ = ==n.合法; 合法性==
- **legacy**: /ˈleɡəsi/ = ==n.遗产; 遗留; 后遗症==
- **delegate**: /ˈdelɪɡət/ = de + leg + ate = 加强 + 法律—“法律授权之感” ==v.委任 n.代表== (~ a to
- **legislate**: /ˈledʒɪsleɪt/ = legis + l + ate = 法律 + v. ==v.立法== (~ again
    - **legislative**: /ˈledʒɪsleɪtɪv/ = ==a.立法的==
    - **legislation**: /ˌledʒɪsˈleɪʃ(ə)n/ = ==n.立法==
- **legitimate**: /lɪˈdʒɪtɪmət/ = legitim + ate = 法律 + a. ==a.合法的; 合规
- **licit**: /ˈlɪsɪt/ = lic + it = 法律 + a. ==a.合法的; 准许
    - **license**: /ˈlaɪs(ə)ns/ = licen + se = 法律 + n. ==n.许可证 v.批准, 许可==
- **leisure**: /ˈliːʒər/ = leis + ure = 法律→许可 + n. ==n.空闲; 休
- **loyal**: /ˈlɔɪəl/ = loy(leg) + al = 法律 + a. ==a.忠诚
    - **loyalty**: /ˈlɔɪəlti/ = ==n忠诚；忠心
