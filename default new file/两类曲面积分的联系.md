
1. **公式**：
$$
\iint_\Sigma P dydz + Q dzdx + R dxdy = \iint_\Sigma (P \cos \alpha + Q \cos \beta + R \cos \gamma) dS
$$
其中 $\cos \alpha, \cos \beta, \cos \gamma$ 为有向曲面 $\Sigma$ 在点 $(x, y, z)$ 处的法向量的方向余弦。

2. **转换投影法**：由两类曲面积分的联系，设有向曲面 $\Sigma$ 由方程 $z = z(x, y)$ 给出，在 $xoy$ 面投影为 $D_{xy}$，曲面 $\Sigma$ 取上侧，则
$$
\cos \alpha = \frac{-z'_x}{\sqrt{1 + z'^2_x + z'^2_y}}, \quad \cos \beta = \frac{-z'_y}{\sqrt{1 + z'^2_x + z'^2_y}}, \quad \cos \gamma = \frac{1}{\sqrt{1 + z'^2_x + z'^2_y}}
$$
整理得
$$
\iint_\Sigma P dydz + Q dzdx + R dxdy = \pm \iint_{D_{xy}} [P(-z'_x) + Q(-z'_y) + R] dxdy
$$
其中，曲面取上（下）侧，取正（负）号。
