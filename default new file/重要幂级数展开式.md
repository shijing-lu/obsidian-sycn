1) $\displaystyle \frac{1}{1-x} = 1 + x + x^2 + \cdots + x^n + \cdots, \quad x \in (-1, 1)$
2) $\displaystyle \frac{1}{1+x} = 1 - x + x^2 - \cdots + (-1)^n x^n + \cdots, \quad x \in (-1, 1)$
3) $\displaystyle e^x = 1 + x + \frac{x^2}{2!} + \cdots + \frac{x^n}{n!} + \cdots, \quad x \in (-\infty, +\infty)$
4) $\displaystyle \sin x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!} + \cdots + (-1)^n \frac{x^{2n+1}}{(2n+1)!} + \cdots, \quad x \in (-\infty, +\infty)$
5) $\displaystyle \cos x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n}}{(2n)!} = 1 - \frac{x^2}{2!} + \cdots + (-1)^n \frac{x^{2n}}{(2n)!} + \cdots, \quad x \in (-\infty, +\infty)$
6) $\displaystyle \ln(1+x) = \sum_{n=1}^\infty (-1)^{n-1} \frac{x^n}{n} = x - \frac{x^2}{2} + \cdots + (-1)^{n-1} \frac{x^n}{n} + \cdots, \quad x \in (-1, 1]$
7) $\displaystyle \ln(1-x) = -\sum_{n=1}^\infty \frac{x^n}{n} = -x - \frac{x^2}{2} - \cdots - \frac{x^n}{n} - \cdots, \quad x \in [-1, 1)$
8) $\displaystyle (1+x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \cdots + \frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!}x^n + \cdots, \quad x \in (-1, 1)$
$$
\begin{cases}
x \in (-1, 1), \alpha \leq -1 \\
x \in (-1, 1), -1 < \alpha < 0 \\
x \in [-1, 1], \alpha > 0
\end{cases}
$$
9) $\displaystyle \arctan x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n+1}}{2n+1}, \quad x \in [-1, 1]$
10) $\frac{1}{2}\ln\frac{1+x}{1-x} = \sum_{n=0}^{\infty}\frac{x^{2n+1}}{2n+1}, x \in (-1,1)$
