   **正态分布的常用结论**：若 $X\sim N(\mu,\sigma^2)$，则
   - $P\{X>\mu\}=P\{X<\mu\}=\frac{1}{2}$；
   - $Y=aX+b\sim N(a\mu+b, a^2\sigma^2),\ a\neq 0$，即正态随机变量的一次函数仍服从正态分布；
