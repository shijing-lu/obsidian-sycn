# **merc merch = 商业**

> [!tip] 快速记忆
> 
> 核心是“交易、商业”。**commercial** (商业的)；**merchant** (商人)。

- **commercial**: /kəˈmɜːrʃ(ə)l/ = com + merc + ial = 加强 + 商业 + a. ==a.商业的；商务的==
    - 【真题意群】a commercial organization 商业组织
- **commerce**: /ˈkɑːmɜːrs/ = ==n.商业；贸易==
- **merchant**: /ˈmɜːrtʃənt/ = merch + ant = 商业 + n. ==n.商人==
    - 【真题意群】a merchant ship 一艘商船
- **merchandise**: /ˈmɜːrtʃəndaɪs/ = ==n.商品== (同 commodity, goods)
- **mercy**: /ˈmɜːrsi/ = merc + y = 商业 + n. ==n.仁慈，宽恕；幸运==
    - **merciful**: /ˈmɜːrsɪf(ə)l/ = ==a.仁慈的；令人解脱的==
- **market**: /ˈmɑːrkɪt/ = mark + et = 商业 + n. ==n.市场 v.营销==
