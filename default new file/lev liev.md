# **lev liev = 举起 提高**

> [!tip] 快速记忆 
> 核心动作“举起、变轻”。**elevator** 是把人举起来的电梯；**relieve** 则是把重担举起，从而起到减轻、缓和的作用。

- **level**: /ˈlev(ə)l/ = lev + el = 举起的高度 ==n.水平; 等级== (例: sea ~; price ~)
- **relevant**: /ˈreləvənt/ = re + lev + ant = 反复 + 举起 + a. ==a.有关的== (be ~ to)
    - 【真题意群】relevant information 相关信息
    - **irrelevant**: = ==a.不相关的==
- **lever**: /ˈlevər/ = lev + er = 举起 + n. ==n.杠杆== (同 tool, means)
- **relief**: /rɪˈliːf/ = re + lief = 反复表加强 + 举起—“把压着的东西举起来” ==n.减轻; 缓和==
    - 【真题意群】temporary relief 暂时的缓解
    - **relieve**: = ==v.减轻; 缓和== (同 ease)
    - **alleviate**: /əˈliːvieɪt/ = al + lev + i + ate = to + 举起 + v. ==v.减轻; 缓和==
- **elevate**: /ˈelɪveɪt/ = e + lev + ate = out + 举起 ==v.提升; 举起== (同 promote, boost)
    - **elevator**: = ==n.电梯==
- **levy**: /ˈlevi/ = lev + y = 举起—“层层向上” ==v.征收; n.征收== (例: ~ tax on; impose duty)
- **lift**: /lɪft/ = lift = 举起 ==v.提; 抬起; 提高 n.鼓舞; 电梯; 上升==
- **lofty**: /ˈlɔːfti/ = loft + y = 抬升 + a. ==a.高耸的==
