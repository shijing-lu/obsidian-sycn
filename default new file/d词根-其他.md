> [!tip] 快速记忆 
> 这组词汇很有意思，包含了不少词源谐音和拟声记忆法（比如 disease 疾病就是身体“不轻松”，drama 就是我们常说的“抓马”）。

- **damp**: /dæmp/ = “d“向下 = 下面的地方 ==n.a.潮湿(的) v.使潮湿;抑制==
- **dash**: /dæʃ/ = d 拟声 = 迅速前行的声音 ==n.v.冲 n.破折号==
- **deed**: /diːd/ = “d“向下 = 强化—“确有其事”“联想 did” ==n.行为;事迹==
- **demolition**: /ˌdeməˈlɪʃ(ə)n/ = de + mol + i + tion = × + 建造、组块 + n. ==n.毁坏;破坏==
- **devote**: /dɪˈvoʊt/ = de + vot + e = 加强 + 发誓 ==v.奉献==
- **directly**: /dəˈrektli; daɪˈrektli/ = di + rect + ly = 离开 + 笔直 + ad. ==ad.直接地==
- **drama**: /ˈdrɑːmə/ = 中文已有谐音词汇“抓马” ==n.戏剧;戏剧性事件==
    - **dramatic**: /drəˈmætɪk/ = ==a.戏剧的;戏剧性的;激动人心的==
- **dealer**: /ˈdiːlər/ = deal + er = 交易 + n. ==n.商人;交易商==
- **dilemma**: /dɪˈlemə/ = di + lemma = 2 + 争论“谐音来嘛” ==n.进退两难的境地==
- **disease**: /dɪˈziːz/ = dis + ease = × + 轻松 ==n.疾病 v.传染==
- **density**: /ˈdensəti/ = dens + ity = 密 + n. ==n.密度;浓度==
