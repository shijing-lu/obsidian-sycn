#### 1. 极点在积分域以外
若积分域 $D = \{(r, \theta) \mid \varphi_1(\theta) \leq r \leq \varphi_2(\theta), \alpha \leq \theta \leq \beta\}$，则
$$
\iint_D f(x, y) d\sigma = \int_\alpha^\beta d\theta \int_{\varphi_1(\theta)}^{\varphi_2(\theta)} f(r\cos\theta, r\sin\theta) r dr
$$

#### 2. 极点在积分域边界上
若积分域 $D = \{(r, \theta) \mid 0 \leq r \leq \varphi(\theta), \alpha \leq \theta \leq \beta\}$，则
$$
\iint_D f(x, y) d\sigma = \int_\alpha^\beta d\theta \int_0^{\varphi(\theta)} f(r\cos\theta, r\sin\theta) r dr
$$

#### 3. 极点在积分域内部
若积分域 $D = \{(r, \theta) \mid 0 \leq r \leq \varphi(\theta), 0 \leq \theta \leq 2\pi\}$，则
$$
\iint_D f(x, y) d\sigma = \int_0^{2\pi} d\theta \int_0^{\varphi(\theta)} f(r\cos\theta, r\sin\theta) r dr
$$
