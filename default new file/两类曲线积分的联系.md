
**公式**：$\int_L P(x,y)dx + Q(x,y)dy = \int_L [P(x,y)\cos\alpha + Q(x,y)\cos\beta]ds$。

其中 $\cos\alpha, \cos\beta$ 为有向曲线 $L$ 沿正向切向量的方向余弦。

类似地，可以得到两类空间曲线积分之间的联系：
$$
\begin{aligned}
&\int_{\Gamma} P(x,y,z)dx + Q(x,y,z)dy + R(x,y,z)dz \\
&= \int_{\Gamma} [P(x,y,z)\cos\alpha + Q(x,y,z)\cos\beta + R(x,y,z)\cos\gamma]ds
\end{aligned}
$$
其中 $\cos\alpha, \cos\beta, \cos\gamma$ 为有向曲线 $\Gamma$ 沿正向切向量的方向余弦。
