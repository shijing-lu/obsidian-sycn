# **J 字母 单列高频词汇**

> [!tip] 快速记忆 
> J 字母的单列词以 jour- 居多，与天/日 (day) 的概念相关。

- **jog**: /dʒɑːɡ/ = “j“象形直线偏离=跑动 ==v.慢跑==
- **journal**: /ˈdʒɜːrn(ə)l/ = journ + al = 一天 + n. ==n.杂志刊物;日记日报==
    - **journalist**: /ˈdʒɜːrnəlɪst/ = ==n.新闻工作者;记者==
    - **journalism**: /ˈdʒɜːrnəlɪz(ə)m/ = ==n.新闻业;新闻学==
    - **journalistic**: /ˌdʒɜːrnəˈlɪstɪk/ = ==a.新闻工作者的==
- **journey**: /ˈdʒɜːrni/ = ==n.v.旅行==
