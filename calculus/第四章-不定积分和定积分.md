**组合法**
对于形如 $\displaystyle \int \frac{a \sin x + b \cos x}{c \sin x + d \cos x} \, dx$ 的积分，可令
$$
a \sin x + b \cos x = A (c \sin x + d \cos x) + B (c \cos x - d \sin x)
$$
其中 $A, B$ 为待定系数，则
$$
\int \frac{a \sin x + b \cos x}{c \sin x + d \cos x} \, dx = A \int dx + B \int \frac{c \cos x - d \sin x}{c \sin x + d \cos x} \, dx
$$
第二项中分子恰好是分母的导数（或相差一个常数倍数）
