### 第一节 微分方程的基本概念、一阶微分方程

#### 一、微分方程基本概念
1. **微分方程**：含有自变量、未知函数、未知函数的导数的方程称为微分方程。未知函数为一元函数的方程称为常微分方程。
2. **微分方程的阶**：微分方程中未知函数的导数的最高阶数，称为微分方程的阶。
3. **微分方程的解**
   - **解**：代入微分方程能使方程成为恒等式的函数称为微分方程的解；
   - **通解**：若方程的解中含有独立的任意常数，且独立常数的个数与方程的阶数相同，则称这样的解为方程的通解。
   - **特解**：不含有任意常数或任意常数确定后的解称为特解。
4. **初始条件**：确定通解中任意常数的条件称为初始条件，满足初始条件的解称为满足该初始条件的特解。
5. **线性微分方程**：如果未知函数和它的各阶导数都是一次项，而且它们的系数只是自变量的函数或常数，则称这种微分方程为线性微分方程。
6. **积分方程**：带有未知函数的变上（下）限积分的方程称为积分方程。

#### 六、二阶可降阶型微分方程（仅数一二）

#### 1. $y'' = f(x, y')$ 型（不含 $y$）
- 令 $p = y'$，则 $y'' = p'$，方程化为 $p' = f(x, p)$；
- 解出 $p = \varphi(x, C_1)$，再积分得 $y = \int \varphi(x, C_1)dx + C_2$。

#### 2. $y'' = f(y, y')$ 型（不含 $x$）
- 令 $p = y'$，则 $y'' = \frac{dp}{dx} = p\frac{dp}{dy}$；
- 方程化为 $p\frac{dp}{dy} = f(y, p)$，解出 $p = \varphi(y, C_1)$；
- 再由 $\frac{dy}{dx} = \varphi(y, C_1)$ 分离变量积分。

#### 七、一阶常系数线性差分方程（仅数三）
1. **差分定义**：$\Delta y_t = y_{t+1} - y_t$。
2. **方程形式**：$y_{t+1} + a y_t = f(t)$。
3. **齐次方程通解**：特征方程 $\lambda + a = 0 \Rightarrow \lambda = -a$，通解为 $y_t = C(-a)^t$。
4. **非齐次方程特解**：设 $y^* = \mu^t Q_m(t) x^k$，其中 $k = \begin{cases} 0, & \mu \neq -a \\ 1, & \mu = -a \end{cases}$。
