# **liber = 自由 (free)**

> [!tip] 快速记忆 核心是“自由”。**liberate** 解放就是让人获得自由；**deliver** 把东西递出去，也有一种使其脱手自由的引申含义。

- **liberate**: /ˈlɪbəreɪt/ = liber + ate = 自由 + v. ==v.解放== (同 emancipate)
    
    - **liberation**: = ==n.解放==
        
- **liberty**: /ˈlɪbərti/ = ==n.自由== (同 freedom)；【真题意群】the statue of liberty 自由女神像
    
- **liberal**: /ˈlɪbərəl/ = ==a.自由主义的；慷慨的== (同 generous)
    
- **deliver**: /dɪˈlɪvər/ = de + liver(liber) = 加强 + 自由 ==v.传递；投递==；【真题意群】deliver milk 送牛奶
    
    - **delivery**: /dɪˈlɪvəri/ = ==n.交付；分娩==
        
- **deliberate**: /dɪˈlɪbərət/ = ==a.故意的；深思的 v.仔细考虑==
    
    - **deliberately**: /dɪˈlɪbərətli/ = de + liber + ate + ly = 加强 + 自由 + a. + ad. ==ad.故意地==；【真题意群】you are deliberately late. 你故意迟到。
        
    - **deliberation**: /dɪˌlɪbəˈreɪʃ(ə)n/ = ==n.慎重考虑；沉着==
