

# **jur jurs just = 正义；审判**

> [!tip] 快速记忆 核心含义是“法律、正义、判断”。**justice** 是正义，**judge** 是法官/审判，**injure** (伤害) 就是不(in)正义(jure)的行为。

- **injure**: /ˈɪndʒər/ = in + jure = × + 正义 ==v.伤害==
    - 【真题意群】injure one’s neck 伤到某人的脖子
    - **injury**: /ˈɪndʒəri/ = ==n.伤害==
    - **injured**: /ˈɪndʒərd/ = ==a.受伤的==
- **jury**: /ˈdʒʊri/ = jury = 正义 ==n.陪审团==
- **jurisdiction**: /ˌdʒʊrɪsˈdɪkʃ(ə)n/ = juris + dict + ion = 正义 + 说 + n. ==n.司法权;管辖权==
- **just**: /dʒʌst/ = ==ad.恰好;只是;仅仅;刚刚 a.公正的;合理的;正确的==
    - **justice**: /ˈdʒʌstɪs/ = just + ice = 正义 + n. ==n.正义==
    - 【真题意群】enjoy full justice 享受司法公正
    - **injustice**: /ɪnˈdʒʌstɪs/ = ==n.不正义==
    - **justify**: /ˈdʒʌstɪfaɪ/ = ==v.辩护==
    - **justification**: /ˌdʒʌstɪfɪˈkeɪʃ(ə)n/ = ==n.辩护==
- **adjust**: /əˈdʒʌst/ = ad + just = 去 + 正确 ==v.调整==
    - 【真题意群】adjust one’s way 调整某人的方法
    - **adjustment**: /əˈdʒʌstmənt/ = ==n.调整;适应==
- **prejudice**: /ˈpredʒədɪs/ = pre + jud + ice = 提前 + 审判 + n. ==n.偏见== without ~; preference
    - 【真题意群】a deep prejudice 严重的偏见
- **judge**: /dʒʌdʒ/ = judg + e = 审判 ==v.评判;审判 n.法官==
    - 【真题意群】judge a fact 判断事实
    - **judgement**: /'dʒʌdʒm(ə)nt/ = ==n.审判== (有没有 e 都可以)
    - 【真题意群】reserve one’s judgement 保留某人的判断
    - **judicial**: /dʒuːˈdɪʃəl/ = ==a.司法的;法庭的;公正明断的==

# **junct join = 连接**

> [!tip] 快速记忆 核心意思是“连接 (join)”。**join** 加入；**conjunction** 是连词；**junction** 就是相交连接的接合点/枢纽。

- **join**: /dʒɔɪn/ = join = 连接 ==v.加入==
    - **joint**: /dʒɔɪnt/ = ==n.结合处;关节 a.共同的联合的==
- **conjunction**: /kənˈdʒʌŋkʃ(ə)n/ = con + junct + ion = 共同 + 连接 + n. ==n.结合;连词==
    - **conjunctive**: /kənˈdʒʌŋktɪv/ = ==a.连接的==
    - **disjunctive**: /dɪsˈdʒʌŋktɪv/ = ==a.分离的==
- **junction**: /ˈdʒʌŋkʃ(ə)n/ = junct + ion = 连接 + n. ==n.连接;接合点==
- **adjoin**: /əˈdʒɔɪn/ = ad + join = to + 连接 ==v.毗邻==
    - **adjoining**: /əˈdʒɔɪnɪŋ/ = ==a.毗邻的==

# **joy = 开心**

> [!tip] 快速记忆 核心是“快乐、愉悦”。

- **joy**: /dʒɔɪ/ = joy = ==n.高兴;喜悦;乐趣==
    - 【真题意群】be filled with joy 充满喜悦
- **enjoy**: /ɪnˈdʒɔɪ/ = en + joy = 进入 + 开心 ==v.享受==
    - **enjoyment**: /ɪnˈdʒɔɪmənt/ = ==n.愉快;满意==

# **juven = 小的**

> [!tip] 快速记忆 指“年少的、年轻的”。**junior** 指资历浅的/年少的；**juvenile** 指未成年人。

- **junior**: /ˈdʒuːniər/ = jun + ior = 小的 + a. ==a.年少的;资历浅的== (senior 反义词)
- **juvenile**: /ˈdʒuːvən(ə)l/ = juven + ile = 小 + a. ==a.少年的;幼稚的 n.少年==
- **young**: /jʌŋ/ = 源于 jun = 小的 ==a.年轻的 n.年轻人==
    - **youth**: /juːθ/ = ==n.青春;青年时期==

# **J 字母 单列高频词汇**

> [!tip] 快速记忆 J 字母的单列词以 jour- 居多，与天/日 (day) 的概念相关。

- **jog**: /dʒɑːɡ/ = “j“象形直线偏离=跑动 ==v.慢跑==
- **journal**: /ˈdʒɜːrn(ə)l/ = journ + al = 一天 + n. ==n.杂志刊物;日记日报==
    - **journalist**: /ˈdʒɜːrnəlɪst/ = ==n.新闻工作者;记者==
    - **journalism**: /ˈdʒɜːrnəlɪz(ə)m/ = ==n.新闻业;新闻学==
    - **journalistic**: /ˌdʒɜːrnəˈlɪstɪk/ = ==a.新闻工作者的==
- **journey**: /ˈdʒɜːrni/ = ==n.v.旅行==
