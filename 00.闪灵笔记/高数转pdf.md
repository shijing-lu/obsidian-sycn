

# 多元函数微分学

## 物理应用常用公式（仅数一二）

1. 恒力沿直线做功：$W = F \cdot s$

2. x 处变力做功的微元：$dW = F(x)dx$

3. 面积为 A 的平板在水深 h 处的压力：$P = \rho gh \cdot A$

4. 水深 x 处压力的微元：$dP = \rho g x dA$

5. 相距为 r 的两质点间的引力大小：$F = G \frac{m_1 m_2}{r^2}$

6. 均匀直线段 $[a,b]$，线密度为 $\rho(x)$，质心坐标：$\bar{x} = \frac{\int_a^b x\rho(x)dx}{\int_a^b \rho(x)dx}$

## 经济学应用常用公式（仅数三）

边际和弹性是经济学中的两个重要概念。

### 1. 边际及其相关概念

在经济学中：
- 边际成本定义为产量增加一个单位时所增加的总成本
- 边际收益定义为多销售一个单位产品时所增加的销售总收入

设某产品的产量为 x 单位时所需的总成本为 $C = C(x)$，则称 $C(x)$ 为总成本函数。

设某产品的销售量为 x 单位时的总收入为 $R = R(x)$，则称 $R(x)$ 为总收益函数。

当 $C(x)$ 和 $R(x)$ 可导时，其导函数 $C'(x)$ 和 $R'(x)$ 分别称为边际成本和边际收益，记为：
- $MC = C'(x)$（边际成本）
- $MR = R'(x)$（边际收益）

因为总利润函数 $L(x) = R(x) - C(x)$，所以边际利润为：
$$ML = L'(x) = MR - MC = R'(x) - C'(x)$$

即边际利润为边际收益与边际成本之差。

### 2. 弹性及其相关概念

弹性用于定量地描述一个经济变量对另一个经济变量变化的反应程度，即当一个经济变量变动百分之一时会使另一经济变量变动百分之几。

设 x 和 y 是两个变量，y 对 x 的弹性记为 $\frac{E_y}{E_x}$，当 $y = y(x)$ 可导时，其计算公式为：
$$\frac{E_y}{E_x} = \frac{x}{y} \cdot \frac{dy}{dx}$$

#### (1) 需求的价格弹性

设某商品的市场需求量为 Q，价格为 p，需求函数 $Q = Q(p)$ 可导，则该商品需求对价格的弹性（简称需求弹性）为：
$$\frac{E_Q}{E_p} = -\frac{p}{Q} \cdot \frac{dQ}{dp}$$

其经济意义是：当价格为 p 时，若提价（降价）1%，则需求量将减少（增加）$|\frac{E_Q}{E_p}|$ %

【注】由于需求函数 $Q = Q(p)$ 一般是单调减少的，因而需求对价格的弹性常为负值，如果在题目中给出的弹性为正值，其实是指弹性的绝对值。

#### (2) 收益的价格弹性

除了需求对价格的弹性外，在经济学中还常研究收益对价格的弹性：
$$\frac{E_R}{E_p} = -\frac{p}{R} \cdot \frac{dR}{dp}$$

因为 $R = pQ$，所以有：
$$\frac{E_R}{E_p} = \frac{p}{pQ} \cdot \frac{d(pQ)}{dp} = \frac{1}{Q}\left(Q + p\frac{dQ}{dp}\right) = 1 + \frac{p}{Q} \cdot \frac{dQ}{dp} = 1 + \frac{E_Q}{E_p}$$

其经济意义是：当价格为 p 时，若提价（降价）1%，则收益将增加（减少）$\frac{E_R}{E_p}$ %

【注】由于收益函数单调递增，$\frac{dR}{dp} > 0$，从而 $\frac{E_R}{E_p} > 0$

## 例题

【例 4.7】设总成本关于产量 x 的函数为 $C(x) = 400 + 3x + \frac{1}{200}x^2$，需求量 x 关于价格 P 的函数为 $P = \frac{100}{\sqrt{x}}$。求边际成本，边际收益，边际利润以及收益对价格的弹性。（仅数三）

---


**题型：求隐函数的偏导数**
求导方法：设 $z=f(x, y)$ 由 $F(x, y, z)=0$ 确定
1. 公式法：$(x,y,z)$ 均为自变量，$\frac{\partial z}{\partial x}=-\frac{F_x}{F_z},\frac{\partial z}{\partial y}=-\frac{F_y}{F_z}$；
2. 直接法：$F(x, y, z)=0$ 两端对 $x$ 或 $y$ 求偏导（$x, y$ 为自变量，$z$ 为中间变量）；
3. 微分形式不变性：$F_x^{\prime}dx+F_y^{\prime}dy+F_z^{\prime}dz=0$（$x, y, z$ 均为自变量）。
