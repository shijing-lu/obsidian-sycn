









# **mark marc = 标记**

> [!tip] 快速记忆 与做记号、标志相关。**landmark** 就是地上的标志（地标）；**remark** 就是反复做记号（评论）。

- **mark**: /mɑːrk/ = mark = 标记 ==n.标记；v.做记号==
    - **marked**: /mɑːrkt/ = ==a.明显的；显著的==
- **bookmark**: /ˈbʊkmɑːrk/ = book + mark = 书 + 标记 ==n.书签==
- **remark**: /rɪˈmɑːrk/ = re + mark = 反复 + 标记 ==n.v.评论== (~ on)
    - **remarkable**: /rɪˈmɑːrkəb(ə)l/ = ==a.引人注目的== (同 excellent, extraordinary)
    - **remarkably**: = ==ad.引人注目地==
- **march**: /mɑːrtʃ/ = marc + h = 标记 + n. ==n.三月 v.进军==
- **hallmark**: /ˈhɔːlmɑːrk/ = hall + mark = 大 + 标注 ==n.特点== (同 feature, distinction, trait)
- **landmark**: /ˈlændmɑːrk/ = land + mark = 地 + 标 ==n.地标==
- **margin**: /ˈmɑːrdʒɪn/ = marg + in = 边界 + n.“边界是有标记的” ==n.边缘；利润==
    - **marginal**: /ˈmɑːrdʒɪn(ə)l/ = ==a.微不足道的；边际的==

# **mir mar = 惊讶**

> [!tip] 快速记忆 让人感到惊叹、神奇。**miracle** (奇迹)；**admire** 令人惊叹从而赞赏 (钦佩)。

- **mirror**: /ˈmɪrər/ = mir + ror = 惊讶 + n. ==n.镜子==
    - 【真题意群】a mirror image 镜像
- **admire**: /ədˈmaɪər/ = ad + mir = to + 惊讶 ==v.钦佩；赞美==
    - 【真题意群】admire the trend 欣赏潮流
    - **admirable**: /ˈædmərəb(ə)l/ = ==a.令人钦佩的；绝妙的；极好的==；【真题意群】an admirable job 令人钦佩的工作
    - **admiration**: /ˌædməˈreɪʃ(ə)n/ = ==n.钦佩；赞美==
- **miracle**: /ˈmɪrək(ə)l/ = mir + acle = 惊讶 + n. ==n.奇迹(人力往往做不到)==
- **marvel**: /ˈmɑːrv(ə)l/ = mar + vel = 惊讶 + n. ==n.奇迹；v.对…感到惊讶== (~ at)
    - **marvelous**: = ==a.奇迹的==
- **mirth**: /mɜːrθ/ = mir + th = 惊讶（惊喜）+ n. ==n.欢乐==

# **migr = 迁移**

> [!tip] 快速记忆 核心是“移动、迁徙”。**migrate** 是迁徙，**immigrate** 往里面(im)迁是移入，**emigrate** 往外面(e)迁是移出。

- **migrant**: /ˈmaɪɡrənt/ = migr + ant = 迁移 + n. ==n.移民；(不强调移出移入)候鸟 a.移居的==
- **migrate**: /ˈmaɪɡreɪt/ = ==v.移居；移动==
    - **migration**: = ==n.迁移；移居==
- **immigration**: /ˌɪmɪˈɡreɪʃn/ = im + migr + ation = 里面 + 迁移 + n. ==n.移民==
    - **immigrant**: /ˈɪmɪɡrənt/ = ==n.移民 (移入)==
    - **immigrate**: /ˈɪmɪɡreɪt/ = ==v.移入==
- **emigrate**: /ˈemɪɡreɪt/ = e + migr + ate = out + 迁移 + v. ==v.移居国外==
    - **emigrant**: /ˈemɪɡrənt/ = ==n.移民（移出）==

# **ma(i)n(i) manu = hand 手→控制**

> [!tip] 快速记忆 词根来源于“手 (hand)”。用手操作就是 **manage** (管理)；纯手工就是 **manual**；手工做出来的就是 **manufacture** (制造)。

- **manage**: /ˈmænɪdʒ/ = man + age = 手 + v. ==v.管理== (同 administrate; ~ to do)
    - **manager**: /ˈmænɪdʒər/ = ==n.管理者==
    - **management**: /ˈmænɪdʒmənt/ = ==n.管理==
- **manufacture**: /ˌmænjuˈfæktʃər/ = manu + fact + ure = 手 + 做 + n./v. ==v.制造；n.制造；制造品==
    - **manufacturer**: /ˌmænjuˈfæktʃərər/ = ==n.制造商==
- **manner**: /ˈmænər/ = man + ner = 手 + n. ==n.礼貌==
- **permanent**: /ˈpɜːrmənənt/ = per + man + ent = 自始至终 + 手（中）+ a. ==a.永久的==
- **remain**: /rɪˈmeɪn/ = re + main = 回 + 手（里） ==v.仍然是；保持；保留==
    - **remainder**: /rɪˈmeɪndər/ = re + main + der = 后 + 停留 + n. ==n.剩余物；其他人员==
    - **remains**: /rɪˈmeɪnz/ = ==n.残骸；遗址==
- **remnant**: /ˈremnənt/ = ==n.剩余部分；残余；幸存者==
- **manual**: /ˈmænjuəl/ = manu + al = 手 + a. ==a.手工的== (例: the instruction ~; ~ operation)
- **manifest**: /ˈmænɪfest/ = man + i + fest = 手 + 抓住 ==v.显现；证明 a.明显的==
- **manipulate**: /məˈnɪpjuleɪt/ = mani + pul + ate = 手 + 推 + v. ==v.操作；控制==

# **merg = 沉没**

> [!tip] 快速记忆 核心是“没入水中、沉没”。向外浮现出来是 **emerge** (出现)；向水下沉没是 **submerge** (淹没)。

- **emerge**: /ɪˈmɜːrdʒ/ = e + merge = out + 沉没—“从沉没中出来” ==v.出现== (~ from)
    - **emergence**: /ɪˈmɜːrdʒəns/ = ==n.出现；兴起==
    - **emergency**: /ɪˈmɜːrdʒənsi/ = ==n.紧急情况== (例: an ~ measure)；【真题意群】deal with an emergency 处理紧急事件
- **merge**: /mɜːrdʒ/ = merg + e = 沉没 ==v.合并== (~ into; unite, conflate)
    - **merger**: /ˈmɜːrdʒər/ = ==n.合并；并购==
- **submerge**: /səbˈmɜːrdʒ/ = sub + merg + e = 下面 + 沉没 ==v.沉入水中；完全掩盖==
- **immerse**: /ɪˈmɜːrs/ = im + mers + e = 里面 + 沉没 ==v.沉浸；使陷入== (~ in)

# **men(t) = 心智；思考**

> [!tip] 快速记忆 与精神、思想有关。**mind** 是头脑心智；**mental** 就是精神的；**mentor** 是指导你心智的导师。

- **mind**: /maɪnd/ = mind = 心智 ==n.思想 v.介意==
- **remind**: /rɪˈmaɪnd/ = re + mind = 再 + 思考 ==v.使想起==
    - **reminder**: /rɪˈmaɪndər/ = ==n.提示；提醒物==
- **mental**: /ˈment(ə)l/ = ment + al = 心智 + a. ==a.精神的== (反义 physical)
- **mention**: /ˈmenʃ(ə)n/ = ment + ion = 心智 + n.v. ==v.提到；n.提到== (例: not to mention)
- **comment**: /ˈkɑːment/ = com + ment = 加强 + 心智 ==v.n.评论== (同 criticism, judgement)
    - **commentary**: /ˈkɑːmənteri/ = ==n.现场报道==
- **mentor**: /ˈmentər/ = ment + or = 心智 + n. ==n.导师== (同 tutor)
- **mean**: /miːn/ = me(a)n = 思考 ==v.意味着 a.自私的；刻薄的；平均的 n.平均数==
    - **means**: /miːnz/ = ==n.手段；方法（源于“居中调停”的场景）==
    - **meaning**: /ˈmiːnɪŋ/ = ==n.意义；意思==
    - **meaningful**: /ˈmiːnɪŋf(ə)l/ = ==a.有目的的；有意义的 ad.意味深长地==
    - **meanwhile**: = mean + while = 中间 + 在…期间 ==ad.同时；在此期间==
- **commend**: = com + mend = 共同 + 思考 ==v.推荐；赞扬==
- **recommend**: /ˌrekəˈmend/ = re + com + mend = 再 + 共同 + 思考 ==v.推荐； 建议==
    - 【真题意群】recommend a film 推荐一部电影
- **mad**: /mæd/ = mad = 心智 ==a.疯狂的==
    

# **memor member = 记忆**

> [!tip] 快速记忆 与“记得 (remember)”、“记忆 (memory)”紧密相连。

- **memory**: /ˈmeməri/ = memor + y = 记忆 + n. ==n.记忆==
    - 【真题意群】have a good memory 记性好
    - **memorize**: /ˈmeməraɪz/ = ==v.记住==
        
- **memorial**: /məˈmɔːriəl/ = ==n.纪念碑；纪念物==
    - 【真题意群】a memorial hall 纪念堂
- **memorable**: /ˈmemərəb(ə)l/ = ==a.值得记忆的== (同 notable, remarkable)
- **commemorate**: /kəˈmeməreɪt/ = com + memor + ate = 共同 + 记住 + v. ==v.用…纪念；作为…的纪念==
- **remember**: /rɪˈmembər/ = re + member = 又 + 记忆 ==v.记得== (同 recall, 反义 forget)
- **member**: /ˈmembər/ = member = 记住的人 ==n.成员会员（其实不是这个词根）==
    - **membership**: /ˈmembərʃɪp/ = ==n.会员身份==
- **memo**: /ˈmemoʊ/ = memo = 记忆 ==n.备忘录==

# **mun(i) = 服务职责**

> [!tip] 快速记忆 与公众、群体服务有关。大家共同服务建立的就是社区 **community**；相互服务/交流就是 **communicate**。

- **communicate**: /kəˈmjuːnɪkeɪt/ = com + mun + i + cate = 共同 + 服务 + v. ==v.交流；沟通==
    - **communication**: /kəˌmjuːnɪˈkeɪʃn/ = ==n.交流；沟通==
- **community**: /kəˈmjuːnəti/ = com + mun + ity = 共同 + 服务 + n. ==n.社区==
- **communal**: /kəˈmjuːn(ə)l/ = ==a.公共的== (例: ~ facility)
- **communism**: /ˈkɑːmjənɪzəm/ = ==n.共产主义==
- **common**: /ˈkɑːmən/ = com + mon = 共同 + 服务 ==a.普通的；一般的==
- **immune**: /i'mju:n/ = im + mun + e = 里面 + 服务 ==a.免疫的==
    - **immunity**: = ==n.免除；豁免；免疫力==
