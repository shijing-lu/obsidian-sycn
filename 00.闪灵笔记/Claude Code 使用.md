### 插件使用推荐
#### codegraph
>  这是一个用于将项目转化为知识图谱的开源项目，为 AI阅读项目节省 Token
>  1.  [github 开源地址](https://github.com/colbymchenry/codegraph)
>  2. [b 站参考视频](https://www.bilibili.com/video/BV1As796BEL5/?spm_id_from=333.1007.tianma.6-4-22.click&vd_source=398b62fc876e809c5ae38c3c6a90a2ae)


使用步骤：
1. npm 全局配置+安装
```
npm i -g @colbymchenry/codegraph
codegraph install
```
2. 进入项目，初始化codegraph
```
codegraph init -i
```
![[PixPin_2026-06-06_10-19-42.png]]
这就初始化好了
3. 打开 AI编程软件，让他读读项目试试

codegraph 修改配置命令
方法一：重新输入命令 `codegraph install`
卸载命令：
```
uninstall codegraph
```
