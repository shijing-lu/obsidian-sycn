## 🤖 智能分类规则

### 内容识别
- **数学类**：函数、极限、导数、积分、矩阵、∑、∫、∂、∞、$...$
- **街健类**：肌肉、训练、动作、力量、RM、组数、次数
- **英语类**：语法、词汇、写作、阅读、时态、语态、从句

### 分类算法
```
IF 包含 [函数、极限、连续、导数、积分]
   → Atlas/数学/函数与极限/
   
IF 包含 [肌肉、训练、动作、力量]
   → Atlas/街健/肌肉解剖/ 或 Atlas/街健/训练方法/
   
IF 包含 [语法、词汇、写作、阅读]
   → Atlas/英语/对应子文件夹/
   
ELSE
   → Atlas/其他/待分类/
```

## 🔄 执行流程

### 1. 扫描分析
- 识别所有双链引用 `[[...]]`
- 分析内容主题特征
- 确定归档位置

### 2. 智能归档
- **文件夹不存在** → 自动创建
- **文件不存在** → 创建标准格式文件
- **文件已存在** → 检查内容完整性

### 3. 链接更新
- 确保双链引用指向正确位置
- 建立相关概念连接
- 更新图谱关系
