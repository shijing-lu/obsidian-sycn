# Obsidian 快捷键指南

主要是记录一下符合自己使用习惯的快捷键。并在此基础上不断地进行改善。

> **提示**：打开设置的快捷键是 ctrl+, 但是没有生效，可能是冲突了，我改为 ctrl+.

## 核心快捷键

### 编辑模式切换
- **在编辑模式下快速切换编辑和阅读的视图**：`Ctrl/Cmd + E` ⭐️
  - 英文：Toggle edit/preview mode

### 系统设置
- **快捷打开设置栏**：`Ctrl + .`
  - 英文：Open settings
- 在新窗口打开当前文件：`ctrl+shift+n`
### Claudian 和面板
- **调出 Claudian 面板**：通过命令面板 `Ctrl/Cmd + P` → 搜索 "Claudian"
  - 英文：Command palette → Claudian
- **折疊/展开左侧边栏**：`ctrl+shift+→`
  - 英文：Toggle file explorer
- 折疊/展开 右侧边栏：`ctrl+shift+←`
  - 英文：Toggle sidebar

### 标题设置
ctrl + 1...6

代码块：`ctrl+shift+C`
